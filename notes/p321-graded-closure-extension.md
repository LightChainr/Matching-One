# P321: direct-sum closure works, but Q differentiation does not force Jordan mixing

## Decision

The crossed and trivial closures can be made into one exact graded object, but
only by keeping them as separate module blocks:

```text
M = M_cross direct_sum M_trivial,
Gamma = diag(I,-I),
W_Q = diag(I,QI),
J_Q = Gamma W_Q = diag(I,-Q I),
C = diag(T,I),
D_Q = J_Q C = diag(T,-Q I).
```

For a common transfer word `A`,

```text
Tr[D_Q diag(A,A)] = Tr(TA)-Q Tr(A).
```

Thus the two-closure functional from `9dda24e` has an exact supertrace/block
realization.  This repairs the single-space pull-through obstruction without
turning the weighted difference into one ordinary local defect.

The new result is negative and useful:

> A regular `Q` derivative of this graded label is diagonal, not nilpotent.
> A Jordan matrix element can be manufactured only after supplying a singular
> confluent identification of the two modules, and that identification is not
> unique in the checked algebra.

Therefore the first missing datum in `F_t(tau)` is an independent scalar
thermal amplitude in each closure module.  A logarithmic/Jordan matrix element
is additional extension data, not a consequence of the homology trace or the
`L_hom -> L_CP` tangent shift alone.

## Exact block pull-through

On the doubled connectivity space define

```text
E_i       = diag(e_i,e_i),
E_i^target = diag(e_(i+1),e_i).
```

Translation covariance gives, representation-independently,

```text
C E_i = E_i^target C.
```

Because `J_Q` is central in the block label,

```text
D_Q E_i = E_i^target D_Q.
```

Splitting the last equation into its constant and `Q` coefficients gives zero
integer matrix residual at every site for widths 2, 3 and 4.  This is the
correct sense in which the two channels form a blockwise affine-TL
intertwiner.  The first block crosses the seam and shifts the generator; the
second block remains untwisted.

The result contrasts with the single-space sum

```text
T-QI,
```

whose two terms were forced to obey incompatible pull-through laws.  Direct
sum, rather than algebraic cancellation, is the essential operation.

## The regular Q derivative is semisimple

It is important to separate grading from weight:

```text
Gamma = diag(I,-I),
W_Q   = diag(I,QI),
J_Q   = Gamma W_Q.
```

At `Q=1`, `J_1` has eigenvalues `+1,-1`; those do not collide.  The ungraded
weight `W_Q` does have coincident eigenvalues at `Q=1`, but its derivative is

```text
W'_1 = diag(0,I),
(W'_1)^2 = W'_1.
```

Equivalently,

```text
J'_1 = diag(0,-I)
```

has nonzero square and rank equal to the Catalan module dimension.  The exact
ranks at widths 2, 3 and 4 are `2,5,14`.  Nothing nilpotent is generated by
ordinary differentiation.

This also types the exact #333 transport correctly:

```text
L_hom -> L_CP tangent shift = -pi_0D.
```

It is the diagonal derivative of the 0D sector weight.  It is a lift
counterterm/connection coefficient, not evidence for an off-diagonal
logarithmic partner.

## A Jordan limit exists, but is extra and nonunique

Let `delta=Q-1` and let `X` be any allowed module map.  The singular basis

```text
S_X(delta) = [[I,X],[0,delta I]]
```

gives the exact identity

```text
S_X(delta) diag(I,(1+delta)I) S_X(delta)^-1
 = [[I,X],[0,(1+delta)I]].
```

As `delta -> 0`, this tends to

```text
I + N_X,
N_X = [[0,X],[0,0]],
N_X^2=0.
```

So a two-by-two module-block Jordan extension is algebraically possible.  It
is not produced in a regular basis; the singular `S_X` is precisely the extra
confluent identification that must be physically declared.

For crossed pull-through, `X` must satisfy

```text
X e_i = e_(i+1) X,
X T = T X.
```

The canonical choice `X=T` works with zero residual and produces a rank
`2,5,14` nilpotent at widths 2, 3 and 4.  But it is not selected uniquely.
Exact rational linear algebra gives:

| width | module dimension | join sigma-intertwiners | affine sigma-intertwiners |
|---:|---:|---:|---:|
| 2 | 2 | 2 | 2 |
| 3 | 5 | 5 | 3 |
| 4 | 14 | 20 | 9 |

The corresponding affine commutant dimensions are also `2,3,9`; multiplication
by `T` identifies the commutant with the sigma-intertwiner space.  Even after
translation compatibility there is no unique nilpotent line.

These multiplicities are exact for the periodic connectivity-join quotient.
A fuller detach/loop-weight affine-TL action could reduce them, but the current
algebra cannot choose a Jordan partner.

## Consequence for `F_t(tau)`

The minimal continuum input remains two scalar one-point amplitudes:

```text
F_t^cross(tau),
F_t^trivial(tau),
F_t(tau)=F_t^cross(tau)-F_t^trivial(tau)  at Q=1.
```

To replace these by a Jordan matrix element one must additionally provide:

1. a canonical `Q`-dependent identification of the two modules;
2. a selected off-diagonal intertwiner `X`;
3. normalization/Gram data fixing the scale of `X`;
4. a thermal insertion which actually couples through that extension.

This is consistent with the #333 signed connected-history positive control:
nilpotency requires explicit noncoarsening/connected-history structure.  It
does not arise from the diagonal critical-polynomial coefficient `-Q`.

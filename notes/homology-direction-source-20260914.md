# Direction-resolved rank-one homology as a modular source

Date: 2026-09-14. Continuum formula from Arguin/Pinson plus exact finite L=3,4 square controls. Addendum to draft #773 / #585 / #765 / #775.

## 1. Aggregate rank one throws away a universal directional law

A rank-one configuration has image subgroup generated by one primitive vector

    {a,b}, gcd(a,b)=1,

with `{a,b}` identified with `{-a,-b}`. The aggregate probability

    P1=sum_primitive pi({a,b})

forgets this direction.

Arguin's torus homology formula gives the continuum probability of every primitive subgroup. For Q=1, with `tau_(a,b)=a-b tau`, Eq. (19) of hep-th/0111193 gives a closed theta-function expression for `pi_1({a,b};tau)`. The modular action is exact:

    pi_tau({a,b}) = pi_(tau+1)({a+b,b}),
    pi_tau({a,b}) = pi_(-1/tau)({-b,a}).                 (1)

Thus the rank-one directional distribution is itself a universal modular object, not microscopic decoration.

## 2. An orientationless homology-character source

Define

    H_tau(theta_1,theta_2)
      = sum_primitive pi({a,b};tau)
          cos(a theta_1+b theta_2).                       (2)

Then

    H_tau(0,0)=P1(tau).                                  (3)

Equation (1) gives the exact covariance rules

    H_(tau+1)(theta_1,theta_2)
      = H_tau(theta_1,theta_1+theta_2),                  (4)

    H_(-1/tau)(theta_1,theta_2)
      = H_tau(theta_2,-theta_1).                         (5)

So theta is a dual homology source. It refines the bounded rank source `sX`: `s` distinguishes rank 0/1/2, while theta resolves the infinitely many primitive directions inside rank one.

A combined continuum topological partition can be written schematically as

    Z_top(s,theta;tau)
      = P0 e^-s + H_tau(theta) + P2 e^s.                 (6)

At theta=0 it reduces to the rank-source object already studied on #773.

## 3. Direction tensor and a modular-invariant scalar

The Hessian at theta=0 is

    -partial_i partial_j H_tau(0)
       = sum_primitive pi({a,b}) v_i v_j,
       v=(a,b).                                          (7)

Under a change of homology basis this tensor transforms covariantly.

A particularly clean scalar uses the torus metric:

    R_tau(a,b)=|a-b tau|^2 / Im(tau).                    (8)

`R_tau` is invariant under the simultaneous modular transformation of tau and the primitive homology vector. Hence

    W2(tau)
      = E[R_tau(a,b) | rank=1]                           (9)

is a genuine modular-invariant rank-one directional observable. More generally

    L_dir(t;tau)
      = E[exp(-t R_tau(a,b)) | rank=1]                  (10)

is an entire family of scalar modular fingerprints.

These observables require no naming of a CFT primary: their combinatorial semantics are exactly the homology subgroup.

## 4. Square-torus continuum distribution

Using Arguin's Q=1 Gaussian/homology sum at `tau=i`, the conditional rank-one direction probabilities begin

    P({1,0}|r=1) = P({0,1}|r=1)
                 = 0.4447212750831043947...,

    P({1,1}|r=1) = P({1,-1}|r=1)
                 = 0.05507302548667763086...,

    P({1,2}), P({1,-2}), P({2,1}), P({2,-1})
                 = 0.00010284679714423245... each,

with higher slopes exponentially suppressed.

The modular scalar is

    boxed: W2(i)=1.11179170483969684736....              (11)

Two simple character values are

    H(pi,0)/P1  = -0.11014606262345338660...,
    H(pi,pi)/P1 = -0.77970787475309322680....             (12)

These are continuum positive-control numbers, not fitted lattice amplitudes.

## 5. Exact finite square-site controls

An independent lifted-homology enumerator was extended to return the primitive generator whenever rank=1. Evaluated at the finite square NN balance root:

### L=3

    P({1,0}|r=1)=P({0,1}|r=1)=0.4747378759225488...,
    P({1,1}|r=1)=P({1,-1}|r=1)=0.0252621240774512...,

    W2=1.05052424815490238...,
    H(pi,0)/P1=-0.05052424815490238...,
    H(pi,pi)/P1=-0.89895150369019524....

### L=4

    P({1,0}|r=1)=P({0,1}|r=1)=0.4658668998248268...,
    P({1,1}|r=1)=P({1,-1}|r=1)=0.0341331001751732...,

    W2=1.06826620035034641...,
    H(pi,0)/P1=-0.06826620035034641...,
    H(pi,pi)/P1=-0.86346759929930719....

The two tiny sizes move in the direction of the continuum values. This is a positive control only, not a convergence-rate estimate.

At these sizes only the four axis/diagonal primitive subgroups occur in the NN rank-one sector. Larger widths are required before higher primitive slopes can enter without small-torus geometric obstruction.

## 6. Connection to oblique and elongated geometries

The direction-resolved law gives a natural interpolation between two regimes already treated separately in the project:

1. **critical fixed modulus:** several primitive homology classes have O(1) continuum probabilities determined by tau;
2. **fixed subcritical / very elongated geometry:** directional connection cost selects the norm-minimizing period and nonparallel classes become exponentially separated.

Thus the loss of competing directions away from criticality can be studied directly at the level of the homology-direction distribution rather than inferred from aggregate rank.

For #765 this suggests replacing the binary question "which period is cheapest?" by a quantitative directional Gibbs law whose critical endpoint is supplied by (2)--(10).

## 7. Interface to map-resolved torus tomography

#585 asks for observables with explicit connectivity/map semantics. The primitive subgroup `{a,b}` is exactly such a label. Therefore the family `H_tau(theta)` is a better positive control for modular/map-resolved candidates than another scalar aspect-ratio ray:

- the source language is explicit;
- modular covariance is exact;
- infinitely many directional components are constrained simultaneously;
- held-out shear/modulus tests are available.

A continuum candidate which fits aggregate P1 but predicts the wrong homology-direction tensor should be rejected.

## 8. Suggested finite-lattice computation

Where an exact rank-sector transfer already carries lifted homology, retain the primitive rank-one generator and output

    C[L,a,b,k]
      = # configurations of size k with rank-one subgroup {a,b}.  (13)

Do not build a separate large engine if #775's state representation can carry this label cheaply. At minimum report `W2`, selected character values and the axis/diagonal/higher-slope mass.

## 9. Boundaries

- Arguin's formula is a continuum critical FK/percolation result; transporting it to finite square-site lattices is a universality/convergence statement, not an exact finite identity.
- `{a,b}` is an unoriented subgroup, so the cosine source is natural; an oriented complex phase would require an additional orientation convention.
- The direction tensor is topological data, not a local operator identification.

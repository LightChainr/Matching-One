# Rank-jump-two attachment spines: an exact finite classification and the 6-arm risk

Date: 2026-09-14. Proof draft / exact graph lemma on an honest NN square-site torus. This note isolates the local-topological content of a single-site jump `Delta_v(r-1)=2`. The exact attachment-offset classification is finite graph theory; the upgrade to macroscopic alternating 6/8-arm events is stated separately as a proof obligation.

## 1. Setup

Let `G_0` be the occupied NN graph with site `v` vacant and `G_1` the graph after opening only `v`. Assume

    rank im[H_1(G_0)->H_1(T^2)] = 0,
    rank im[H_1(G_1)->H_1(T^2)] = 2.                     (1)

Thus `Delta_v X=2` for `X=r-1`.

Every connected component `C` of `G_0` has zero deck displacement around every closed walk. Consequently, after choosing one lifted vertex, `C` admits a consistent lift potential to the universal cover `Z^2`: the lifted coordinate of a vertex is path-independent up to one global deck translation for the whole component.

Let `A(C)` be the set of occupied NN neighbours of `v` that belong to `C`. Only components with `|A(C)|>=2` can create a cycle when `v` is opened.

## 2. Attachment deck offsets

Fix one lift `v_tilde` of `v`. For each attachment `a in A(C)`, there is a unique local lift of `a` adjacent to `v_tilde`; compare it with the chosen lifted copy of `a` in the consistent lift of `C`. Their difference is a period vector

    tau_C(a) in Lambda.                                    (2)

Changing the chosen global lift of `C` adds the same period vector to every `tau_C(a)`, so all differences

    tau_C(a)-tau_C(b)                                      (3)

are well-defined.

### Lemma 1 — exact homology generator

The ambient homology image created by opening `v` is generated by the vectors

    { tau_C(a)-tau_C(b) :
      C touches v, a,b in A(C) }.                          (4)

Proof sketch. Any new cycle must use `v`, because `G_0` has ambient rank zero. Remove `v` from such a cycle. Each remaining path lies inside one component `C` and joins two attachments `a,b`; closing it by the two incident edges at `v` has deck displacement (3). Conversely every path in connected `C` between two attachments closes through `v` and realizes exactly that displacement. Old cycles contribute zero ambient homology by assumption. Therefore (4) generates the full new image.

This statement is directly implementable with lifted union-find potentials and does not require an arm classifier.

## 3. Minimal spine dichotomy

For each component `C`, let

    H_C = span_Z {tau_C(a)-tau_C(b)} subset Lambda,

and let `r_C` be its real rank, `0,1,2`. By Lemma 1,

    rank span_C H_C = 2.                                   (5)

There are two minimal mechanisms.

### Type T — single-component theta/multicontact spine

Some one component has `r_C=2`. Then necessarily `|A(C)|>=3`: two independent differences need at least three attachment offsets.

The minimal case has three attachment germs. Adding `v` to one connected outside component creates two independent cycles through the same outside component. A regular neighbourhood can have the ribbon topology of a theta spine of a once-punctured torus. It is therefore **not** legitimate to assume that every rank jump two requires four black attachment arms.

Four or more contacts in the same component also belong to this class unless decomposed further by a declared spine convention.

### Type R — split-loop / rose mechanism

No single component has rank two, but at least two touching components have rank-one subgroups whose generated directions are nonparallel. Each such component needs at least two attachments, so the minimal total number of attachment germs is four.

Opening `v` then closes at least two independent loops carried by different outside components. This is the natural four-black-arm / figure-eight or split-rose mechanism.

### Corollary

Every single-site rank jump two contains either

1. a rank-two attachment-offset set in one outside component with at least three contacts; or
2. at least two rank-one outside components with at least two contacts each and nonparallel deck directions.

This is exhaustive by (5). It is stronger and more precise than classifying by the occupied degree of `v` alone.

## 4. Why Type T is the concrete 6-arm threat

The standard 8-arm story implicitly imagines four macroscopic black arms separated by four complementary arms. Type R is compatible with that picture.

Type T is different. Its minimal three attachment branches can form a theta spine. If those three black branches stay disjoint to a macroscopic annulus, planar separation supplies three complementary matching-white channels, giving a 3+3 polychromatic / 6-arm candidate rather than 4+4.

This is exactly the lower channel that issue #768 must exclude if the 8-arm field is to be the first allowed matching-odd scalar: with the usual polychromatic exponents,

    alpha_6-alpha_4 = 5/3 < 4.                             (6)

The mere existence of Type T does not yet prove a nonzero continuum 6-arm amplitude. It does prove that an argument of the form "rank jump two topologically requires four black arms" is false without an additional ribbon/map/parity theorem.

## 5. Macroscopic-arm extraction: precise remaining lemma

A useful next theorem would be:

> On a torus with systole `ell`, a Type-T rank-jump-two event forces three mutually disjoint black arms from a fixed neighbourhood of `v` to distance `c ell`, for an absolute `c>0`; Type R forces four. Matching duality then supplies the corresponding separating white arms.

The attachment offsets show why such a statement is plausible. If all connecting paths between the relevant attachment germs were confined to a contractible disk of diameter `<ell/2`, every displacement difference (3) would be zero, contradicting rank two. In the universal cover, independent nonzero differences force paths to distinct deck translates.

What is not yet proved here is the **simultaneous disjoint-arm extraction with a uniform annulus and the matching-white separators**. Shared tree segments, the location of branch points, and lattice/matching diagonal conventions must be handled explicitly. This is a finite geometric lemma, not a CFT selection rule.

## 6. Exact computational classifier for #769

For every configuration with `Delta_v X=2`:

1. close `v` and find the occupied NN components touching its four neighbours;
2. assign lifted potentials within each touching rank-zero component;
3. record the attachment offsets `tau_C(a)`;
4. compute each `r_C` and the rank of their union;
5. label at least:

```text
T3: one component, exactly 3 attachment germs, r_C=2;
T4+: one component, >=4 germs, r_C=2;
R22: >=2 rank-one components, two-contact minimal split;
MIXED: larger nonminimal variants;
```

and retain representative configurations plus the generated deck vectors.

This classification is exact at the graph/homology level and is cheaper than solving the full macroscopic arm problem. Issue #769 has been asked to include it.

## 7. Implication for the current 8-arm conjecture

The strong 8-arm claim now has a sharper fork:

- if Type T is impossible after all under the honest square-site/matching embedding, prove the missing graph lemma;
- if Type T exists but belongs to a matching-even or wrong map sector, prove that selection rule;
- if Type T contributes generically to the matching-odd rank observable, the leading 8-arm hypothesis must be corrected, because a lower 6-arm channel is available.

No finite occurrence count by itself decides which branch is correct. The purpose of this note is to make the obstruction concrete enough that theory (#768) and exact enumeration (#769) meet on the same typed object.

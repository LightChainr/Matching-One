# Circulant implementation and common-random-number coupling for Gaussian tori

Status: implementation-oriented derivation for issue #22.

The fixed-N Gaussian-integer construction is not only geometrically cleaner than Pell pairing; for primitive `(a,b)` it has an exact one-dimensional cyclic representation that should make production code simpler and common-random-number coupling much cleaner.

## 1. Quotient is exactly Z/NZ

Take period vectors

\[
v_1=(a,b),\qquad v_2=(-b,a),
\]

with

\[
\gcd(a,b)=1,
\qquad N=a^2+b^2.
\]

Define

\[
\phi:\mathbb Z^2\to\mathbb Z_N,
\qquad
\phi(x,y)=ax+by\pmod N.
\]

Both periods lie in the kernel:

\[
\phi(a,b)=a^2+b^2=0\pmod N,
\]

\[
\phi(-b,a)=-ab+ab=0.
\]

Because `gcd(a,b)=1`, the map is surjective. Its kernel therefore has index `N`. The period lattice generated by `v1,v2` also has index

\[
|\det(v_1,v_2)|=a^2+b^2=N.
\]

Hence the two sublattices coincide:

\[
\boxed{
\mathbb Z^2/\langle v_1,v_2\rangle\cong\mathbb Z_N,
\qquad j=ax+by\pmod N.
}
\]

No coordinate fundamental-domain search is needed.

## 2. Primal and matching graphs are circulant

Under the label `j=ax+by mod N`, the square-lattice nearest-neighbour steps are

\[
\pm e_x\mapsto \pm a,
\qquad
\pm e_y\mapsto \pm b.
\]

Therefore the primal NN graph is the undirected circulant

\[
\boxed{
C_N(\pm a,\pm b).
}
\]

The square-site matching lattice adds diagonal steps

\[
\pm(e_x+e_y)\mapsto\pm(a+b),
\]

\[
\pm(e_x-e_y)\mapsto\pm(a-b),
\]

so the matching graph is

\[
\boxed{
C_N(\pm a,\pm b,\pm(a+b),\pm(a-b)).
}
\]

This is a very small edge generator: for each vertex, only two forward primal steps and four forward matching steps are needed after duplicate handling.

## 3. Recovering torus winding from lifted displacements

The cyclic label alone is insufficient for homology: the union-find still needs a lifted displacement in `Z^2` for each edge.

Store each step with its physical lattice displacement, e.g.

```text
+a      -> (1,0)
+b      -> (0,1)
+a+b    -> (1,1)
+a-b    -> (1,-1)
```

and negatives accordingly.

When a union-find cycle closes with lifted displacement `(X,Y)`, it is a torus winding iff `(X,Y)` is a nonzero period-lattice vector. Its winding coefficients in the period basis are exactly

\[
\boxed{
m=\frac{aX+bY}{N},
\qquad
n=\frac{-bX+aY}{N}.
}
\]

For a legitimately closed quotient cycle these are integers. This gives an inexpensive consistency assertion in debug/reference builds.

The homology subgroup can be maintained in the `(m,n)` basis exactly as in the existing rank-0/1/2 implementation.

## 4. Same-N orientations can share the exact same random field

Suppose

\[
N=a_1^2+b_1^2=a_2^2+b_2^2
\]

with two inequivalent primitive representations.

Both geometries live on the same abstract vertex set

\[
\{0,1,\ldots,N-1\}.
\]

Generate once per replica

\[
U_0,\ldots,U_{N-1}.
\]

Use the identical occupation decision `U_j<p` in both circulant graphs. This removes the most awkward feature of Pell pairing:

- no extra/missing site;
- no arbitrary truncation of a 289-vector against a 288-vector;
- no difference in canonical sample size;
- no mismatch in continuum modulus or physical area.

It does **not** guarantee high covariance, because the two graphs have different edge steps. It is nevertheless a canonical zero-parameter coupling.

## 5. Automorphism coupling as a frozen variance-reduction parameter

A second geometry may relabel the common cyclic vertex set by any unit

\[
j\mapsto tj\pmod N,
\qquad \gcd(t,N)=1.
\]

This preserves iid Bernoulli occupancy and the marginal distribution exactly. It changes only the coupling between the two orientation observables.

Hence one may use

\[
U_j^{(1)}=U_j,
\qquad
U_j^{(2)}=U_{tj\bmod N}
\]

as a family of legal common-random-number couplings.

### Structural preselection

Before looking at percolation outcomes, score each unit `t` by overlap between the mapped primal/matching step sets. For example,

\[
S(t)=w_1|tS_{\rm NN}^{(1)}\cap S_{\rm NN}^{(2)}|
+w_2|tS_{\rm match}^{(1)}\cap S_{\rm match}^{(2)}|.
\]

Freeze the maximizer using this graph-only score.

For the current same-N pairs, simple searches show that a unit can typically align one undirected nearest-neighbour direction, although not the full graph. This is already more geometrically meaningful than raw array-index pairing between different-size Pell tori.

### Pilot-frozen empirical alternative

If structural overlap is insufficient, estimate the covariance for a bounded shortlist of `t` values on a small independent pilot set, freeze the best `t`, then evaluate on fresh replicas. Record the full pilot shortlist to avoid hidden adaptive selection.

## 6. Antithetic orientation coupling

Because the target quantity is a difference between orientation amplitudes, also test the legal antithetic field

\[
U_j^{(2)}=1-U_{tj}.
\]

This does not preserve the same black configuration at identical `p`; it preserves the correct Bernoulli marginal only at `p=1/2`. Therefore it is appropriate for exact-threshold controls such as square bond percolation, **not** for square-site target runs at `p\ne1/2` unless the parameter/complement mapping is adjusted explicitly.

Do not use antithetic coupling casually in the target model.

## 7. Why this should replace large Pell scans for discovery

The proposed spin-4 matching residual obeys roughly

\[
\Delta M(p_c)\sim L^{-13/4},
\]

and the root gap roughly

\[
\Delta p^*\sim L^{-4}.
\]

If per-replica variance stays `O(1)`, constant-SNR direct detection requires sample count growing as approximately

\[
n_{\rm samp}\sim L^{13/2}
\]

for fixed-p `M` differences. With `O(L^2)` work per connectivity replica, total direct cost can grow near

\[
L^{17/2}=L^{8.5}.
\]

This makes large Pell pairs intrinsically poor **discovery** sizes. Their value is eventual asymptotic confirmation after the effect has been identified at moderate sizes and after covariance reduction has been optimized.

The first same-N pairs `N=65,85,145,...` have physical lengths only `8.06,9.22,12.04,...`, where an `L^-4` orientation signal is orders of magnitude larger than at `L=41` or `99`.

## 8. Recommended implementation order

1. Implement one primitive Gaussian torus in the cyclic representation.
2. Cross-check its edge set and homology results against the general integer-period reference implementation.
3. Verify invariance under changing `(a,b)` signs/order and under unimodular period-basis changes.
4. Implement two same-N geometries sharing `U_j`.
5. Measure covariance under `t=1`.
6. Add graph-only unit-multiplier coupling and freeze the selected `t`.
7. Only after correctness, attach full cross/both/either/horizontal channels and Newman-Ziff threshold ranks.

## 9. Suggested first runs

Use the same-N pairs

```text
N=65:  (8,1)  vs (7,4)
N=85:  (9,2)  vs (7,6)
N=145: (12,1) vs (9,8)
```

before returning to `L~40` or `L~100`.

At these sizes a CPU run with millions to tens of millions of replicas is cheap enough to characterize both the signal and covariance. Use the result to perform a formal sample-size calculation before any GPU rental.

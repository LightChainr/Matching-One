## Exact affine block

For the complementary torus events `cross` and `either`, write

\[
S_{\rm cross}=1-S_{\rm either}.
\]

This affine involution has the homogeneous-coordinate representation

\[
C=\begin{pmatrix}1&0\\1&-1\end{pmatrix},\qquad C^2=1,
\]

on `(1,S)`.  In the centered coordinate `s=S-1/2`, it is simply
`diag(1,-1)`.  Differentiation gives `S'_cross=-S'_either`.  The constant
coordinate cancels in a same-area orientation projector, so both `P4[S]` and
`P4[S']` inherit the same exact minus sign.  This is an exact block of the
state model, not a fitted sign convention.

\[

particular, this change tests whether the visible `S'` drift was merely a

two states in the thermal/matching-odd block:

\[

\[

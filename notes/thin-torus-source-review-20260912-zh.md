# 本轮结果：匹配根、完整阈值分布与拓扑源，并不是同一个极限对象

## 核心判断

这次没有增加宽度，也没有增加随机样本。已完成三项连接：

1. 对每个固定宽度，证明两次同调出生时间的联合极值极限，并给出显式常数；完整阈值分布趋向两端，而不是趋向圆柱匹配根。
2. 解释为什么匹配中位根仍可准确趋向内部谱交点：它平衡的是两个指数稀有事件。其中心概率窗口、条件分布、源致根位移和直接抽样病态性均可精确推导。
3. 在实际宽度四点渗流算子上，证明偶拓扑源响应的一般可见阶数为 28，非零源配分函数的一个固定实例为 29。三维单配置源代数不等于三维长度动力学。

这些是有限格点概率与精确代数结果，不是新的无限方格临界点、普适指数或连续场识别。没有做广泛新颖性检索。

## 一、两次出生分离到 0 和 1：不只是一条小宽度数值曲线

在周期为 `(w,0),(0,m)` 的诚实方格点渗流环面上，保持周期二的平行提升边。令 r 为环境同调像的秩。给每个站点独立均匀标签，T1、T2 分别是 r 第一次达到 1、2 的占据概率。

`F(p)=E[r(p)]/2=(1+M(p))/2` 是以各一半概率选择 T1 或 T2 后的阈值分布。它不是固定 p 下 r 的分布。

满行迫使横向绕行，空行禁止纵向绕行，因此每个有限系统都满足：

```
P0(p) <= (1-p^w)^m,
P2(p) <= [1-(1-p)^w]^m.
```

固定 w、任意内点 p，m 增长时 rank 1 概率趋于一；M 趋于零，F 趋于 1/2。整个阈值概率测度弱收敛到 `(delta_0+delta_1)/2`。所以：固定非中位分位数走向两端，有限中位数却可以趋向内部 q_w。对极限平坦 CDF 求逆不能恢复有限中位根的极限。

更精确地，对每个固定整数 w>=2：

```
(m^(1/w) T1, m^(1/w)(1-T2)) => (A_w,B_w),
P(A_w>x)=exp(-x^w),
P(B_w>y)=exp(-c_w y^w),
A_w 与 B_w 在极限中独立。
```

这里 `c_w=[z^0](z^-1+1+z)^w` 是中央三项式系数，w=2,3,4 分别为 3、7、19。它不是拟合参数，而是最短白色 matching 绕行形状的精确计数：m 足够大时，大小恰为 w 的最短 matching 绕行集合有 `m*c_w` 个。主格点侧最短集合只有 m 个完整横行。

证明包括非最短圈的消失界、局部图案的混合阶乘矩，以及低标签与高标签图案重叠时的不相容处理。它不假设有限出生时间独立。事实上独立有限控制给出连续出生时间协方差：2x3 为 `1123/58800`，3x3 为 `1/56`，均非零。

对固定 u，有

```
u<1/2: m^(1/w) Q_m(u) -> [-log(1-2u)]^(1/w),
u>1/2: m^(1/w)(1-Q_m(u)) -> [-log(2u-1)/c_w]^(1/w).
```

同时证明了任意正阶联合矩收敛，并将结论转回仓库使用的整数排列出生秩 K1/K2；没有忽略独立均匀顺序统计量与排列时钟之间的噪声。

证明：`notes/thin-torus-two-birth-limits-20260912.md`。

## 二、两个周期都增长仍可能不够：#613 的几何条件有实际内容

上面的有限行界还直接适用于 `w=o(log m)`，此时即便 w 也趋向无穷，仍然有 rank 1 集中和两端阈值极限。例如 `w_j=j, m_j=ceil(exp(j^2))`，两个周期都增长，却不产生指向无限二维 p_c 的阈值阶跃。

这不是反驳 #613。该 issue 使用的是 `ell_N/log N -> infinity`；这里反例的该比值趋于零。本次排除的是将它擅自削弱为“最短周期趋于无穷”。也没有证明原条件恰好必要，或给出全部对数宽度临界区的相图。

固定宽度的 Weibull 常数和 Poisson 误差没有被声称对增长宽度一致。

## 三、为什么一个根仍然稳定：它刻画稀有扇区之间的条件转变

对于已经证明谱分解的宽度 2、3、4，在各自交点 q 附近：

```
Pj(p;m) = lambda_j(p)^m [1+O(eta^m)], j=0,2,
lambda_0(q)=lambda_2(q)=lambda_*<1.
```

记 `a_j=(log lambda_j)'(q)`。在 `p=q+x/m` 上，

```
P(r=2 | r!=1) -> 1/[1+exp(-(a2-a0)x)],
F(p) -> 1/2.
```

条件概率确实形成 sigmoid，但无条件阈值 CDF 仍平坦。这是两个不同测度下的结论。

更具体地，令 `u_m=1/2+z*lambda_*^m/2`，则

```
m[Q_m(u_m)-q] -> g^-1(z),
g(x)=exp(a2*x)-exp(a0*x).
```

中心的 p 窗口是 `1/m`，承载的概率质量却是 `lambda_*^m`。因此

```
M'(p_m) ~ m*h'*lambda_*^m,
Q'_m(1/2) ~ 2/[m*h'*lambda_*^m], h'=a2-a0.
```

根的确定性偏差很小，不等于抽样分辨率很高。

宽度四的精确有限公式给出的分位数数值控制：

| 长度 m | Q(.25) | Q(.75) | 四分位距 |
|---:|---:|---:|---:|
| 32 | 0.3637332207 | 0.7851468495 | 0.4214136288 |
| 256 | 0.2215691537 | 0.8810030956 | 0.6594339420 |
| 65536 | 0.0568643963 | 0.9721533901 | 0.9152889938 |
| 1000000 | 0.0288314252 | 0.9860463208 | 0.9572148957 |

这些不是百万行模拟，而是小伴随矩阵幂。中位极限另外为已发表的 `q4=0.591417170853138...`，不是表中各有限 m 的精确中位数。数值由 80 位精度计算，并以 110 位重算选定点。

对单个 p 的独立 Bernoulli 配置直接观测 `X=r-1`，看到至少一个非零 X 的概率为 `1-(1-E)^n`。在 q4、m=128 时 E 约 `8.49e-10`，仅达到 95% 的“一次非零”概率就需约 `3.53e9` 个这样的样本。这不是根精度要求，也不是普遍计算复杂度下界，不能移植到 Newman–Ziff 全路径直方图、条件化/Rao–Blackwell、重要抽样或精确转移算法。

证明及统计边界：`notes/thin-torus-central-layer-source-20260912.md`。

## 四、内禀源可以重新引入被抵消的模式

保持 #337 原定义：

```
Z(p,s)=P0 exp(-s)+P1+P2 exp(s)
      =1+M sinh(s)+E[cosh(s)-1],
E=P0+P2.
```

用同一全参数迹恒等式，新完成的精确一般阶数为：

| 序列 | 对长度 m 的一般最小常系数递推阶数 |
|---|---:|
| M | 16 |
| E，原始二阶源矩 | 28 |
| exp(s)=2 时两倍倾斜均值的分子 | 28 |
| exp(s)=2 时两倍配分函数 | 29 |

物理 Bernoulli 归一化只重新缩放特征值。倾斜均值是上述序列的比值，没有声称该比值也满足 28 阶线性递推。

与 M 相比，E 恢复了 3+4+4+1=12 个一般模式。上界来自上一轮已证明的全长度迹分解；下界来自原始 509 态算子在 t=3 直接传播得到的精确 Hankel 子式。所有子式非零，并经两个有限域的独立消元核对。这不是在几个参数点猜测全参数恒等式。

此外，源平衡根 p_m(s) 满足精确有限关系

```
log[P2(p_m(s))/P0(p_m(s))]+2s=0,
dp_m/ds|_0 = -E(p_m)/M'(p_m).
```

对宽度 2、3、4 的局部谱合同，

```
p_m(s)=q-2s/(m*h')+O(m^-2+eta^m/m).
```

宽度四 `m*dp_m/ds -> -0.811572172063160...`。未倾斜 M 的根偏差是指数级小；一个固定非零内禀源可改成 `1/m` 级位移。物理归一化未被省略，只是在求零点时因其严格正而消去。

在非零 s 下，原来从 M 抵消的 B16 项具有系数 `-2sinh(s)`。其较慢模式重新进入响应，因此不能把 s=0 的快速修正率视为所有源方向的统一复杂度。

另一方面，长薄环面上任意固定 p 内点、任何有界 s 都有 `Z->1`，全部源累积量趋于零。这种源反射对称性恢复是 rank 1 集中的平凡结果，不能单独作为二维临界点标志。

证明及精确秩证书：`notes/width4-topological-source-visible-modes-20260912.md`。

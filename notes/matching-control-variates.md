# Exact-equivalence control variates for the matching function

Status: high-priority variance-reduction proposal.

## Exact starting point

For a square periodic system, Mertens and Ziff show that the same matching function can be represented by several wrapping-probability differences,

\[
M_L(p)=R^x_L(p)-\widehat R^x_L(1-p),
\qquad x\in\{c,b,e,h\},
\]

where, in their notation:

- `c`: cross-wrapping;
- `b`: wraps both coordinate directions, including spiral or cross wrapping;
- `e`: wraps in either direction (any wrapping);
- `h`: horizontal wrapping, with or without vertical wrapping.

The cluster-number representation is another estimator of the same expectation,

\[
M_L(p)=E[N_B-N_W]-N\chi(p),
\qquad \chi(p)=p-2p^2+p^4
\]

for square site percolation.

Therefore one simulation stream can produce several random variables with exactly the same expectation but different covariance and variance.

Reference: S. Mertens and R. M. Ziff, Phys. Rev. E 94, 062152 (2016), arXiv:1603.07289.

## Proposal: minimum-variance unbiased combination

On each coupled black/white configuration define

\[
D_x=I_x(B)-I_x(W^*),
\qquad x\in\{c,b,e,h\},
\]

and optionally

\[
D_N=N_B-N_W-N\chi(p).
\]

For every retained channel `j`,

\[
E[D_j]=M_L(p).
\]

Thus any fixed weights satisfying

\[
\sum_j w_j=1
\]

give an unbiased estimator

\[
D_{\rm cv}=\sum_jw_jD_j.
\]

If `Sigma` is the covariance matrix of the channel vector, the variance-minimizing weights under the sum constraint are

\[
w_*=
\frac{\Sigma^{-1}{\bf 1}}
{{\bf 1}^T\Sigma^{-1}{\bf 1}},
\]

with the usual pseudoinverse/regularization safeguards when `Sigma` is nearly singular.

This is generalized least squares / control-variate optimization, but here the equal-expectation identities are supplied by exact percolation topology rather than by an approximate regression model.

## Avoiding adaptive bias

Do not estimate weights on the same final sample and silently treat them as fixed.

Use one of:

1. independent pilot sample to estimate `Sigma`, then freeze `w_*`;
2. K-fold cross-fitting, where each fold uses weights learned from the other folds;
3. a symmetry-fixed simple combination preregistered before the large run.

Report both the unoptimized single-channel estimator and the optimized estimator.

## Why this may matter

Near the matching root, black NN and white NN+NNN wrapping events are strongly constrained by torus topology. The different indicators are therefore not generic independent Bernoulli measurements; their covariance matrix may contain near-control-variate directions with much smaller variance.

The cluster-number channel is unbounded compared with the wrapping indicators and may look noisy alone, but it can still be useful with a negative or small control-variate weight if its fluctuations correlate with the wrapping channels.

A successful covariance projection can reduce the number of GPU replicas needed for a fixed root error without changing the finite-size estimator itself.

## First experiment on CPU

At a few modest sizes, e.g. physical circumferences around `16, 24, 32, 48`:

1. use complementary black/white configurations from the same random field;
2. measure all available `D_j` channels;
3. estimate the covariance and correlation matrices;
4. compute pilot-frozen optimal weights;
5. compare standard errors of:
   - `D_e` alone (fast union-find reference),
   - `D_c` alone,
   - equal-weight average,
   - covariance-optimal combination,
   - combination including `D_N`;
6. repeat away from and near the estimated root to see whether weights are stable in `p`.

Acceptance threshold before GPU: at least a reproducible factor-of-two reduction in variance at multiple sizes, or another clear structural covariance pattern worth exploiting.

## Homology implementation requirement

The current `matched_torus_reference.py` only detects whether a cluster has **any** nonzero winding. That is enough for `e` but not for `c`, `b`, and directional classes.

The next reference implementation should retain a basis of independent winding vectors generated by closed cycles in each connected component. In two dimensions:

- homology rank `0`: no wrapping;
- rank `1`: single/spiral wrapping with one primitive winding direction;
- rank `2`: cross-wrapping.

Directional/both classes can then be classified from the generated winding subgroup rather than from a Boolean flag.

This homology classifier should be exhaustively tested against the configuration-level topological statements in the 2016 derivation before being optimized.

## Newman-Ziff version

A more powerful CPU implementation should record these observables by occupation count `k` during a Newman-Ziff growth process and convolve with the binomial distribution afterward. For the matching partner, black occupation `k` corresponds naturally to `N-k` white sites in the complementary configuration.

That gives smooth `M_L(p)` curves and covariance information over a probability interval from the same microcanonical data, reducing the need for an arbitrary fine grid of independent `p` simulations.

For GPU work, compare this sequential union-find strategy against many-replica bit-parallel fixed-`p` kernels; the better architecture may differ between CPU and GPU.

## Geometry caveat

The full set `{c,b,e,h}` is stated for the symmetric periodic setting used by Mertens-Ziff. For rectangular/sheared/rotated tori, do not assume every directional identity survives in the same scalar form without re-deriving the symmetry step. The topological `c` relation is the safest starting point; `e`, `h`, and combined directional identities should be validated for each quotient geometry.

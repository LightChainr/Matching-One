# Phase C: exact typed mixed-join oracle

The antisymmetric N650 path mark is exactly zero, but the symmetric mixed
join can carry two distinct configuration-level signals.  This oracle uses
the smallest honest Gaussian lineage with the same relative factors,

```text
N1 -> N2 / N5 -> N10,   (1+i)(2-i)=3+i,
```

on the real square-lattice quotient `P(3+i)=[[3,-1],[1,3]]`.  Its C++
column-HNF is `[[10,3],[0,1]]`; the intermediate HNFs are
`[[2,1],[0,1]]` and `[[5,3],[0,1]]`.  All `2^10=1024` site masks are
enumerated.

## Typed connectivity and exact displacement

For every mask the oracle keeps two layers:

- occupied black sites with NN edges;
- vacant white sites with NN+NNN matching edges.

`R2` and `R5` identify same-colour sites in the corresponding HNF fibers.
An identification from representative `x` to `y` carries displacement
`y-x`; the potential union-find therefore records the exact final-period
winding generated by the join.

For each colour and `R=0,2,5,25`, retain both

```text
partition rank = occupied vertices - connected components,
ambient H1 rank = rank of all winding generators in H1(T2;Q).
```

The ambient mixed row is

\[
\delta_c=r_{c,25}-r_{c,2}-r_{c,5}+r_{c,0}.
\]

It is not degenerate.  The exact `(delta_B,delta_W)` histogram includes six
pairs, and balanced mask `61` gives `(0,-1)`, hence colour-odd response
`1/2`.

## Local incidence subtraction

For partition rank use the submodular sign

\[
J_c^{\rm full}=r_{c,2}+r_{c,5}-r_{c,25}-r_{c,0}.
\]

Within each source fiber, occupied sites are edges of the bipartite incidence
graph between `C2` and `C5` quotient classes.  Its cycle rank

\[
J_c^{\rm local}=b_1(\text{occupied incidence graph})
\]

is the exact isolated-fiber contribution.  Define

\[
R_c=J_c^{\rm full}-J_c^{\rm local}.
\]

`R_c` vanishes when the fiber has no external connectivity and measures how
spatial NN/matching connections create or screen the local `C2 x C5`
incidence cycle.  It need not be nonnegative.  Balanced mask `87` gives
`(R_B,R_W)=(1,0)`, a nonzero colour-odd witness `1/2`.

At `p=1/2` the exact local normalization is

```text
E[J_B_local] = E[J_W_local] = 499/1024,
E[J_B_local-J_W_local] = 0,
Var(J_B_local-J_W_local) = 681/512.
```

## Symmetry and production interface

Both join orders give the same partition and ambient ranks on every mask and
colour.  The matching involution is the **typed layer swap**: it exchanges
black-NN with white-matching.  It negates colour-odd rows exactly.  Merely
complementing a mask while leaving the graph types fixed is not that
involution and is not claimed to be odd.

The primary future N650 state is the locally-subtracted four-vector

```text
(R_S_even, R_D_even, R_S_odd, R_D_odd),
```

formed inside each same-stream batch from the two orientations.  Score it
against zero with one full delete-one `4x4` covariance.  The ambient-H1
even/odd pair is a correlated mechanism diagnostic, not another vote.
Calling the primary zero a q2/Jordan prediction additionally assumes a
factor-additive topology bridge; a nonzero result falsifies that bridge and
detects mixed factor interaction, not generic chronological “memory.”

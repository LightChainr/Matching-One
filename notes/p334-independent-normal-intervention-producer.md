## Exact source and singular-prefix convention

Only fresh rankcell00 has a nonzero response; every other prefix contributes
zero to the same full-population denominator. For each vacant label u,
contact edges e, touched components c and winding rank are computed in both
geometries. Relative contact addresses are differenced only within the
same UF root. Joint-safe degree class a is `(e_first,e_second)` among labels
preserving rank0 in both geometries. Its loop mark is L=e-c.

For class count n, summed marks S and squared marks Q, define integer

```
v_o(u) = n L_o(u) - S_o,
t_o(u) = v_o(u)^2 - (n Q_oo - S_o^2),
Gnum_ij = sum_u v_i v_j,  Mnum_ok = sum_u t_o v_k.
```

All these quantities vanish outside joint-safe classes. The physical
scores are s=v/d, T=t/d², G=Gnum/d³ and M=Mnum/d⁴. The implementation
uses exact integer rank, not a floating tolerance or prefix-selection rule.

- rank2: `Gnum^+=adj(Gnum)/det(Gnum)`;
- rank1: `Gnum^+=Gnum/trace(Gnum)^2`, the Moore-Penrose inverse;
- rank0: `Gnum^+=0`.

Thus `phi=(t-Mnum Gnum^+ v)/d²` is a rational score at every prefix.
Singular prefixes are retained and counted. There is no ridge, threshold,
or removal of rare prefixes. All projection numerators and denominators,
class-zero sums and `sum phi*v=0` use signed128-bit integers. The fixed
d<=173, square degree4 bounds leave ample integer headroom.

For each own-source axis, B=max|phi|, without a lower floor. If B=0 the
axis response is exactly zero. Otherwise numerator n_phi and common
positive denominator D give Bnum=max|n_phi|, B=Bnum/D and exact rational
label weights `Bnum+n_phi` and `Bnum-n_phi`, each totaling d*Bnum.
There is no floating probability normalization or clipping.

## Coupling and unbiased target

Both arms use the same discrete uniform integer in `[0,d*Bnum)` in an
inverse-CDF sampler over sorted vacant labels. Uniform128-bit rejection
sampling implements the rational probabilities. This is a valid common
inverse-CDF coupling, not a claim of variance-optimal or maximal coupling.

An independent uniform permutation of **all** vacant labels supplies common
remainder priorities. Each arm inserts its selected label first, then
deletes that label from the shared priority list. Each arm's conditional
remainder is marginally uniform. Both receiving geometries share the
resulting arm permutation. Equal selected labels give identically equal
tails, so their response is exactly zero and tail evaluation is skipped.

For every own axis and observable the stored paired contribution is
`B*(F_plus-F_minus)/2`. Its conditional expectation is exactly
`E_uniform[phi F]`. No small-amplitude or Taylor approximation is used.
Randomness is the existing deterministic SplitMix counter stream; the
probability statements use its usual ideal-uniform sampling interpretation,
not a cryptographic or true-randomness claim.

## Fixed stream domain

Let SM be the existing splitmix64 function. Derive

```
prefix_seed = SM(base_seed XOR SM((N<<32) OR 0xf3340001))
treatment_seed = SM(base_seed XOR SM((N<<32) OR 0xf3340002))
counter = batch*prefixes_per_batch + offset
local_id = (((counter*8 + rep)*2 + own_axis)*2 + slot)
treatment_key = SM(treatment_seed XOR SM(local_id))
```

The prefix uses unchanged `counter_permutation(N,prefix_seed,counter)`.
Slot0 samples the coupled labels; slot1 shuffles the common remainder.
Eight rep slots remain reserved even for a smaller technical smoke.
The production must use the same frozen25000 count in all20 batches;
changing it changes counter ranges and is not an extension protocol.
N domains are separate, with independent-prefix sampling as declared.

## Output contract

Each batch directory contains:

- `prefixes.csv.gz`: every fresh prefix, including all non00 zeros;
  N,batch,counter,k0,first_rank,second_rank,gram_rank (-1 outside00),
  B_first,B_second, then24 mean paired-response columns.
- `batch.json`: full denominator, counter domain, seed keys, source SHA,
  period matrices, rankcell counts, Gram-rank counts in00, zero-B counts,
  skipped equal-label pairs, evaluated tails, labels, response sums,
  full-prefix means and sum of outer products of prefix mean responses.
- `COMPLETED`: written only after both artifacts close successfully.

The24 labels have source first/second, receiver first/second and observable
`A_ref,E_ref,C,W,K1,K2`, in that nested order. Responses are averaged over
all requested paired reps, including exact-zero pairs. Batch means divide
by all fresh prefixes, **never by active00 or nonzero-B count**.

With `p_ref=0.59274605079` and Q(k)=Pr(Binomial(N,p_ref)>=k):
`A_ref=Q(K1)+Q(K2)-1`, `E_ref=1-Q(K1)+Q(K2)`,
`C=(K1+K2)/(2(N+1))`, `W=(K2-K1)/(N+1)`; K1,K2 are raw integers.
C and W are continuous-uniform-order-statistic conditional first moments;
no claim about conditional second moments is made by these outputs.
Batch accumulation and canonical tails use long double; serialized
prefix responses retain17 significant digits. Independent20-batch
scientific covariance and the primary four-coordinate decision belong
to the coordinator. The sum-outer array is supplementary prefix-level
sufficient information, not extra independent evidence.

## Technical boundary and cost

The only local execution allowed here is compilation and at most64 fresh
prefixes per size under `--smoke --seed 17`, separate from production.
The executable prints operational counts/time only, never response means.
No scientific summary is inspected and no cloud sampling is started.
The main production work is fresh-prefix UF construction plus tails for
active00, nonzero-B, unequal-label pairs. A conservative ceiling is
`00_count * 2 axes * 8 reps * 2 arms * 2 receivers` engine calls; equal-label
coupling skips reduce that cost. Dispatch can parallelize independent
batches without changing any random stream, preferably leaving one core
free on each16-vCPU host. No large benchmark is needed before dispatch.

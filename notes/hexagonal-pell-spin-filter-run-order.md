This note exists only to prevent the modular-shape hypothesis from becoming a post-hoc curve-fitting exercise.

1. Norm-5 #57 remains the first dedicated H4/H12 discriminator.
2. The Pell campaign is an independent orthogonal test based on torus automorphism, not a replacement for norm 5.
3. At N=780, report fixed H4 (`root L^-6`, residual `L^-21/4`) and same-radial H12 (`root L^-4`, residual `L^-13/4`) scores before a free exponent.
4. Do not reinterpret an H4 failure by moving the modular zero away from `tau=exp(i*pi/3)`; that zero is fixed by symmetry.
5. A nonzero H4-like amplitude at the exact continuum hexagonal shape is impossible for a genuine spin-4 one-point, but finite integer period matrices only approximate that shape. The finite target is the **extra L^-2 suppression**, not exact zero.
6. If N=780 lacks enough power, use its measured variance to decide whether N=10864 is informative; do not assume the larger run is necessary.

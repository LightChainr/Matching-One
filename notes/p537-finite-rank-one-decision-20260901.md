“ordinary landing 的有限 leading block 必然只有一个 pure-thermal 振幅”不再是可用的工作假设。

  `+2.6904188461441777e-14`。两次完整 `2^23` background / `192,937,984`

- #545 给出任意 `R>=1, L>=2R+5` 的显式四臂构型族；其两态 minor 对每个

  `Psi=T_01 A_12-T_12 A_01=-533831111/140737488355328`，并由 Sturm
  证书保持匹配根区间 `[0.59,0.60]` 内不变号。

这些是两个不同层次的代数反例。它们足以让项目停止把 pure-thermal rank one 当成
默认压缩，也足以停止继续搜索第二、第三个有限 minor、扩大 N 或增加 landing descriptor。

### #544 的最后增量：L4→L5 是局部衰减候选，不是 full-U 尺度结论

关闭前的 `e8e9c7cf` 又完成同一 broad radius-one `ell4`/canonical-source 聚合的
axis-L4 与 axis-L5 exact population。L5 的 16 个 `2^20` shards 和 scorer 已在独立
临时目录逐字节复现，结果为

```text
Psi4(L4) = -2.5014630411224358e-6
Psi4(L5) = -4.0685187141747587e-7

L^4 chi_perp: -0.6623827058, -0.6734049505

```

因此 finite rank two 在第二个完整 population 仍存在；两个尺度也与 thermal-orthogonal
系数约按 `L^-4=N^-2` 衰减相容。只有两个尺寸，这不是指数估计。报告中的
`G4=2p(1-p)(Psi'S-Psi S')/S^3` 继续沿用 #545 的 landing-subblock `S`，所以
`L^4 G4` 的近稳定不能改写成完整 original-U `T_N` 的尺度律。

这个增量保留为 **P1 reserve hypothesis**：若 one-defect gate 以后仍需数值判别，才冻结

## 两个 Draft 不能声称什么

### #544 是显式 N25 coarse minor，不是 formal ordinary/no-extra 证书

producer 固定 `x=West(z)`，保存 separate source Bell keys 和局部黑臂接触位，未保存
`x+y+z` 全局联合组件映射或 global no-extra 布尔量；最终列又把 Bell transition 求和成
source absent/present。因此它没有执行 #537 所要求的 canonical ordinary/no-extra
包含性判决。它的 pooled root、全局 `beta/R` 和完整 Schur fibre 处理比 #545 更接近
完整对象，但语义仍只覆盖声明的 radius-one coarsening。

该分支还包含约 7.6 万行生成数据、没有顶层测试/CI，历史 CSV 的 CRLF 使
`git diff --check` 产生约 2965 条 whitespace 报告。结果可引用，分支不是合并单元。

### #545 是 broad all-scale witness，不是完整 pooled-root mixed Hessian

它的可靠增量是 all-scale 显式构型族、完整 axis-L4 broad landing 聚合，以及相应
Sturm/Wronskian 精确算术。它没有冻结 allowed Bell-8、global no-extra、`z` 的
before/after Bell 或 off-port branch，也只计算 axis-L4。

更关键的是，#545 在 landing 子块内令 `beta=Q(A)/Q(T)`，并以该子块
`S=T_01+T_12` 定义 `C=2 Psi/S` 与其导数。#537 的完整对象要求从两几何总体先确定
`beta`、`M_t` 和 `R`，再线性分解 landing fibre；这些量不能在每个子块内重新估计。
所以 #545 的 `C/G` 是正确的 reduced-block 恒等式，却不是 original-U 的完整
pooled-root Schur summand。

此外，脚本生成的两个 JSON 与提交文件语义相同但字节不同；“root certificate
regenerated byte-identically”不成立。后续 `e1f19e4c` 只补 Python 3.9 兼容，未改变
上述范围。以上边界不改变其 all-scale pointwise witness。

## 当前科学判决

1. **研究路线层面退休 finite pure-thermal rank-one rescue。** 未形式化的
   ordinary/no-extra 定义不再获得一次次改合同、补字段、换几何来挽救 rank one 的预算。
2. **保留完整目标。** #537 仍需控制
   `T_N=jY_p-R*jM_p-R_p*jM`，等价于完整 pooled-root 的
   `partial_u partial_epsilon Yhat=T_N/D=J_N/A_N`；有限非零不证明非零无限体极限。
3. **#544/#545 降为固定提交支持。** 它们不是两张独立渐近证据票，也不授权随机生产。

## one-defect 闸门已经触发

[精确结果](p537-one-defect-diagonal-edge-20260901.md)找到一条 literal physical edge：axis
N25、`z=East(x)`、`y=(-1,-1)`，一次 `z` flip 同时使 rank `0→1`、source Bell
`9240712→6848576`、`g16 4→0`。完整总体先冻结 pooled root、`mu` 和 `beta` 后，恢复
geometry pool 与 C4 orbit 的 source midpoint 为 `-1.0888815582478189e-11`，root
counterterm 为 `+2.5901918540035547e-12`，full Schur weight 为
`-8.298623728474635e-12`；三项都有严格不含零的有理区间。

停止规则 A 因而执行：blanket full-graph two-independent-defect / 自动 six-arm gain 路线
被否定，完整 graph 不再枚举。第一条 witness 是 `arm_mask=3` 的 contact/collision edge；
第二条固定 witness 把三对 NN 距离都提高到 2，仍使 joint terminal incidence `2→1`，且
full Schur weight 严格为负 `-9.586976893140449e-11`。因此 metric 非邻接并不等于
separated；contact 必须按 joint incidence/typed carrier 定义。

平行固定资产 `df4a64f6` 只在 N25 axis/tilted、`x=West(z)` 的 alternating radius-one
selected sector 中汇总 740,950 条 kernel-changing fibres，总 signed mass 为
`-4.948839916450813e-6`，并在该 sector 内得到 contact mask 0 的 0 classes / 0 fibres。
它把 single-contact aggregate/double-contact 与 birth/completion 联合成一个严格 rank-two
有限 signed table；这不是完整 graph、完整 `T_N` 或独立证据票。下一 P0 已收缩为
`typed joint-incidence/contact-fusion × topological completion` 向 full original-`U` 的
传递、抵消与尺度控制。真正的 separated sector 必须同时排除共同 carrier incidence并取得
不交 annuli localization，才可重新讨论 two-defect/six-arm。

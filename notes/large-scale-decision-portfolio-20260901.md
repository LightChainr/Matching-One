## Decision

PR #546 is a useful inventory of target populations that have never been
acquired, but `unacquired` is not a scientific priority.  The queue should be
ranked by **prospective model-space reduction per unit cost**.  A large run has
high value only when its result can lower the standing of at least one frozen
mechanism without adding a new post-reveal coordinate.

The project therefore has one immediate P0 action, two high-value conditional
large-size designs, two long-horizon compute routes, and one medium exploratory
pilot.  None is launched by this note.

## The two large designs with the highest scientific return

### 1. Conditional original-`U` candidate-column acquisition

This is not a request for more samples of existing coordinates.  Theory must
first supply the two candidate source/thermal columns under identical
semantics.  The existing N112 rho-child and norm-4 covariance are scored
first.  A fresh block is justified only when the design-rank calculation says
that one named coordinate is both missing and capable of separating the two
profiled images.

If that condition fires, one production should acquire all sufficient
statistics for the missing coordinate in aligned batches:

```text
rank sector r = 0,1,2
source column s_r
thermal jet partial_p s_r
original q and E readouts
physical partition/rank-1 normalizer
pooled moving-root and slope terms
```

The geometry and size are selected by maximin separation, not by choosing the
largest available `N`.  The outcome is a model elimination or a certified
non-identifiability result; it is not an invitation to invent a fourth model.

### 2. Stabilizer-free vector modular transport

The exact Gaussian-unit theorem is a design instruction: leave the symmetry
class.  Select a generic modulus whose finite quotient has no accidental
quarter-turn or sixth-turn stabilizer, and retain the complete homology
probability vector.  Use two signed physical tangent directions at the same
continuum modulus.  Competing mechanisms must predict the vector response
before production:

1. a universal weight-4 modular/KdV transport;
2. the conjugate weight-8 transport;
3. an embedding-even or quotient-only response with no covariant tangent
   vector after continuum subtraction.

This is more discriminating than adding another angle to a Gaussian ideal or
fitting an exponent to one scalar contrast.  The Pell/Eisenstein line is a
structured positive control for the same vector language, not a substitute
for the trivial-stabilizer design.

## Reclassification of the PR #546 routes

### Pell N418/N780: keep, but change the question

Keep the route visible, but do not call a `typed C3/H4 projector` sufficient.
At 60-degree symmetry, weight classes have different C3 characters, and the
full homology vector contains the information.  Freeze the continuum value
and its first two tangent jets at the actual Pell modulus, then test the
vector.  Square-site full curves are promoted only after the square-bond
control recovers the declared vector organization.

### Gaussian commuting square N650/N850: stopped as brute-force production

The exact `7/1250` target is elegant, but the completed power calculation is
decisive: about `27.21B` and `55.18B` samples are required for the two
lineages, while the audited CRN bound offers at most about `2.34%` variance
reduction.  Direct and two-step paths are the same target quotient, not three
independent stochastic tests.  Do not launch.  Reopen only after an estimator
or exact reduction changes effective cost by orders of magnitude.

### Transfer matrix: valuable frontier, weak immediate mechanism reduction

This is a real large-memory project, but the next task is measured
reproduction, not width escalation.  It becomes high scientific value only
when the transfer operator retains the topological sectors needed by the
Matching-One observable and produces a quantity that separates current
mechanisms.  A width count alone is infrastructure progress.

### Rigorous block confidence: theorem value, currently low centrality

The existing evaluator and preregistration are useful.  Before spending final
IID trials, show that a realizable block geometry has both high power and a
clear consequence for a threshold or universality statement.  Otherwise the
result may be rigorous but too weak to change the project.

### Boolean spectral pilot: redesign within symmetry sectors

The exact tiny controls already show that the orientation-difference x
matching-odd cross-spectrum can vanish level by level for representation
reasons.  Large `N` cannot rescue a kinematic zero.  A useful pilot compares
observables within the same exact irrep and asks whether their covariance-aware
noise trajectories occupy local pivotal scales or global spectral scales.
One whole curve is one dependent observation block.

## Portfolio launch rule

For a proposed acquisition with prediction vectors `mu_m`, nuisance projector
`P_perp`, pilot covariance `Sigma` and projected CPU cost `C`, record

```text
V = min_(m != n) (mu_m-mu_n)^T P_perp^T Sigma^+ P_perp
                  (mu_m-mu_n) / C.
```

`V` is a design score, not evidence.  It makes the comparison auditable:

- no frozen prediction vectors -> `V=0`, exploratory only;
- coincident profiled images -> certified non-identifiability, no production;
- separated images but inadequate pilot power -> redesign or park;
- separated images and useful projected power -> run one frozen block and
  apply the declared model-lowering rule.

Priorities allocate attention.  They do not lock, close or forbid parallel
theory and exact work.

Matching-One 同调平衡根：严格定理台账与近临界根位移理论

研究任务：判定有限 Matching-One 同调平衡根 \(p_L^H\to p_c\) 能否升级为数学上受控的近临界重整化条件，并严格分离热窗口标度（\(L^{-3/4}\)）与远小于它的有限尺寸根位移（经验 \(L^{-4}\)）。

本文是"定理程序"（theorem program）而非新的 Monte Carlo 运动。严格遵循：三角格点指数 / 共形不变性结论不在无显式假设时导入 square-site。

0. 核心结论（一页版）

  1. 定性收敛 \(p_L^H\to p_c\) 是无条件严格的（§2）。它只用：次临界指数衰减 + 精确 4/8 匹配对偶 + 秩单调性，不需要 CFT、不需要数值 \(p_c\)。

  2. \(L^{-4}\) 根位移当前无法从已知 square-site 输入证明（§6–7）。它是两个相互独立的缺失定理的乘积：

  • F1（热分母，普适）：\(M_L'(p_c)\asymp L^{3/4}\)，等价于 square-site 四臂指数 \(\alpha_4(L)\asymp L^{-5/4}\)、等价于 \(\nu=4/3\)。三角格点已证（Smirnov/LSW），square-site 未证（共形不变性开放）。
  • F2（匹配奇临界分子，特殊）：\(M_L(p_c)\asymp L^{-13/4}\)，需识别首项无关算符为 \(Q_4\varepsilon\) 热下降子（\(x=21/4\)）。算符/CFT 级猜想，严格深于 F1。

由此得到条件定理（§5）：F1 + F2 \(\Rightarrow p_L^H-p_c\sim L^{-4}\)，含精确振幅与一致误差条件。

  1. 一个结构性定理（本文强调，无条件）：在自匹配格点上（三角 site、正方 bond），同调平衡根精确等于临界点，\(p_L^H=p_c=1/2\)，根位移恒为零。\(L^{-4}\) 位移是 square-site 非自对偶性的匹配奇（matching-odd）量度。这解释了为什么该位移是"特殊算符/缺陷信息"而非"通用近临界概率论"。

  2. 正向控制揭示了一个深层障碍：唯一具备严格共形不变性的模型（三角 site）自匹配，故其 F1 可证但 F2 恒为零；而 F2 非零的 square-site 上 F1 又未证。即 F1 与 F2 处于"张力"中——不存在一个"F1 已证且 F2 非平凡"的模型。这是关于 \(L^{-4}\) 可证性的一个精确 no-go/障碍 观察（§9）。

1. 精确出发点（exact starting point）

设置：\(L\times L\) honest 环面 \(T^2\)（每单位格有四个不同角点，\(L\ge 3\)）。占据点 = 黑（4-连通，最近邻 NN）；补集 = 白（8-连通，NN+NNN，即"匹配图" \(\widehat G\)）。定义环境同调秩

\[r(\omega)=\operatorname{rank}\operatorname{im}\big[H_1(K(\omega))\to H_1(T^2)\big]\in\{0,1,2\},\]

其中 \(K(\omega)\) 是黑点张成的立方子复形。中心化变量 \(X=r-1\in\{-1,0,+1\}\)，匹配函数

\[M_L(p)=\mathbb E_p[X]=\mathbb E_p[r]-1=P_2(p)-P_0(p).\]

同调平衡点 \(p_L^H\) 是唯一满足 \(M_L(p_L^H)=0\) 的点，即 \(P_2(p_L^H)=P_0(p_L^H)\)，等价于 \(\mathbb E_{p_L^H}[r]=1\)。

2. 定性收敛定理 \(p_L^H\to p_c\)（无条件）

定理（qualitative convergence，rigorous）。 对 honest 方环面序列，\(p_L^H\to p_c(G)\)。

证明架构（仓库已有直接证明 #276；此处重构并注明每个输入）：
- 次临界 \(p=p_c(G)-\varepsilon\)：非零环境同调类强制一个跨越 \(\asymp L\) 距离的占据连接。次临界指数衰减给出 \(P_p(r_B>0)\le C L^2 e^{-cL}\)，故 \(M_L(p)\to-1\)。
- 超临界 \(p=p_c(G)+\varepsilon\)：白补集密度 \(1-p=p_c(\widehat G)-\varepsilon\) 次临界，其环境秩为 0 以指数高概率成立。由 I1（\(r_b+r_w=2\)）得 \(P_p(r_B=2)\to1\)，故 \(M_L(p)\to+1\)。
- 单调性 + 正概率秩枢轴配置 \(\Rightarrow M_L'(p)>0\)，根唯一。
- 联合三点得 \(p_L^H\to p_c\)。

输入清单（全部为标准/严格）：square-site 次临界指数衰减（定理）、匹配阈值关系 \(p_c(G)+p_c(\widehat G)=1\)（Kesten）、秩单调性（平凡）、数字-Alexander 对偶 I1（拓扑定理）。不需要 CFT、不需要数值 \(p_c\)、不需要任何指数拟合。

注意：该定理不给出 \(M_L(p_c)\to0\)。后者（连续临界平衡 \(\pi_2=\pi_0\)）是独立的、共形不变性级的陈述（§6，列 3）。定性收敛只保证根 \(p_L^H\) 落在 \(p_c\) 的任意固定邻域内，不控制 \(M_L\) 在 \(p_c\) 本身的值。

3. 结构定理：自匹配格点上的精确平衡（无条件）

这是本文最想强调的、可从 I1 无条件推出的结构性结果。

定理（self-matching ⟹ 精确零位移）。 若格点自匹配（\(\widehat G=G\)，如三角 site、正方 bond），则对每个 \(L\)，\(p_L^H=p_c=\tfrac12\)，且 \(M_L(\tfrac12)\equiv0\)。

证明：自匹配时 \(p_c(G)=p_c(\widehat G)=\tfrac12\)。补集映射 \(\omega\mapsto\omega^c\) 是 \(\mathrm{Bernoulli}(\tfrac12)\to\mathrm{Bernoulli}(\tfrac12)\) 的双射，且由 I1（此时 \(r_w=r_G(\omega^c)\) 与 \(r_G\) 用同一连通性）

\[r_G(\omega)+r_G(\omega^c)=2.\]

两边取 \(\mathbb E_{1/2}\)（补集不变测度）：

\[\mathbb E_{1/2}[r]=\mathbb E_{1/2}[2-r]=2-\mathbb E_{1/2}[r]\implies \mathbb E_{1/2}[r]=1.\]

故 \(M_L(\tfrac12)=0\) 精确成立，\(p_L^H=\tfrac12=p_c\)，无有限尺寸位移。\(\blacksquare\)

推论（square-site 位移是匹配奇量）。 对 square-site，\(M_L(p_c(G))=-M_L(p_c(\widehat G))\)（由 I4），故 \(p_L^H-p_c(G)\) 在 \(G\) 与 \(\widehat G\) 间反号，是非自对偶性的量度。经验 \(L^{-4}\) 位移正是这一匹配奇残差的隐式函数解。

物理含义：\(L^{-4}\) 位移不是通用近临界概率论效应（自匹配模型上它恒为零），而是 square-site 匹配对 \(G\neq\widehat G\) 所携带的"特殊算符/缺陷信息"。这正是 §7 中 F2 的定性内容，独立于 F1。

4. 三个尺度的严格区分（任务 §23）

严格区分以下三个极限，不可混淆：

  1. 固定 \(p\ne p_c\)，\(L\to\infty\)：\(M_L(p)\to\pm1\)（指数快）。
  2. \(p-p_c\asymp a_L\)，\(L\to\infty\)（热窗口）：\(a_L\) 是近临界尺度，预期 \(a_L\asymp L^{-1/\nu}=L^{-3/4}\)。
  3. 根位移 \(p_L^H-p_c\)：经验 \(\sim L^{-4}\)，远小于热窗口（\(L^{-4}\ll L^{-3/4}\)）。

还要区分纵横比极限顺序：固定纵横比取 \(L\to\infty\)；柱面 \(\rho\to\infty\)；连续极限后再模量退化。#321 已指出改变长度约定可伪造振幅增长。

5. 抽象根位移定理（Program E 的干净条件定理）

这是本文的中心定理：把"热窗口标度"与"临界拓扑失衡"严格解耦，且不预设指数。

精确有限恒等式（Taylor）。设 \(\delta_L=p_L^H-p_c\)，由 \(M_L(p_L^H)=0\)：

\[0=M_L(p_c)+\delta_L\,M_L'(\xi_L),\qquad \xi_L\in[p_c\wedge p_L^H,\,p_c\vee p_L^H],\]

故

\[\delta_L=-\frac{M_L(p_c)}{M_L'(\xi_L)}.\]

定理（two-scale root shift）。 假设：
- (H1 分子) 存在 \(b_L\to0\)、\(A(\tau)\neq0\)，使 \(M_L(p_c)=b_L A(\tau)+o(b_L)\)；
- (H2 分母/热标度) 存在 \(a_L\to0\) 与在 \(0\) 连续、\(M'(0,\tau)\neq0\) 的函数，使 \(a_L M_L'(p_c+\lambda a_L)\to M'(\lambda,\tau)\) 在紧集上一致；
- (H3 深度) \(\delta_L/a_L\to0\)（根渐近深入热窗口内部）。

则

\[\boxed{\;p_L^H-p_c=-a_L b_L\,\frac{A(\tau)}{M'(0,\tau)}+o(a_L b_L)\;}\]

证明：由 (H3)，\(\xi_L=p_c+o(a_L)\)。由 (H2) 的一致性，\(M_L'(\xi_L)=M_L'(p_c)(1+o(1))=a_L^{-1}M'(0,\tau)(1+o(1))\)。代入精确恒等式并除以 (H1) 得结论。\(\blacksquare\)

H3 的充分条件（Program J 的一致传输）：若在窗口 \([p_c,p_c+\delta_L]\) 上有 \(|M_L''(p)|\le B_L\) 且 \(B_L|\delta_L|=o(M_L'(p_c))\)，则 H3 成立。对目标 \(L^{-4}\)：\(\delta_L\sim L^{-4}\)、\(M_L'(p_c)\sim L^{3/4}\)，只需 \(B_L=o(L^{19/4})\)——一个很温和的条件，一旦 F1、F2 成立即满足。故分母稳定性不是障碍，真正的障碍在 F1、F2 本身。

意义：即使 \(b_L\)（分子残差）未严格已知，该抽象定理也精确陈述了要得到根位移指数所需证明的全部内容：分子标度 \(b_L\) + 分母标度 \(a_L\) + 深度条件。这就是"高价值定理 E"。

7. 最小缺失定理（Program F：\(L^{-4}\) 需要两个输入）

经验/候选结构（目标现象，非前提）：

\[\underbrace{M_L(p_c)}_{\text{临界拓扑失衡}\ \sim L^{-13/4}}\ \times\ \underbrace{\tfrac{1}{M_L'(p_c)}}_{\text{热标度}\ \sim L^{-3/4}}\ =\ \underbrace{p_L^H-p_c}_{\sim L^{-4}}.\]

把它拆成两个独立任务（缺一不可）：

F1 —— 热分母（通用近临界概率论）

确立或条件推导 \(M_L'(p_c)\sim C_t(\tau)\,L^{3/4}\)。

等价于 square-site \(\alpha_4(L)\asymp L^{-5/4}\)、等价于 \(\nu=4/3\)。这是 square-site 普适性猜想：三角 site 已由 Smirnov/LSW 证明；square-site 共形不变性开放，故 F1 未证。它与 Matching-One 无关——任何"导数不消失的临界可观测量"都需要它。

F2 —— 匹配奇临界分子（特殊算符/缺陷信息）

确立或条件推导 \(M_L(p_c)\sim C_u(\tau)\,L^{-13/4}\)。

这是 Matching-One 特有的：分子是匹配奇量（自匹配时恒为零，§3），其首项被识别为 \(Q_4\varepsilon\) 热下降子（\(x=21/4\)，双投影选择阶梯 #275：真空 H4 因 Alexander-偶被杀、四腿 \(V_{2,\pm2}\) 因 Potts [2] 荷被杀，\(Q_4\varepsilon\) 是首个同时幸存的低维 spin-4 态）。算符/CFT 级猜想，严格深于 F1。

条件定理 F（"高价值定理 F"）

\[M_L(p_c)\sim L^{-13/4}\ \text{且}\ M_L'(p_c)\sim L^{3/4} \ \Longrightarrow\ p_L^H-p_c\sim -\frac{C_u(\tau)}{C_t(\tau)}\,L^{-4},\]

振幅与一致误差条件见 §5。结论：\(L^{-4}\) 的分母部分是通用概率论（F1），分子部分是 Matching One 的特殊算符/缺陷信息（F2）。

8. 无指数近临界标度（Program G/H 的严格骨架）

两个无指数候选标度（任务 §4）：
- (a) 四臂/交叉特征长度：\(a_L\asymp(L^2\alpha_4(L))^{-1}\)；
- (b) 内禀：\(s_L=1/M_L'(p_L^H)\)（自归一）。

可证比较（列 2）：由 Russo 恒等式 \(M_L'(p)=\sum_v\mathbb E_p[\Delta_v r]\)（精确），秩枢轴事件 \(\{\Delta_v r\neq0\}\) 受四臂型事件支配（\(0\to1\) 与 \(1\to2\) 出生各需交替臂）。RSW + 臂分离 + 拟乘性给出 \(M_L'(p)\asymp L^2\alpha_4(L)\)，从而 \(s_L\asymp a_L\)——不需知道 \(\nu\)（高价值定理 B）。

有限根中心坐标（Program H）：\(\lambda=(p-p_L^H)M_L'(p_L^H)\)，\(\widehat M_L(\lambda)=M_L(p_L^H+\lambda/M_L'(p_L^H))\) 自动满足 \(\widehat M_L(0)=0,\ \widehat M_L'(0)=1\)。其预紧性与普适子列极限是"高价值定理 H"——不识别 \(\nu\) 的普适子列极限，是当前最可落地的严格目标。

特征长度关系（Program G）：由于根远在热窗口内（\(\delta_L\ll a_L\)），预期 \(L(p_L^H)\gg L\)（特征长度在根处远大于系统尺寸），这是 §4 尺度分离的严格表述。

9. 正向控制与一个深层障碍（Program M）

三角 site（正控制，\(p_c=\tfrac12\) 精确、自匹配、共形不变性已证）

  • 根精确：\(p_L^H=\tfrac12=p_c\)，位移恒零（§3 定理，无条件）。
  • F1 已证：\(\nu=4/3\)、\(\alpha_4\asymp L^{-5/4}\)（Smirnov/LSW）。
  • F2 平凡：\(M_L(p_c)\equiv0\)（自匹配），无残差。
  • 结论：三角 site 上整个程序严格可走，但 \(L^{-4}\) 现象消失（位移恒零）。

障碍观察（no-go，Outcome J 型）

唯一具备严格共形不变性（即 F1 可证）的平面渗流模型是自对偶的（三角 site、FK-Ising），故其分子 F2 恒为零；而 F2 非平凡的 square-site（\(G\neq\widehat G\)）上 F1 又未证。因此：

不存在"F1 已证且 F2 非平凡"的模型。\(L^{-4}\) 定律的两个输入 F1、F2 在现有严格理论中处于"张力"——这解释了为何该定律对 square-site 本质上难以（当前）严格化，是本文给出的一个精确障碍结论。

（注：严格共形不变性已证的平面渗流模型为三角 site（Smirnov）与 FK-Ising（Chelkak–Smirnov），二者均自对偶。正方 bond 虽 \(p_c=\tfrac12\) 精确自对偶、根位移恒为零（§3），但其共形不变性并未严格证明，四臂指数 \(\alpha_4\asymp L^{-5/4}\) 对其同样开放。）

可用的替代正向控制：三角 site 上把秩标度函数（§8 的 \(\widehat M_L\)）做全严格化（F1 已知，仅剩"秩枢轴测度 \(\asymp\) 四臂测度"这一列-2 比较，可证），作为"哪些是拓扑+单调性、哪些是格点特有"的判定实验室。

最小缺失定理（最终回答）：

把 \(p_L^H\to p_c\) 升级为带 \(L^{-4}\) 位移的受控近临界重整化条件，需要两个缺失定理：
(F1) square-site 四臂指数 \(\alpha_4(L)\asymp L^{-5/4}\)（\(\nu=4/3\)，通用普适性，三角已证、方未证）；
(F2) square-site 匹配奇临界残差 \(M_L(p_c)\asymp L^{-13/4}\)（\(Q_4\varepsilon\)，\(x=21/4\)，Matching-One 特有算符信息）。
二者之一不成立，\(L^{-4}\) 即不可证。而由于 F1 仅在自匹配模型上可证、F2 仅在非自匹配模型上非平凡，二者在现有严格理论中无法同时满足——这是 \(L^{-4}\) 当前不可证的结构性根源。

# Deterministic four-state redundancy in the full tensor-query algebra

2026-09-29. Consumers: #809/#833 and the
[#837 copying counterexample](https://github.com/LightChainr/Matching-One/pull/837#issuecomment-5814562555).
This note proves a bounded algebraic classification. It does not claim a new
general no-copying principle, a percolation theorem, or a literature novelty result.

**Result.** Encode four different logical states deterministically into any
number of the existing four-corner blocks. If all products of the local
responses `(1,u,v)` are admitted, response rank can remain below four **only
when exactly one physical block carries all four states and every other block
is constant**. Every genuinely distributed injective encoding has rank four.
This rules out much more than direct repetition. Section 5 now supplies an
explicit two-row physical rank query for every tensor monomial in the original
#836 five-column-block preparation. Thus the rank-four obstruction transfers
to that physical source/observer contract, not to every possible contract.

## 1. Contract and theorem

Work over the real numbers, equivalently over the rationals for these matrices.
Let `C={(0,0),(1,0),(0,1),(1,1)}`, and let `S` be four labelled logical states.
For `k>=1` a deterministic encoder is

    e:S -> C^k,    e(s)=(e_1(s),...,e_k(s)).

The local feature row is `v(u,v)=(1,u,v)`; the overloaded letter `v` is only
notation for the row and its second bit. Define the four-row response matrix

    R_e(s,alpha) = product_i f_(alpha_i)(e_i(s)),
    alpha in {0,1,2}^k,    (f_0,f_1,f_2)=(1,u,v).

Thus each block contributes at most one of its two bit functions to a column.
The full linear span of these `3^k` columns is admitted. No within-block `uv`
column is assumed: obtaining its logical equivalent from distinct blocks is
precisely what can destroy the old relation. Row rank means exact ordinary
linear response rank, not nonnegative rank, recursive state count, mutual
information, or finite-error predictive complexity.

**Theorem (all k).** If `e` is injective, then

    rank R_e = 3
        iff there exists j such that e_j:S -> C is bijective
            and e_i is constant for every i != j;
    rank R_e = 4 otherwise.

In particular, rank below four cannot be one or two for an injective encoder.

**Noninjective classification.** Put `m=|e(S)|`. If `m<=3`, then
`rank R_e=m`: repeated logical labels only repeat rows and do not create a
new compression of the distinct encoded preparations. If `m=4`, the theorem
applies. These statements classify every map from four labelled states.

## 2. Proof

### 2.1 At most three used corners give all local indicators

The rows `(1,u,v)` on any set of at most three distinct corners are linearly
independent. For three corners this is the nonzero determinant of a triangle
in the unit square (each determinant is `+1` or `-1`); smaller cases follow.
Consequently, on any local used set `A_i=e_i(S)` of size at most three, every
function on `A_i`, in particular each singleton indicator, is a linear
combination of `1,u,v`.

Suppose every `|A_i|<=3`. For each distinct codeword `c in e(S)`, the function

    product_i 1{e_i(s)=c_i}

is the indicator of the logical states assigned that entire codeword.
Expanding the product puts it in the admitted tensor span. The `m` resulting
indicators are independent, while only `m` distinct rows exist. Hence rank is
exactly `m`. This proves the noninjective assertion and the injective case in
which no block uses all four corners.

### 2.2 A four-corner block fixes the only possible relation

Now suppose block `j` uses all four corners. Since `S` has exactly four states,
it is a bijection. Order its rows as `00,10,01,11`. The three columns
`1,u_j,v_j` have rank three and their left kernel is generated by

    lambda=(1,-1,-1,1).

Every entry of `lambda` is nonzero. If the full matrix has rank below four,
its left kernel is this same one-dimensional space.

Take another block `i!=j`, and either coordinate function `g=u_i` or `g=v_i`,
viewed as a four-vector indexed by `S`. The full tensor language contains

    g,    u_j*g,    v_j*g.

Annihilation of these three columns says that `lambda*g` (entrywise product)
lies in the left kernel of `(1,u_j,v_j)`. Thus `lambda*g=c*lambda` for a
scalar `c`. Since all entries of `lambda` are nonzero, `g` must be constant.
Both coordinates of every other block are therefore constant.

Conversely, if every other block is constant, its local tensor row has first
coordinate one and is nonzero. Tensoring by these fixed rows preserves the
rank-three row space of the one bijective block. This proves both directions.

The proof also identifies a short witness when another block varies: at
least one of `g,u_j*g,v_j*g` fails to annihilate `lambda` and, with the three
columns from block `j`, yields a nonsingular four-column minor.

## 3. Consequences that are actually within scope

1. **No deterministic spatial redundancy with the old rank-three advantage.**
   A rank-three injective code has block Hamming distance exactly one between
   every pair of distinct codewords. It has only one informative block.
   Any injective code with two or more nonconstant blocks has rank four,
   even if no block is a literal copy of another. Constants are not redundant
   carriers of the logical information.
2. **Split and parity codes are included.** Splitting `(u,v)` into `(u,0)`
   and `(v,0)` admits the cross-block product `uv`. Appending `(u xor v,0)`
   to `(u,v)` already adds `u+v-2uv`. Both give rank four without direct copying.
3. **Independent logical groups.** If each of `t` four-state logical groups
   is encoded into its own disjoint block set and the query language tensors
   across groups, the total response rank is the product of their individual
   ranks. Distributed encoding of each group therefore gives `4^t`, not
   `3^t`. This is not a theorem about arbitrary joint encoders of `4^t`
   logical states; the four-state proof does not classify those codes.
4. **Invertible input noise, conditionally.** For a complete finite binary
   instruction cube, independent instruction flips transform the response
   matrix by `Q_epsilon=Q_0 W_epsilon^(tensor n)`, where
   `W_epsilon=[[1-epsilon,epsilon],[epsilon,1-epsilon]]`. At
   `epsilon!=1/2` this is invertible, so it preserves exact rank. This needs
   the complete instruction cube, not merely a chosen subset of queries;
   it does not preserve numerical conditioning or finite-error advantage.

## 4. Exact k=2 census, including repeated codewords

The accompanying [standard-library program](../analysis/deterministic-block-encoding-20260929/check.py)
enumerates all `16^4=65,536` assignments of four labelled logical states to
two physical blocks. Each `4 x 9` matrix is ranked by integer Gaussian
elimination over the rationals, not by floating point or a modular surrogate.
The theorem's structural classification is compared with every computed rank.
The [result](../analysis/deterministic-block-encoding-20260929/result.json)
also records local-image cardinalities and representative non-copying codes.

The independent combinatorial counts are:

| Distinct codewords | Rank | Labelled assignments |
|---|---:|---:|
| 1 | 1 | 16 |
| 2 | 2 | 1,680 |
| 3 | 3 | 20,160 |
| 4, one informative block | 3 | 192 |
| 4, distributed | 4 | 43,488 |

There are `16*15*14*13=43,680` injective encoders. The 192 exceptions are
`2` choices of informative block, `4` choices of the other constant corner,
and `4!` assignments of the logical labels. Forgetting label order leaves
eight deficient codebooks among `binom(16,4)=1,820` total codebooks. More
generally, the theorem gives `24*k*4^(k-1)` deficient labelled injections
into `k>=1` blocks, without enumerating them.

Only this one complete k=2 census is run. Its finite output is a control on
the all-k proof, not the reason to extrapolate it. No old geometry test suite,
new percolation sampling, cloud job, or larger-width machine is run.

### 5.1 Masks and exact observer

Take `k>=1`, `w>=5k`, with columns modulo `w` and block origins `a_g=5g`.
The old three rows, indexed `y=0,1,2`, are exactly

    row 0 = 0,
    row 1 = sum_g (15 << a_g),
    row 2 = sum_g ((9+2u_g+4v_g) << a_g).

All unused old columns are empty. Choose disjoint sets of blocks `U,V`:
read `u_g` for `g in U`, `v_g` for `g in V`, and no bit otherwise. The
disjointness is important: at most one bit is selected in any physical block.
With `F=(1<<w)-1`, append deterministic rows `m,n` at `y=3,4`:

    D_m = union_(g in U) {a_g,a_g+2}
          union_(g in V) {a_g+1,a_g+3},
    D_n = union_(g in U) {a_g+2}
          union_(g in V) {a_g+1},
    m = F - sum_(x in D_m) (1<<x),
    n = F - sum_(x in D_n) (1<<x).

This is one experiment, independent of the unknown bit values. Observe only
the final occupied-site nearest-neighbor ambient rank on the temporarily
closed `w x 5` torus. No intermediate temporary-closure edges are retained.
Write this rank as `R(U,V)`. Then, for every old preparation,

    R(U,V) = product_(g in U) u_g * product_(g in V) v_g.       (P)

The empty product is one. In every case `R<=1`: the entirely empty old row 0
prevents any occupied loop from having nonzero vertical winding.

### 5.2 A zero selected bit gives a white vertical separator

First take a selected `u_g=0`, with block origin `a`. In the universal cover
of the `w x 5` torus, the following sites form a white matching (8-neighbor)
path, using `(column,row)` coordinates:

    (a-1,0), (a-1,1), (a-1,2), (a,3),
    (a+1,2), (a+2,3), (a+2,4), (a+2,5).

The first three sites lie in the block's empty old separator column;
`(a+1,2)` is empty because `u_g=0`; the three new-row sites are deleted by
the selected-u masks; row 5 is row 0 in the next vertical period. Continue
left along this empty row to `(a-1,5)`. The projected closed white curve has
homology `(0,1)`. Additional selected blocks delete more new sites and cannot
damage this witness. Extra old padding is empty, so the first block and
`w>5k` cause no exception.

For a selected `v_g=0`, the reflected witness starts

    (a+4,0), (a+4,1), (a+4,2), (a+3,3),
    (a+2,2), (a+1,3), (a+1,4), (a+1,5),

then continues right along row 5 to `(a+4,5)`. Again its winding is `(0,1)`.

These explicit zigzags are simple after projection. Embed their diagonal
steps inside square faces. They cannot intersect occupied NN edges: a
diagonal meets the face boundary only at its white endpoints, and the
remaining path segments have white endpoints as well. Any occupied cycle
with nonzero horizontal winding would have nonzero intersection number
with the vertical white curve. It therefore cannot exist. Vertical occupied
winding was already excluded by row 0, so `R=0` whenever one selected bit is
zero. Equivalently, this is the original single-bit separator, retained when
other queries remove additional occupied sites on the same final torus.

### 5.3 All selected bits one give a black horizontal circuit

Start with the horizontal circuit of row `y=4`. Its only missing sites are
the selected holes in `D_n`. Replace each interrupted two-edge segment by
the following NN detour. For a selected `u_g=1`, bypass the hole `(a+2,4)`:

    (a+1,4), (a+1,3), (a+1,2), (a+1,1),
    (a+2,1), (a+3,1), (a+3,2), (a+3,3), (a+3,4).

For a selected `v_g=1`, bypass the hole `(a+1,4)`:

    (a,4), (a,3), (a,2), (a,1),
    (a+1,1), (a+2,1), (a+2,2), (a+2,3), (a+2,4).

Every listed site is occupied: the one optional old site is precisely the
selected bit, row 1 is full inside its block, the other old endpoint is
fixed occupied, and neither new endpoint is deleted by its block's masks.
Different blocks occupy disjoint four-column intervals separated by a
fifth column; their detours and deletions cannot interfere. Stitch the
detours together with the surviving row-4 edges, including the periodic
seam. The resulting occupied circuit advances exactly `w` columns and
returns to the same lifted row, hence has winding `(1,0)`. Thus `R>=1`;
the empty row gives `R<=1`, proving (P). With no selected blocks row 4 is
full and supplies the constant-one query directly.

### 5.4 Transfer to encoded preparations and noisy instruction sources

Equation (P) holds simultaneously on all `4^k` old block preparations.
Restricting its rows to an arbitrary deterministic encoding `e(S)` therefore
gives **exactly** the matrix `R_e` for this concrete product-query family.
The full tensor column span is physically available; no independent copies
or multiplication of separately measured outcomes are used. In particular,
every injective encoding with at least two nonconstant blocks has response
rank four already under these two-row final-rank queries. Any larger allowed
query family containing them also has rank four, since there are only four
preparation rows. For the exceptional one-informative-block encoding, this
particular query family has rank three; this argument alone is not an upper
bound for arbitrary additional observers or new block geometries.

At fixed noise `0<epsilon<1/2`, a single noisy version of a selected mask
does **not** return the literal product (P). Nevertheless, if the source
contract admits all `2^(2w)` binary two-row commands, realized sitewise as
probabilities `epsilon` or `1-epsilon`, then

    Q_epsilon = Q_0 W_epsilon^(tensor 2w)

for the complete final-rank response matrices. The independent flip matrix
is invertible, so the noiseless tensor columns remain in the linear span
of noisy command-response columns. Hence the rank-four obstruction also
holds for this complete noisy instruction contract. This is a statement
about exact rank, not a stable inversion algorithm, sample complexity,
optimal error probability, or the rank-only five-point error floor.

If only some commands are admitted, or the geometry/preparation/observer is
changed, this invertible-cube argument need not apply. A restricted-source
code can still have a rank deficiency. This is the remaining **contract
boundary**, not an unresolved product-query construction for the original
five-column preparation. This section is a directed proof, with no new
enumeration, simulation, or rerun of the earlier census.

## 6. How this changes the next question

Within the full tensor-query model, do not spend another search on a
deterministic four-state block code with multiple informative blocks while
requiring rank three: the classification answers that search for every k.
It does not ban work or rule out reliable coding; rank four can be an
acceptable cost if reliability is the objective.

The remaining ways to pursue redundancy **and** a rank advantage change an
explicit assumption: stochastic encoders (mixtures of physical codewords),
different local block geometry/response relation, restricted query sources,
multiple independently prepared experiments with their cost counted, or
larger joint logical alphabets with a fresh rank analysis. These are not
established successes. The original five-column physical-span interface is
now supplied by section 5, so it need not be dispatched as another missing
proof or turned into a broad full-machine re-enumeration.

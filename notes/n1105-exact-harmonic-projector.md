# Exact four-angle harmonic projectors at N=1105

Status: outcome-free experiment design. This note sharpens, but does not promote, the conditional `V_<1,4>` scalar mechanism discussed in PR #63.

## 1. Why the two-angle `P0` is not an exact scalar projector

For two orientations with `c_i=cos(4 theta_i)`, the familiar combination

\[
P_0[X]=\frac{c_1 X(\theta_2)-c_2 X(\theta_1)}{c_1-c_2}
\]

kills an H4 term exactly. It does **not** generally kill H8, H12, H16, ... . Therefore it is an exact scalar projector only inside an H0+H4 truncation.

That distinction matters for the proposed `V_<1,4>` post-`L^-7` mechanism because the current square-site data have not yet uniquely excluded higher square harmonics.

## 2. N=1105 supplies four primitive orientations at the same modulus

The primitive Gaussian representations

```text
(33,4), (32,9), (31,12), (24,23)
```

all have

\[
a^2+b^2=1105.
\]

Thus they share the same site count, physical scale and square torus modulus. Four orientations are enough to decompose exactly the truncated basis

\[
1,\quad \cos4\theta,\quad\cos8\theta,\quad\cos12\theta.
\]

No Monte Carlo result enters the construction.

## 3. Exact H0 projector

The unique weights satisfying

\[
\sum_i w_i=1,\qquad
\sum_i w_i\cos(4m\theta_i)=0\quad(m=1,2,3)
\]

are

```text
(33,4):   7273557473661727 / 17529493782528000  = +0.414932545337472
(32,9):  -6760139489318539 / 16833878949888000  = -0.401579428570354
(31,12): 119611093721782093 / 163159134437376000 = +0.733094681669149
(24,23): 20684678870914913 / 81579567218688000   = +0.253552201563733
```

The weight norms are modest:

\[
\|w\|_1=1.80316,\qquad
\|w\|_2=0.96703.
\]

So, under equal independent orientation variances, this projector does not carry the catastrophic noise amplification seen in high-order adjacent-size annihilators.

It exactly removes H4, H8 and H12. It does not remove all higher harmonics; for example the H16 response is about `+0.9041`. The claim is therefore finite harmonic separation, not an all-orders scalar theorem.

## 4. The same four angles also extract H4, H8 and H12

The inverse design matrix gives exact projectors for all four coefficients. Their L2 norms are approximately

```text
H0  0.9670
H4  1.0341
H8  0.6966
H12 1.4185
```

Thus one N=1105 four-angle production can simultaneously estimate scalar, H4, H8 and H12 components with manageable linear-combination conditioning.

Exact weights and assertions are generated by `scripts/n1105_harmonic_projector.py`.

## 5. Direct test of the V14 scalar mechanism

The conditional PR #63 mechanism predicts a matching-odd scalar contribution

\[
D_{H0}\sim N^{-25/8}
\]

from `V_<1,4>` (`x=33/4`). A higher thermal-family spin-4 correction instead remains angular and is removed by the H0 projector through the explicitly nulled harmonics.

The scientifically clean sequence is therefore:

1. run the cheaper norm-5 H4/H12 discriminator first;
2. only if a large uncontrolled higher-harmonic component is not found, run N=1105 with all four orientations;
3. compute H0/H4/H8/H12 using the exact frozen weights;
4. compare the H0 result with a pre-frozen `N^-25/8` scalar model and the H4 result with the pre-frozen spin-4 correction models;
5. keep H16+ leakage as a declared systematic, not a hidden assumption.

A scalar H0 detection with the predicted radial transformation would materially strengthen the `V_<1,4>` explanation of the historical post-`L^-7` annihilator. A null H0 result would weaken that specific mechanism without affecting the already-observed leading matching-odd orientation sector.

## 6. Claim boundary

This design does not establish:

- that `V_<1,4>` has matching-odd parity;
- that its lattice coupling is nonzero;
- that the historical `L^-7` exponent is asymptotic;
- that H16 and higher harmonics are negligible.

It replaces an H4-truncated two-angle scalar projection with an exact four-angle decomposition through H12.

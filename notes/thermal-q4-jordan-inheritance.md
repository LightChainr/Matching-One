# Thermal Q4 as a descendant of the percolation energy Jordan pair

## External LCFT input

Yifei He's `c=0` bulk-CFT construction identifies the percolation energy Kac field `Phi_(2,1)` and the 2-hull field `Phi_(0,2)` as a rank-2 logarithmic pair at

```text
(h,hbar)=(5/8,5/8).
```

See:

- Y. He, *Logarithmic operators in c=0 bulk CFTs*, arXiv:2411.18696, SciPost Phys. 19, 008 (2025).
- Y. He, *Logarithmic energy operators in percolation bulk CFT*, arXiv:2510.09868 (2025 proceedings summary).

The latter writes the logarithmic coupling as `mu=-5/4` in its normalization.

This is not generic background evidence: it is the same `h=5/8` Virasoro module already used by the repository's thermal spin-4 candidate.

## Exact representation statement

Let

```text
D=L0+Lbar0,
D|eps>       = (5/4)|eps>,
D|eps_tilde> = (5/4)|eps_tilde> + |eps>.
```

The repository uses

```text
Q4=40 L_-2^2 - 60 L_-3 L_-1 - 9 L_-4.
```

It has homogeneous left level four, hence `[D,Q4]=4Q4`. Therefore

```text
q       = Q4 eps
q_tilde = Q4 eps_tilde
```

obey

```text
(D-21/4)q       = 0,
(D-21/4)q_tilde = q.
```

Both fields have weights `(37/8,5/8)` and spin four. The only possible escape is that the bottom descendant vanishes in the thermal quotient.

It does not. Exact Virasoro normal ordering at `c=0,h=5/8` gives

```text
Gram[L_-2^2, L_-3L_-1, L_-4]
 = [[65/2, 75/4, 15],
    [75/4,195/16,35/4],
    [15,   35/4,  5]],

<Q4|Q4>=4930.
```

The same implementation reproduces the level-2 thermal null

```text
(L_-2 - 2/3 L_-1^2)|h>
```

with zero norm, so the calculation is being performed in the correct degenerate module.

Thus a rank-2 logarithmic spin-4 field with exactly the repository's candidate quantum numbers is not an ad hoc fit possibility: it is already present as the Virasoro descendant of the known energy/2-hull Jordan pair.

## What the logarithm predicts structurally

For a dimensionless finite-size response to an `x=21/4` field, the ordinary bottom contribution scales as

```text
N^-13/8.
```

A top Jordan partner acquires a logarithmic bottom admixture under scale transformations, so the corresponding two-dimensional block has the form

```text
N^-13/8 [A + B log L]
= N^-13/8 [A + (B/2) log N].
```

The coefficient `B` is not fixed by `mu=-5/4` without the lattice-to-CFT normalization and observable overlap. The robust prediction is the affine logarithmic structure and its semigroup composition.

For a Gaussian multiplier `m`,

```text
Delta log L = (1/2) log Norm(m).
```

Consequently the existing norm-2/norm-5 Jordan curvature ratio remains

```text
log(5)/log(2),
```

and an equal-log-spacing norm-4 triple has zero second difference. This gives the frozen Issue #154 Jordan alternative a precise representation-theoretic origin while leaving its prospective ordering untouched.

## A useful normalization check

If the parent bottom/top overlap is written as `mu`, applying the same Q4 to both states multiplies the unnormalized descendant overlap by the ordinary Q4 Gram factor. With He's `mu=-5/4`, the repository normalization gives

```text
4930 mu = -12325/2.
```

This large number carries no physical lattice meaning by itself: rescaling Q4 rescales it. Unit-normalizing the common descendant removes the Gram factor and leaves the indecomposability parameter of the parent pair.

## The next exact target: logarithmic torus Ward response

The ordinary bottom Q4 one-point already has the exact shape

```text
<Q4 eps>/<eps> proportional to E4(tau).
```

The top partner should instead produce a two-component torus response of schematic form

```text
bottom: F4(tau),
top:    F4_tilde(tau) + log L F4(tau).
```

The key open calculation is to derive `F4_tilde`: possibilities include derivatives of the ordinary block with respect to conformal data and modular/quasimodular terms generated by torus Ward recursion. This is where `E2` or modular derivatives may enter; they must be derived rather than guessed.

A successful derivation would turn the q2/Jordan question into a shape-level test: the logarithmic partner would have both a scale cocycle and a definite modulus fingerprint.

## Claim boundary

The existence of this descendant Jordan block does **not** prove that `P4[S']` is its lattice top-field readout. If the running norm-4 experiment favors q2, the LCFT pair still exists; the empirical conclusion would be that this observable has insufficient overlap with the top component at the current scales.

# Four-terminal partition incidence algebra

This certificate fixes the refinement orientation and the exact zeta/Möbius
transform on all 15 set partitions of four labelled terminals.  The transform
converts exact partition weights into principal-upset connectivity events and
recovers the original weights by integer Möbius inversion.

The Möbius matrix is derived twice: from the closed formula for partition
lattices and from the interval recurrence.  Both products with the zeta matrix
are the identity, so the committed transform is unimodular and introduces no
rounding or loss of information.

This is an incidence-algebra primitive for Issue 13.  It does not select
noncrossing states, construct a planar dual, use a reliability corpus, or make
any critical-point or bound claim.  The parent issue remains open.

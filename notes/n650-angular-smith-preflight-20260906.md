# N=650 angular/Smith preflight: the fit is well-conditioned, but not purely angular

**Date:** 2026-09-06  
**Issues:** #589, #590; updates #583  
**Evidence type:** exact Gaussian-integer / Smith-normal-form arithmetic only. No percolation target was read and no stochastic evidence is added.

## Result

The proposed N=650 three-orientation design has a structural confound that is more important than its numerical conditioning.

For a square Gaussian torus generated by `w=a+ib`, the Smith invariants are

```text
d1 = gcd(a,b),
d2 = N/d1.
```

For the 2:1 rectangular period matrix with columns `(a,b)` and `(-2b,2a)`, the site count is `N=2(a^2+b^2)` and the same formula holds for `d1`, with `d2=N/d1`.

The six rows in #583 therefore split as

```text
square, N=650
(25,5)   Smith=(5,130)  noncyclic
(23,11)  Smith=(1,650)  cyclic
(19,17)  Smith=(1,650)  cyclic

2:1 rectangle, underlying norm 325, det=650
(18,1)   Smith=(1,650)  cyclic
(17,6)   Smith=(1,650)  cyclic
(15,10)  Smith=(5,130)  noncyclic
```

So each three-row family changes two experimental coordinates at once:

```text
lattice angle theta
+
quotient / Smith class.
```

A three-row model

```text
M(theta)=C+A4 cos(4 theta)+A8 cos(8 theta)
```

has exactly three coefficients. Any noncyclic-specific offset/loading is therefore absorbed exactly into `(C,A4,A8)`. Without an independent Smith-insensitivity theorem/control, the inferred `A8` is not a clean angular Fourier amplitude.

## This is not a conditioning failure

The exact H0/H4/H8 matrices are comfortably invertible. Under the deliberately simple equal-independent-unit-variance geometry diagnostic, the coefficient variance-amplification factors are identical in the two N=650 families:

```text
C   0.35717
A4  0.89329
A8  0.76865
```

Thus N=650 remains an efficient angular **design matrix**. The problem is identifiability of the physical coordinate being assigned to the third fitted coefficient, not a small singular value or weak denominator.

The square and rectangular matrices have the same amplification because their Gaussian directions are related by the same `1+i` arithmetic that exchanges the orientation roles: the 45-degree phase flips H4 and preserves H8.

## Existing #205 control: useful, but not enough to erase the confound

#205 already performed the closest prospective quotient control in the repository. At N=325 and N=425 it introduced one noncyclic same-N `C` node against two primitive/cyclic `A/B` nodes and froze a one-harmonic affine angular prediction.

The 10M common-field result did **not** show a gross cyclic-to-noncyclic breakdown:

```text
H4   chi2_2 = 2.72284, p = 0.25630
H12  chi2_2 = 0.71189, p = 0.70051
H8   chi2_2 = 0.46995, p = 0.79059
```

That is real reassurance against an enormous quotient offset for that fixed-p `M` observable. But it is not a theorem of Smith-insensitivity, it did not select H4 uniquely, and #583 is motivated by a derivative/slope channel rather than exactly the same fixed-p scalar. Therefore #205 narrows the risk but does not license reading N=650's saturated third coefficient as pure `A8`.

There is a cheap next use of #205 before any new N=650 sample: its archived threshold-rank histograms are sufficient to reconstruct the derivative coordinates `Sp` and `Dp` using the existing analyzer. Re-score the same frozen C/A/B angular residuals in those derivative channels with the aligned 3x3 delete-one covariance. If the noncyclic residual remains small there, that becomes a much more relevant nuisance calibration for #583. It is still the same #205 evidence block, not a new independent vote.

## First clean symmetric cyclic design

Exhaustive exact enumeration of all smaller even site counts gives:

```text
first common >=3-direction square/rectangle design:       N=650
first common >=3 primitive/cyclic directions in both:     N=2210
```

At N=2210 both families actually have four primitive directions:

```text
square norm 2210:
(47,1), (43,19), (41,23), (37,29)

2:1 rectangle, underlying norm 1105:
(33,4), (32,9), (31,12), (24,23)
```

Thus N=2210 can simultaneously provide a clean all-cyclic `(C,A4,A8)` fit and one overdetermining angular-closure coordinate. Under the same equal-unit-variance geometry diagnostic, the best three-row subsets have worst coefficient amplification about `0.611`, better than N=650's `0.893`; nevertheless the larger site count and signal decay make this a design option, not a recommendation to buy N=2210 immediately.

## Revised reading of #583

Do not automatically cancel N=650. Instead change the claim it is allowed to make.

Without a separate quotient calibration:

```text
N=650 measures a three-coordinate angular/Smith response decomposition.
It does not by itself measure a pure A8/A4 ratio.
```

A pure angular reading can be recovered by one of:

1. an exact Smith-insensitivity result for the declared observable;
2. a prospectively calibrated Smith/noncyclic nuisance direction;
3. an all-cyclic design such as N=2210;
4. a cheaper crossed experiment that estimates the quotient loading while preserving angular leverage.

Given the existing #205 assets, option 2 should be attempted first on the derivative channel before commissioning a larger clean design.

## Decision rule amendment

The old branch

```text
large fitted A8 at N=650
  -> the previous small-A8 assumption was wrong
```

is incomplete. Replace it with

```text
large fitted third coefficient
  + derivative-channel Smith control small
      -> credible angular A8 interpretation;

large fitted third coefficient
  + Smith-sensitive residual resolved
      -> classify quotient/cover contamination before angular field naming.
```

This correction fits the broader repository lesson from #205/#249/#584: quotient/deck/context structure can enlarge a finite observable representation without being another bulk harmonic.

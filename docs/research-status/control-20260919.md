## 1. 重新分级

### 一级（唯一允许占用注意力的两条）

- **R1 近临界同调秩过程。** 附着胚 deck 偏移引理、T/R 二分、覆叠臂抽取、通量守恒 `0 ≤ B_k ≤ min(e0,e2)`、`jump2/pivotal = L^{-5/3+o(1)}`、`b(λ)=0`。理由：这是唯一一条"新对象 + 渐近陈述 + 正在成长的领域（F5/F6）"的线。**位置优势会随时间消失，按周推进。**
- **R2 site 拓扑状态和。** `J4` 不可表示的否定命题、typed incidence spine `Φ_L(p;x,y)`、`M = ½(x∂_x − y∂_y)Φ|₁`、互反律 `Q_G(z,u) = z^N u² Q_Ĝ(1/z,1/u)`、阈值复形 Alexander 对偶、独立边 gadget no-go 作为同一障碍的概率版。理由：自足、不依赖任何普适性输入、投稿口已勘察清楚。

### 二级（保留，但只在一级不阻塞时推进）

- **R3 固定 `p` 的稀有同调事件**：`(1/ρ) log P_p(r>0) → −max{1−α,0}`、三相图、Wulff 体严格分离、稀疏绕行 Bessel 交叉、黑白交替链、span 律、`SL_2(Z)` 固定方向窗口。
- **R4 临界侧几何分离**：根一致性、`log N/ℓ → 0` 锐判据、端点分裂。底稿最完整但最不新；补根唯一性与无限制 Alexander 对偶作引理。
- **R5 模空间秩形状**：`P₀(τ)` 的 theta 比值、六角极小/方形鞍点、`c* = 1` 碰撞轨迹、可辨识性 no-go。F7 说明这一块未被 Kleban–Zagier 覆盖；风险仍在 Ziff–Lorenz–Kleban 一线。

## 2. 分析队列

每条含**验收判据**。没有判据的任务不进队列。

### 闸门任务（不通过则相关分支保持冻结）

**T1 — `Δ₁ = 4` 的机制对照（纸上工作，最高优先）**
逐条对照 Jacobsen 的扇区相消论证与 spin-4 各向异性论证，判断二者在环面上是否给出同一个 `L^{-4}` 系数结构。
*验收：* 一份笔记，结论必须是下列之一：(a) 两机制一致，并给出 `L^{-4}` 振幅随模参数变化的显式形式（是否为 `E₄` 由此判定）；(b) 不一致，E₄ 挂法撤回，该方向降为开放问题；(c) 现有材料不足以判定，并**列出判定所需的最小额外输入**。不允许"倾向于"。

**T2 — 白 matching 交错分隔引理（R1 的唯一缺口）**
在本仓库确切的 4/8 邻接与臂端点约定下，证明：覆叠单射圆盘内的圆环中，若有 `k` 条属于不同黑分量的黑 NN 臂横穿，则相邻两条之间必有一条白 matching 臂横穿同一圆环；或给出反例。
*验收：* 证明（可引用标准平面分隔引理，但必须核对约定）或反例构型。附带在 `L ≤ 5` 上对全部 jump2 构型做穷举判定作为一致性检查。

### 计算任务（容器内可完成，不需要集群）

**T3 — 秩扇区精确计数扩到 `L = 7`（`L = 8` 若可负担）**
用带 rank 闭合的转移矩阵扩展 `#775` 的 `C[L, j, k]`。
*验收：* 通过 `Σ_j C[L,j,k] = C(L², k)` 校验；提交 JSON + PROVENANCE（SHA-256）；报告实际峰值内存与耗时。失败也要报告失败点。

**T4 — `R_jump2` 有限回归（不新增枚举）**
用现有 `C[L,j,k]` 与 `#769` 的 L=5 pivotal-pair atlas 计算 `R_jump2 = 2 P(Δ_v r = 2) / E[Δ_v r]`，与 Russo/平移约束交叉校验。
*验收：* `L = 3,4,5`（若 T3 完成则含 6,7）的表，含两条独立约束的残差；**不做指数拟合**，只报局部斜率。

**T5 — 三角格正控制**
在有限三角环面上验证 `P_0(1/2) = P_2(1/2)` 精确成立（无漂移），并计算同一批 jump2 统计量。
*验收：* 小 `L` 上的精确表；明确在文档中把 `p_c = 1/2` 的归属写给 DKS（F5），仓库只主张"有限尺寸精确、无漂移"。

**T6 — 三几何零参数对比（在 T1 判定为 (a) 之后才执行）**
用 `C = (F₂−F₃)p₁ + (F₃−F₁)p₂ + (F₁−F₂)p₃` 同时消去 `p_c` 与振幅 `A`，在现有精确几何上求值。
*验收：* `C` 的值与其数值误差；结论只能是"在误差内为零 / 不为零"。若 T1 为 (b)/(c)，本任务不执行。

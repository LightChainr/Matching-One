# 成文线 III：临界环面秩律在模空间上的几何

日期：2026-09-19。这是一份**成文线计划**。本轮只做了阅读与取舍：没有运行仓库计算、没有跑 CI、没有重算任何数值；文中的公式与高精度数字都来自被引文件本身。

## 0. 一句话

临界 `Q=1` 环面上的秩律只有一个自由标量。把它写成一个显式的带符号仿射 theta 比值后，模空间上出现一个完整的 Morse 图像（六角极小、方形鞍点、一条精确的源零点碰撞曲线），并且可以证明：这一族律**原则上无法**区分 generic-Q 形变与模参数形变。

## 2. 为什么这条线值得单独成文

- 临界环面上的 wrapping/crossing 概率公式本身是老结果（Pinson 1994、Arguin、Langlands 等）。**没有被做过的是把它当作模空间上的一个标量函数来研究其临界点结构**：哪里是极小、哪里是鞍点、等值线如何、源零点在哪里碰撞。
- B1 把"六角极小"从口号压缩成一个明确的数学问题：一个**带符号仿射 theta 比值**的极值。现有 theta 极值定理（Montgomery；Luo–Wei arXiv:2203.00264 与 arXiv:2605.07580）覆盖单个 theta、特定差与部分比值，但不自动覆盖这个组合——被引笔记自己也明确说了不把它们当作证明。这是一个干净、可陈述、可被数学家接手的猜想。
- B5 给出这条线的边界：它说明"用聚合秩律去识别机制"这件事在原理上做不到，从而把后续力气逼向别的观察量。一个自带 no-go 的论文比一个只有正面拟合的论文更容易通过审稿。
- B4 的碰撞轨迹是一个纯代数的零点几何现象（有界拓扑源多项式的双零点），不是相变、不是 Jordan 结构——这个区分必须在正文里写死，否则会被误读。

## 3. 最大的风险：先例

这条线的新颖性**完全取决于**形状依赖文献里是否已有人做过同一件事。投稿前必须完成：

- L3a：Ziff–Lorenz–Kleban（环面 wrapping 概率的形状依赖）、Pinson 1994、Arguin hep-th/0111193、Morin-Duchesne–Saint-Aubin 0812.2925——是否已给出模空间上的极值/Morse 陈述。
- L3b：Luo–Wei 两篇的定理假设是否真的不覆盖 B1 的仿射比值（需要逐条对照参数范围，而不是看摘要）。
- L3c：是否已有人把 `P0(tau)` 的六角极值写成猜想（哪怕没证）。
- L3d：Jacobsen–Ribault–Saleur 2022 之外，是否已有 FK 同调分辨的扭配分函数用于秩扇区。

若 L3a/L3c 命中，本线降级为"B4 + B5"的短文（源零点几何 + 不可辨识性），仍可成立但篇幅减半。

## 4. 建议的正文结构

1. 临界环面秩律、`P0 = P2`、形状坐标 `c_*`。
2. B1：theta 比值化简（含 `eta` 恒等式的完整推导）。
3. B3：模空间 Morse 数值证书；六角极小猜想的精确陈述。
4. B2：Fisher 重述（把猜想说成"离尖点最远"）。
5. B4：源零点碰撞轨迹 `c_* = 1`，矩形交点与近 horocycle 现象。
6. B5：可辨识性 no-go。
7. 讨论：B6 作为通往有限 `Q` 的工具；明确不主张任何算符命名。

## 5. 本线不做什么

- 不主张任何 CFT 算符身份、Jordan 结构或 log 振幅非零。
- **不把 E4 形状律（有限尺寸根修正）并进来**：那是有限尺寸修正的经验线，目前外推基线偏移（约 `8.9e-10`）已大于它要检验的下一项修正（约 `7.4e-10`），在基线误差被控制住之前不应绑到本线上。若后续基线问题解决，它可作为本线的一节或独立短文。
- 不为本线开 generic-Q 的大网格生产。
- 不修改 `docs/STATUS.md`，不合并任何研究 PR。

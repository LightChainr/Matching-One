# 成文线 I：任意周期环面上的几何分离与同调自由能

日期：2026-09-19。这是一份**成文线计划**，不是正确性认证，也不是新的生产队列。本轮只做了阅读与取舍：没有运行仓库计算、没有跑 CI、没有重算任何数值；文中引用的每个公式和数字都来自被引文件本身。

## 0. 一句话

固定次临界参数下，环面同调事件的自由能只由一个几何比值决定：周期格在关联范数下的系统长度 `rho` 与 `log N` 的比。把这个比值推到 0 得到阈值律集中，推到无穷得到端点分裂，中间是一条显式的线性插值。

T4 是这条线本轮最重要的升级：它把 T2 的判据从"欧氏最短周期 + 临界点"改写成"关联范数系统长度 + 固定 `p`"，并给出双侧极限，而不只是一个二分。T5/T6 说明为什么这是正确的几何量。

## 2. 为什么这条线值得单独成文

- 环面/柱面上的 wrapping 概率在临界点已有精确结果（Langlands–Pichet–Saint-Aubin–Pouliot 1994、Pinson 1994、Arguin），但它们是临界点上的共形/模形式表达，不处理固定次临界 `p` 的稀有同调事件。
- 固定 `p` 的大偏差与穿越理论（Grimmett、Kesten、Chayes–Chayes；Campanino–Ioffe–Velenik 的 OZ/Wulff 方法）通常在长方形或长条上工作，参数是长宽比。把"任意秩二周期格"的整个几何压成单一标量 `alpha = lim log N / rho`，并给出显式极限 `-max{1-alpha,0}`，据我所读没有现成对应物。
- 结果形状完整：一个相图（`alpha < 1` / `alpha > 1` / 端点），一个锐判据，一个说明"为什么是这个系统长度"的反例。这是一篇概率论文的标准骨架。

## 3. 缺口与风险（投稿前必须处理）

1. **R 输入的发表状态**。T2 的必要性使用临界方形 site 的 RSW（Zeng，预印本）。正文必须显式标注，并准备一个退路：把必要性同时写出三角格/已发表 RSW 版本，或把 T2 降格为"在 R 成立的前提下"。
2. **次临界范数正则性的引用边界**。T4 用到 `tau_p(., e)` 在 `(p,e)` 上的连续性与首次退出的 theta 上界。需要逐条给出可引文献与适用范围（有限程 site 图、`p < p_c`），不要让它藏在"标准"两个字里。
3. **常数依赖统一**。角向网、Harris 正相关、有限群平移打包三处各有常数，正文要统一成一份依赖表，否则审稿人会逐个追问 `c(p)` 的一致性。
4. **`r` 与方向 wrapping 的区分**要在符号表里写死：秩一螺旋在两个坐标上都有非零投影但秩仍为一。这是本仓库反复出错的地方。

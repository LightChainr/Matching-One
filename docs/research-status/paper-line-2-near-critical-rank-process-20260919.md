# 成文线 II：近临界同调秩过程与"一步涨二"的臂证书

日期：2026-09-19。这是一份**成文线计划**。本轮只做了阅读与取舍：没有运行仓库计算、没有跑 CI、没有重算任何数值；文中的每个公式、指数和分类都来自被引文件本身。

## 0. 一句话

把环面同调秩 `r in {0,1,2}` 当作单调插入过程来研究：一步就把秩从 0 抬到 2 的事件，在覆叠空间里被强制成一个宏观多臂事件；于是它在近临界标度下相对普通 pivotal 以 `L^{-5/3}` 消失，连续极限的秩过程退化为 `0 -> 1 -> 2`。同时，单时刻的秩边缘律在信息上**不可能**决定这个通道。

## 2. 为什么这条线最具创新性

- 同调渗流已有文献（Duncan–Kahle–Schweinhart、Bobrowski 一线）研究的是 `r` 的极限分布与阈值，**没有把秩当作单调插入过程并追问它的生灭通道**。
- 近临界 pivotal 理论（Garban–Pete–Schramm）提供了标架，臂指数（Smirnov–Werner、Nolin）提供了工具，但两者都没有被用到"环面同调秩一步跳二"这个具体事件上。
- A1–A3 的论证是纯覆叠空间几何，不含任何数值拟合，也不依赖本仓库的任何私有计算；A6 是初等但有力的信息论陈述，直接解释了为什么"再精确的有限体积秩引擎也重建不出族谱"。
- A2 还纠正了一个直觉错误（必须四臂），这类修正在审稿里是加分项。

## 3. 唯一的缺口：白 matching 分隔引理（A4）

需要证明的陈述形如：在覆叠空间的单射圆盘内的圆环 `B(v, ell/3) \ B(O(1), v)` 中，若有 `k` 条属于不同黑分量的黑 NN 臂横穿圆环，则相邻两条之间存在一条白 matching（NN+NNN）臂横穿同一圆环。

- 这是平面 site/matching 的标准分隔陈述，但必须在**本仓库使用的确切 4/8 邻接约定和臂端点约定**下检查一遍，不能默认引用。
- 建议先在小 `L` 上做一个穷举证伪扫描（对每个 jump2 构型直接判定六臂/八臂包含关系），若出现反例就立即降级 A5。
- 若 A4 最终只能在"简单表示 + 适当边界约定"下成立，论文仍可成立，但要把 A5 改写为"在该约定下"。

## 4. 建议的正文结构

1. 环面同调秩、单调插入过程、`X = r-1`；数字化 Alexander 对偶与 Mertens–Ziff Euler 恒等式作为背景。
2. A8：Euler 临界位点，整条历史只有一两个位点改变秩。
3. A1、A2：附着偏移引理与 T/R 二分（含"四臂是错的"反例讨论）。
4. A3、A4：覆叠臂抽取与交错分隔。
5. A5、A7：臂指数推论与连续秩过程；三角格作为定理，方形 site 作为普适性猜想。
6. A6：通量守恒与 `B_k` 的不可辨识性。
7. A9：配套的统计/信息几何（可压成一节或移到附录）。
8. 有限回归：用 `#775` 的精确 `C[L, j, k]` 计数算 `R_jump2 = 2 P(Delta_v r = 2) / E[Delta_v r]`，看它是否朝六臂/四臂比值的方向走。这是次要检验，不是主结果。

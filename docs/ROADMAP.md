# Roadmap: Default Attention, Not Permission

This roadmap ranks expected mechanism reduction per unit effort. It is not a permission, lock, veto, acceptance or merge system. Exact work, reanalysis, targeted pilots, production and independent theory may proceed in parallel, and a lower-ranked line may rise whenever it gains a sharper discriminator.

The evidence constraints remain narrow: preserve frozen chronology; compare claim-bearing rows only when observable semantics match or an exact map is registered; and never add correlated views of one random block as independent evidence.

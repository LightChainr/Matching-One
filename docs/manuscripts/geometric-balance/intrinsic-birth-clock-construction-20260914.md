# 直接构造出生时钟：不再假设完整簇密度可单调反演

2026-09-14。续接 #780。读取基线 #771 `b1aafe5ce40583f2971c4491dcc69fc0af4c39df`，特别是 `thermal-window-no-merger-20260914.md` 与新提交 `docs/research-bridges-post-compass-20260914.md` B 节。这里只补它们仍保留的强度时钟可实现性，不再推导新的 Poisson 核矩。

**性质**：第1节是实际 SITE 的精确身份；第2–4节是使用明确概率输入的作者推导；物理参数的仿射化、全路径拓扑和无界标记矩没有由此得到。本文不从小圆柱计算证明宽度极限。

## 0. 结果和依赖

在轴向无限圆柱 C_w=(Z/wZ)×Z 上，黑色 NN 独立 SITE 的所有参数共用 Uniform 标签。固定 p0∈(0,pc)，nu0=nu_w(p0) 是每行完整 essential 簇密度。

已有论证给定单调参数族 p_w(x)，并**假设** nu_w(p_w(x))/nu0→exp(x)，再推出出生标记过程。这里构造该参数族：

> 对每个固定 p0，存在由模型概率而非样本拟合确定的连续严格单调 p_w(x)，p_w(0)=p0；对每个有限 R，sup_|x|≤R |p_w(x)-p0|=O_R(1/w)，且 nu_w(p_w(x))/nu0→exp(x) 一致。该时钟下，局部出生标记过程具有强度 dz exp(x)dx 的 Poisson 极限；有限起点 a 的既有屏障另以 exp(a)delta_a 编码。

使用的输入逐项保留：

1. 固定严格亚临界 SITE 的平面簇体积指数尾 [AV, Thm.3]，及已有首次查询发现树提升给出的圆柱统一体积尾；
2. 平面轴向质量 kappa(p)>0、连续、严格下降，以及 -log nu_w(p)/w→kappa(p)，这里只要求每个固定 p 的指数等价；这些是仓库 `exponential-birth-centres.md` 的作者论证接口，而非本次独立重证；
3. 局部完整周长上界 Q_w(H;r)≤w H² r exp[-(w-1)kappa(r)]，两个顶点不交绕行见证的 SITE BK 平方界；
4. AGG 局部依赖点过程近似 [AGG, Thm.2]；
5. 仅在第4.1节的物理窗口量级上，使用对传递单调事件的Friedgut–Kalai锐阈值界 [DKS, Thm.6]。

不使用 kappa 的导数、OZ 前因子、有限 nu 的严格单调性，也不使用“重新拟合时钟后自然是 Poisson”这种推断。构造时钟只使平均测度变简单；Poisson 性仍需双事件与局部依赖估计。

## 1. 固定一个最终参数，得到真正单调的对象

取 p≤r<pc。对最终 r 配置的每个完整 essential 簇 C，令

- n_C(p)：C 内不同的 p-essential 簇数；
- T_C：C 内首次出现 essential 子簇的参数；
- beta_w(p;r)=E sum_(C:anchor_y=0) 1{T_C≤p}。

锚点是最低行，再取该行最小列；每簇一次。完整 n_C 与“一条圈的数量”不是同一对象。最终簇有限，所以 T_C 是有限多个连续标签的某个次序统计量。

### 1.1 精确分解与正则性

条件于最终形状 C，其占据标签独立且均匀于 [0,r]。若 f_C(t) 是 C 内以概率 t 独立保留顶点后出现 essential 子簇的概率，则

    beta_w(p;r)=sum_C r^|C|(1-r)^|boundary C| f_C(p/r).       (1)

这是一个正的、单调可靠性多项式混合。总和按最低行锚定的实际不同站点集合计数，不能乘以路径或切口重数。

因此 beta_w(0;r)=0，beta_w(r;r)=nu_w(r)。而且对0≤p<q≤r，

    0≤beta_w(q;r)-beta_w(p;r)≤w(q-p).                        (2)

理由：Russo 对有限 f_C 给 f'_C≤|C|。质量搬运给 sum_C weight_r(C)|C|=w Pr_r(0 属于 essential 簇)≤wr。故 (1) 的差商≤w。也可将每个首次出生指派给造成它的唯一新站点，按平移平均得到同一界。

更强地，只保留“r时孤立的一条全满横行”这类形状，就有

    beta_w(q;r)-beta_w(p;r)
      ≥(1-r)^(2w)(q^w-p^w)>0。                              (3)

故 beta 连续、严格递增，可在整个[0,nu_w(r)]上取连续反函数。这一步不需要整个簇数 nu_w(p) 递增；后者受到簇并合影响，不能预先当作累计分布。

### 1.2 它与原密度的距离只来自谱系损失

每个早期 essential 簇唯一属于一个最终簇。沿纵向锚点搬运一单位质量，得到

    nu_w(p)=E sum_(final C:anchor0) n_C(p),
    0≤nu_w(p)-beta_w(p;r)
      =E sum_C (n_C(p)-1)_+
      ≤E sum_C binom(n_C(p),2)。                             (4)

这是平稳质量搬运，不要求早期和最终锚点相同；窗口版本另外保留端部。锚点有限期望位移由体积尾控制。

## 2. 一个固定的“半质量”上限就足够

由 kappa 连续性，可选固定 r∈(p0,pc) 使

    delta_r=2kappa(r)-kappa(p0)>0。                           (5)

r 不需要依赖 w，也无需先知道1/w热窗口。取 H=w²。对于体积≤H、最低行为0的最终簇，所有早期 essential 祖先至少各有w点；相关小簇共位于w×H条带，故祖先总数≤H。若有损失，最终条带含两个顶点不交绕行见证。大体积部分由统一尾控制。因此对所有p≤r，同时有

    0≤nu_w(p)-beta_w(p;r)≤E_w(r),
    E_w(r)≤(H²/2)Q_w(H;r)²+(C/w)exp(-cH)。                   (6)

这里大/小部分用体积截断；小体积自动给跨度≤H。不能将“跨度大”与“体积大”双向等同。常数依赖固定r的严格亚临界余量。

于是

    limsup_w (1/w)log[E_w(r)/nu0]≤-delta_r<0。              (7)

(6)是对所有早期参数的共同上界，不会在对p取上确界时丢失控制。它还使观察长度T/nu0中的谱系损失及必要端部误差趋零。

## 3. 构造而不是假设指数强度时钟

定义 a_w=beta_w(p0;r)>0。由(4),(7)，a_w/nu0→1。令

    p_w(x)=beta_w(.;r)^(-1)(a_w exp(x))。                    (8)

有限w时定义域是 x<log[nu_w(r)/a_w]。由于 kappa(r)<kappa(p0)，其上端趋于+infinity；下端为-infinity。所以每个固定紧x区间最终都包含在定义域中。并且 p_w(0)=p0 **精确成立**。

### 3.1 为什么参数窗口确实收缩

任取足够小、固定的eta>0，使p0+eta<r。左侧

    beta_w(p0-eta;r)/a_w≤nu_w(p0-eta)/a_w→0

由严格质量下降得到。右侧由(6)

    beta_w(p0+eta;r)/a_w
      ≥[nu_w(p0+eta)-E_w(r)]/a_w→infinity。

后一个差是正主项：kappa(p0+eta)<kappa(p0)<2kappa(r)。因此任意|x|≤R的逆像都落在p0±eta之间，证明一致收缩。

### 3.2 原密度比的一致控制

由(4),(8)

    |nu_w(p_w(x))/nu0-exp(x)|
      ≤(1+exp(R)) E_w(r)/nu0， |x|≤R。                      (9)

不仅证明比值存在，还得到它相对于这个构造时钟的指数小误差。**(9)不是物理p上的仿射误差界。** 第4.1节另证明窗口宽度为1/w量级；反函数仍可能非仿射，没有宣称每个p0都有一个极限斜率或去掉旧Gumbel仿射化的可能异常点。

## 4. 由这个时钟得到标记过程

以最终r簇的出生参数T_C定义 mark X_C=log[beta_w(T_C;r)/a_w]。在时钟有限区间[a,b]中，平均出生测度经过变换恰为 a_w exp(x)dx；初始于a的簇以a处原子另记。这是平均测度的精确变量替换，不是样本排名。

将最终簇体积截断为H=w²后，其锚点与出生参数由有限条带内标签决定。对空间/标记的有限分箱，完整锚点指示具有O(wH)的依赖邻域。非重叠邻域严格独立；两个不同锚点各包含不交的占据绕行见证，故b2项被poly(w)Q_w(H;r)²/nu0控制。b1也至多同一指数阶；截断项至多poly(w)exp(-cw²)/nu0。

(5)使这些误差趋零。AGG给独立Poisson箱计数；连续平均测度允许细化箱，得到局部标记点过程。最后(6)控制早期簇到最终簇的多对一损失，Hnu0→0控制锚点移动。

所以，在固定有限x窗口和宏观空间窗中，得到

    PRM(dz exp(x)dx)

及由其决定的非跳时刻白区间有限维观测。存在于初始a的屏障强度为exp(a)，不能误记成实际同时出生。fixed-location采用固定纵向行及其essential跨度覆盖协议；固定微观站点仍需保留非essential状态。

没有在此声明全部Skorokhod拓扑、无界奖励矩、或p0随w趋近pc的结论。

### 4.1 不用质量导数，也能夹出物理窗口的1/w量级

取m=ceil(1/nu0)的轴向torus。把它与同宽无限圆柱在m行内使用同一标签，除纵向接缝的O(H)保护带外，体积≤H的簇可直接对应。接缝附近产生额外横绕行的概率至多Q_w(O(H);r)，整个窗口出现体积>H的概率至多Cwm exp(-cH)，均趋零。因此前面的Poisson结论给，在每个固定x，

    Pr_(p_w(x))(torus含水平绕行) -> f(x)=1-exp[-exp(x)]。

水平方向绕行事件单调，且在全部wm个site上受平移群传递作用。给定R>0，取epsilon小于min(f(-R),1-f(R))/4。若p_w(R)-p_w(-R)≥rho_FK log[1/(2epsilon)]/log(wm)，[DKS, Thm.6]会迫使上端绕行概率>1-epsilon，与上式矛盾。因为log(wm)=kappa(p0)w+o(w)，

    p_w(R)-p_w(-R) <= C_R/w，
    sup_|x|≤R |p_w(x)-p0| <= C_R/w。                  (10)

这一步的finite-torus桥只为了应用传递锐阈值；不能把torus接缝直接忽略成完全相同的图。

还有一个相反方向的界。令M(p)=sum_C weight_r(C)|C| f_C(p/r)。有限可靠性多项式的真实似然评分给

    beta'_w(p;r) <= M(p)/p。

最终r簇的体积尾意味着，在beta_w(p;r)位于[e^-R a_w,e^R a_w]时，

    M(p)/beta_w(p;r)
       <= sum_(n≥0) min[1,Cw exp(-cn)/beta_w(p;r)]
       <= C_R' w。

由p_w(x)→p0>0，积分log beta可得，对固定-R≤x1<x2≤R，

    p_w(x2)-p_w(x1) >= (x2-x1)/(C_R'' w)。             (11)

可靠性混合在内部p区间可逐项求导：最终簇一阶体积矩有限且可支配导数。因此(11)不是对一个只有连续性的函数擅自求导。

(10),(11)确定非退化的1/w窗口量级，但**没有**推出w[p_w(x)-p0]为x的线性函数，也没有计算v(p0)。它们把剩余问题从“窗口可能在任意尺度”收缩为“这个1/w窗口的实际形状与标尺是什么”。固定-R,R的常数未优化，不用来给当前小w误差条。

## 5. 最终参数不是新物理参数

若r和r'都满足(5)，在nu_w(p)/nu0属于一个固定正紧区间时，

    log[beta_w(p;r)/beta_w(p0;r)]
       −log[nu_w(p)/nu0]→0

一致；r'相同。因此最终分组选择在领先时钟中消失。将两种构造置于共同的较高最终参数，(4)与标记计数还说明：两个同x反演在有限宏观窗口产生的额外出生数趋零，谱系损失也趋零。它们具有同一个领先过程，不要求两个反演的物理p之差已控制到o(1/w)。

**新获得的是内禀时钟下的模型映射，不是物理时钟标定。** 机器不必为时钟“是否存在”再扫一排参数；计算应转向p_w(x)的物理尺度/误差，或者寻找上述局部输入的实际失效。

## 6. 有限控制与下一步

独立小脚本在纵向自由的C3×3上，对全部512个配置构造完整簇。它将最终形状内首次绕行概率写成Bernstein多项式，再与全部3^9个共同标签早/晚对逐项求和比较。验证：beta端点、正Bernstein导数、Lipschitz界、密度=命中+损失、损失≤阶乘并合数及有理反函数包围。多组概率只是同一批有限对的重新加权，不是独立数据。此有限控制没有物理宽度渐近信息。

**下一步的两个有价值命题**：

- PHYSICAL-CLOCK：在已经得到1/w窗口量级之后，找出是否存在v(p0)>0，使log nu_w(p0+x/[v(p0)w])−log nu0→x局部一致；这是仿射化，而不只是量级。单位留数或参数解析性不是必须同时完成的前置。
- SOURCE-CLOCK：对保持平移周期的真实小源，分别研究一维强度时钟改变和标记/耦合改变。单一路径的内禀核相同，不意味着两条源路径在共同标签下的联合过程相同。这是后续猜想，不为它新开机器队列。

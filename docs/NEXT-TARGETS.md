# 下一步分析：把已有信号接到可干预的机制

**2026-08-31整理；这是下一轮分析建议，本次未启动下列生产或完整计算。** [STATUS](STATUS.md)记录已有答案；本页只说明接下来要回答什么、从哪里开始、交付什么。

研究重点应从反复证明“单一标量不够”，推进到三个正面问题：**哪种微观扰动改变拓扑扇区；哪些真实结构承担总体方向贡献；已命名的几何变量能否预测新的动力学响应。** 三者分别连接静态源、总体几何和实际传播，不要求先证明一个统一连续场理论。

## 1. 簇源：已测得的偶响应，能否解释原norm-4剩余缩放？

**已有起点。** q=1{rank=2}−1{rank=0}、E=q²、S=(黑NN簇数+白matching簇数)/N均有原始定义。[P40百万偶响应已完成](https://github.com/LightChainr/Matching-One/blob/56a6267d6a6826a165f93ed3a64a670ca7088180/results/p40-even-given-odd/REPORT.md)：固定p、q-fugacity补偿下的C明确为正；缺失E×S等矩已经补齐，不再重复派这项测量。

**下一份交付：原norm-4量的源导数。** 保留原pooled matching root与斜率归一化：

`U_N = (N^(13/8)/2) B_N/D_N`，`B_N=P4_std[∂p〈E〉]`，`D_N=∂p〈q〉_bar`。

沿共同正源族`Bernoulli(p) exp(λS)`，计算原量的`U_dot`，同时保留根位置移动、分子热响应和分母斜率响应。[已有接口推导](https://github.com/LightChainr/Matching-One/blob/56a6267d6a6826a165f93ed3a64a670ca7088180/notes/p40-even-response-norm4-interface.md)可直接使用；先在一个尺寸上的原取向对交付实际`U_dot`及配对误差，再接完整链。

**真正需要补什么。** 原尺寸链为65→130→260和85→170→340。需要相关root/thermal坐标处的q×S×K、E×S×K及低阶矩，因为`∂p Cov(O,S)=κ(O,S,K)/[p(1−p)]`。这里K为占据点总数，κ为三阶联合累积量；若输入存K/N，须恢复N因子。既有threshold histograms提供基线根与热导数，却不能还原簇数混合矩；单个p的百万补充也不能代替完整链。让一次有针对性的重观测直接输出这些源导数所需量，不再先造通用投影框架。

**如何区分机制。** 原q2/Jordan残差分别为`U_N−3U_2N+2U_4N`和`U_N−2U_2N+U_4N`。理论侧需给出同一个簇源如何扰动幸存机制的明确预测；数据侧比较`L4[U_dot]`。原未扰动关系不会自动对任意源成立，裸C或固定p温度补偿T也不能直接代替`U_dot`。

**一个可廉价并行的辅助读数。** 已保存的百万矩原则上足够给出真实Bernoulli温度补偿`T=Cov(E,S)−Cov(E,K)Cov(q,S)/Cov(q,K)`，可与已完成的q-fugacity补偿C对照。它在固定参考p保持当前M均值，不等于调到M=0；它帮助解释微观源，不替代原缩放问题。

**创新落点与代价。** 将“多分量”接到一个已实测的微观源及原始缩放量。主交付需要针对性补矩；辅助T利用现有矩。若簇数读出仍不能区分机制，可引入簇大小二阶矩等新几何量，现有簇数Gram无法还原它。

## 2. P334：总体贡献来自前缀数量，还是前缀内部的出生过程？

**已有起点。** [40k总体配对分析已完成](https://github.com/LightChainr/Matching-One/blob/c3bb43f1b078c5f9f76f71b25cdb3e2e331eb115/results/p334-paired-clock-loading/REPORT.md)。canonical和integrated的噪声比例差异很大；两种读数的H4均值仍弱。选定147-prefix的83.95%积分噪声比例不再作为总体预期。

**下一份交付：总体方向差的两项分解。** 对每个取向o，记r_o为checkpoint处rank1的频率，μ_o为rank1条件下原F2贡献的均值。则

`r₁μ₁ − r₂μ₂ = [(r₁+r₂)/2](μ₁−μ₂) + [(μ₁+μ₂)/2](r₁−r₂)`。

前项测层内完整clock差异，后项测rank1比例差异。用原20批配对，报告两项的有量纲值、区间、协方差及其和；共同除以同一个Δcos4。净差接近零时不造不稳定的“解释百分比”。保留whole-pair fallback，另列rank0/rank2未覆盖部分。先用已保存counter/clock输出完成这份分析，不重建scorer或重复DP。

**紧接的机制问题：空间信息能否解释clock之外的差异？** 已有两个真实prefix在各自中位点的E₁比较，无需重复。下一步面向上述总体中的prefix，在共同占据参数u下比较

`E₁ = u(1−u) Σ_v I_v²`，以及扣除均匀影响后的空间部分。

完整clock足以算均匀项和空间余量的界，不能还原ΣI_v²。先给出覆盖质量、总体加权界及哪些层最值得补信息；需要精确空间项时，才在同一配对样本上补marked/tangent DP。各prefix自己的中位u可作辅助描述，不能当作同一公共扰动。

**创新落点与代价。** 把两个漂亮例子连接到未经筛选总体的贡献，并区分“出现频率”与“内部结构”。首份分解利用现有输出；空间总体化确有新增计算。N100/N400/N900的完成结果用于约束全局出生分布解释，本轮不自动追加更大N或更多经验峰。

## 3. P398：既有几何读出能否预测真实速率干预？

**已有起点。** [width8 T4传播桥](https://github.com/LightChainr/Matching-One/blob/074a5f537caecac9cbd663dcc76ebd05ff54f302/notes/p398-width8-T4-schur-bridge.md)已有具名配置函数、原lags、完整正生成元及固定观察子空间。current删除、T4增量和原参数处的压缩改善均已做过。

**下一份交付：一张新参数响应对照图。** 固定总尝试率，改变join/detach的不平衡：

`G_η = (1+η) Σ(J−I) + (1−η) Σ(D−I)`，`|η|<1`。

保留η=0的原配置函数、K-eigenreadouts及lags。由K交换join/detach的结构，预测同ray相关对η偶、cross-ray相关对η奇。计算零点cross-ray响应及零频积分；同ray的一阶零响应提供对照。再用建议预先固定的η=±1/4比较完整正模型与原14/16维观察子空间的预测，不扫描参数挑选最好图。

η≠0混合两个K rays，需要联合186维扇区；真实响应同时包含平稳测度导数和传播子导数。若cross-ray切线非零，它无法由纯时间重标解释；若原固定几何读出预测失败，应报告丢失的响应，不临时加mark或指数修饰图形。

**创新落点与代价。** 从“已有曲线可以压缩”推进到“现有物理变量可以预测新的干预”。复用1430态实现及现有矩阵做有限参数计算，无新Monte Carlo。现有width4/8的i^j保持波长4；此处是参数外推。真正固定k=1的宽度比较需另用exp(2πij/w)，不能混称尺度验证。

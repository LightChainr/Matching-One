# 多线推进：空间源、不可辨识标记、无序平均、源零点与条件积分

本轮完成五项新的有限/概率分析，并对 #734 的极限顺序作定向纠正。没有重复枚举更大宽度，没有新增 Monte Carlo，没有启动 CPU 集群或 GPU 任务。具体矩阵与概率源仍然分开，不把新观测量代入 #275 的旧冻结合同。

## 1. 完整空间源 Hessian

对任意平移传递有限环面，定义加性占据概率场 p_i=q+a_i，以 M=0 定义有限根 q(a)。精确恒等式为

    q_i=-1/N,
    q_ij=-M_ij/M' + M''/(N² M').

全部零均值空间场的一阶根响应都为零，仅凭平移对称性即可成立。不存在“只要一阶为零就识别了反射奇场”的推论。

本轮完成 4×4 全部 16 个 Fourier 模式。根 Hessian 的惯性为正9、负6、零1，符号由有理数区间核对。单位均方强度下，条纹场 (-1)^x 的二阶根响应是 -1.93203424336，棋盘场 (-1)^(x+y) 是 +2.51989598927。相同均值和强度可以给出相反的有限根移动，因此一个幅度系数不够。

Logit 源下，零均值模式的 logit 根曲率精确等于

    -[Var(H|r=2)-Var(H|r=0)]/[E(K|r=2)-E(K|r=0)].

这给出了条件空间协方差的物理意义。换回 p 根要乘 p(1-p)；与加性概率源比较还存在 p(1-p)(2p-1) 接触项。完整列与区间在 full-site-hessian.json。

## 2. 全部均匀热/拓扑源数据仍可能看不见空间差异

4×4 上，2×2 方块、L 型四点集合、T 型四点集合的平移/D4 轨道大小分别为16、128、64，均落在 r=0、K=4。构造

    f_L=8·1_square-1_L,
    f_T=4·1_square-1_T.

取 W±=1±f_L/16 或 1±f_T/8，全部概率权重严格为正且在1/2到3/2之间。每个(r,K)单元中的权重变化恰好相消，所以整个均匀p的(r,K)联合律不变，所有均匀热导数以及所有非标记 rank 源导数也不变。

条纹/棋盘源对L/T标记的整数二阶对比矩阵为

    [[-512,-128],[0,-256]],   det=131072≠0.

两个独立的空间差异仍然可被读出。它们是正的依赖型标记反例，不是说已知 Bernoulli 定义有歧义；它们反驳的是“整个均匀 rank/thermal 字典相同便足以保证空间 source 相同”。不据此开采样单。

## 3. 平均概率曲线与平均各环境的根并不交换

独立、零均值的站点概率扰动，经环境平均后仍精确给出原 Bernoulli(p) 单配置律，因此 annealed M 严格不变。但各固定环境的有限根平均为

    E q = p_* + σ² M''/(2N M') + O(σ⁴)

（有界、中心对称、独立单位方差场）。4×4 的全站点系数为0.020558979708451625。两个独立扰动站点只需四个环境即可直接验证，其系数为0.002569872463556453。没有随机模拟。

减去每个环境的空间均值会去掉一阶根噪声，但不去掉这项二阶平均偏差；同时也引入相关性，不能再沿用独立环境的 annealed 等式。这里谈的是环境平均，不是有限样本根估计器偏差。

## 4. 有界拓扑源有统一无零点带

X=r-1∈{-1,0,1}，Z(s)=P0 e^-s+P1+P2 e^s。对s=x+iy，

    Re Z=P1+cos y(P0 e^-x+P2 e^x)>0，若 |y|<π/2。

因此任何系统大小下，都不可能在有限实s处由这种非标记有界源的复零点夹逼出相变；这不是关于p或总占据数源的结论。双源零点也不诊断传播算子的 Jordan 结构。

如果改用 s=mσ，这是不同的、随长度增强的偏置。固定宽度谱假设下，

    lim log Z(mσ)/m=max{-α0-σ,0,-α2+σ}.

三段分别选择rank0、rank1、rank2；两个转折位于-α0与+α2。q4处α0=α2=0.168595883942974875…。100/140位精度重算了固定宽度源零点与倾斜概率，不能把这一偏置相变称为固定s的二维渗流临界性。

## 5. 用几何起点固定条件概率比的积分常数

写 Z_j(t)=Σ_{r=j}t^K，最低项为a_j t^{k_j}。则

    log(Z2/Z0)=log(a2/a0)+(k2-k0)log t
              +∫_0^t [E(K|2)-E(K|0)-(k2-k0)]du/u.

4×4 的a2=16、k2=7由最小cross结构给出。用条件均值积分重建的根与直接多项式根在存储的50位上相同。另给出只用N、k2、a2的严格低fugacity锚点误差界，以及带条件样本成本的最优样本分配公式。

这是一项可运行的路径积分对照，不宣称获取独立条件样本或正规化免费。#733 的精确桥本来就计算了正规化，不能拿它证明大宽度未知概率也会自动变便宜。

## 6. #734 与后续检索

Morin-Duchesne–Saint-Aubin arXiv:0812.2925v2 PDF第5页先明确临界温度、mesh→0，再在连续公式上取模参数cusp。固定晶格宽度4不做这一内极限。本文给出精确条件式：若 logλ_w=-γ/w+a/w^(1+ω)+…，相对于连续主项的误差指数被长宽比放大为a r/w^ω；逐点连续极限不保证任意长条上的相对精度。

进一步给出一个明确标注假设的根/比值交叉式。若q_w-p_c~A w^-Δ且h_w'~B w^(y-1)，并且闭合余项与前因子被一致控制，那么r~w^(Δ-y)处可能有非平凡的条件扇区偏置。代入4与3/4只产生条件性的13/4，绝不是本轮证明了square-site临界指数。

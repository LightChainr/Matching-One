# Norm-4 Source Response Beyond a Thermal Clock

## 技术摘要

旧生产排列上的 cluster 源标记已经给出一个明确的有限尺寸结论：**沿源扰动后的共同 matching 根重新调节 p、保持 matching 平衡时，rank-1 拓扑概率仍明显下降，纯共同 thermal-clock 解释被排除。** 六个 N 的导数为 −0.09250 至 −0.09782，相对于各自同流协方差的标准误为 73–160 倍。这里测到的是三态拓扑组成的真实源响应；它尚未给 norm-4 残差指定连续极限能量算符。

N260、N340 的标记量已从各 100k 扩至各 1M，全部来自原生产 counter；原 U 的 bulk-source 导数误差分别降低 4.68、2.81 倍。更高阶机制判别仍弱：源刚性 q2/Jordan 联合名义 p 分别为 0.48573、0.58735，独立高精度基准上的 generator-drift 也未分辨。新增 common-q、common-E 及 common-(q,E) 必要行列式均未分辨，不能将它们的相容性写成机制识别成功。

全部读数、完整协方差、对齐 delete-one 向量及输入 SHA256 位于 [latest.json](latest.json)；科学聚合执行于 `6bd46ad30bc8f583c3ca1f1c8a1b95e7d90571bc`。本页取代 [原 100k 源读数](../norm4-source-thermal/REPORT.md) 作为端点精度与当前机制结论的入口。

## 保持 matching 平衡时，拓扑组成仍然改变

记三态 matching 变量为 q∈{−1,0,1}，E=q²，rank-1 指示量为 1−E。共同微观源为 s=C_B+C_W，耦合 exp(t s)，t=log Q；归档中的密度源 S=s/N 仅为计算坐标。每个 N 都在两方向合并的 matching 根 p₀ 上计算，横线表示两个方向的等权平均，D=平均 ∂ₚ〈q〉，J_q=Cov(q,S)、J_E=Cov(E,S)。

沿 p₀(t) 移动的 rank-1 源导数为

\[
r_s=\frac{d\overline{\Pr(\mathrm{rank}=1)}}{dt}
   =-N\left(\overline{J_E}-\overline{\partial_p\langle E\rangle}
                  \frac{\overline{J_q}}{D}\right).
\]

若源只等价于两方向共同的 a_g+bK 热时钟，这个量严格为零。实际得到（误差为 1 SE）：

- N65：−0.092503 ± 0.000692，z=−133.66。
- N85：−0.094559 ± 0.000914，z=−103.43。
- N130：−0.096367 ± 0.001250，z=−77.12。
- N170：−0.096101 ± 0.001316，z=−73.00。
- N260：−0.097823 ± 0.000612，z=−159.94。
- N340：−0.097110 ± 0.000683，z=−142.18。

因此，cluster fugacity 的效应在消除共同根位移后仍留在拓扑组成中。由于合并 matching 根保持平均 q=0，rank-1 概率的流失对应合并的 rank-0 与 rank-2 概率等量增加。这是当前最清楚的源机制事实。

### 两次激活对根位移均有正贡献

首次激活指示量 I₁=1+(q−E)/2，第二次完成指示量 I₂=(q+E)/2。静态累积事件的贡献定义为

\[
\dot p_1=-\frac{N(\overline{J_q}-\overline{J_E})}{2D},\qquad
\dot p_2=-\frac{N(\overline{J_q}+\overline{J_E})}{2D},\qquad
\dot p_1+\dot p_2=\dot p_0.
\]

按 N65、85、130、170、260、340 顺序，已存中心值为：

- 首次激活：0.019889、0.019528、0.019004、0.018375、0.017943、0.017565。
- 第二次完成：0.008864、0.009294、0.010139、0.010337、0.010988、0.011310。
- 总根位移：0.028753、0.028822、0.029142、0.028712、0.028931、0.028875。

两个贡献方向相同，首次激活贡献更大；它们的误差与相互协方差已随同一个 delete-one 向量保存。这是源对静态累积事件的响应分配，birth-local 或 K₁/K₂ 路径归因并未由这些统计得到。

## 端点源精度已提升，高阶链判别仍未分辨

沿用原定义

\[
U_N=\frac{N^{13/8}}{2D}\,\mathcal P_4[\partial_p\langle E\rangle],
\qquad \mathcal P_4[f]=\frac{f_{\rm first}-f_{\rm second}}{\Delta\cos4\theta},
\qquad v_N=\frac{dU_N}{dt}=N\dot U_{\rm density}.
\]

没有重新拟合自由指数或方向归一化。端点主要读数为：

- N260：v=−5.97229 ± 4.27362；原 100k 为 −3.48616 ± 19.98067。
- N340：v=+11.85937 ± 9.19815；原 100k 为 +31.47760 ± 25.87177。

新减旧的**嵌套配对差**分别为 −2.48613 ± 18.94455、−19.61823 ± 24.51033，未出现分辨出的不一致。这里的改善是 source 标记精度改善，两个版本没有被当作独立重复实验。

两条链为 65→130→260 与 85→170→340。对固定系数的源刚性延伸：

- q2：v_N−3v₂N+2v₄N，联合 χ²=1.44419/2，名义 p=0.48573。
- Jordan：v_N−2v₂N+v₄N，联合 χ²=1.06427/2，名义 p=0.58735。

对允许一个共同生成元参数漂移的延伸，以互不重叠 complement 的 U 作基准，消去漂移增益后的行列式为 −3.93493 ± 3.54673（q2）和 −3.94756 ± 4.16309（Jordan）。完整定义和次要的 within-source 版本均在 JSON 中。

**相容的源切向不能复活失效的未扰动参数化。** 同一 disjoint complement 上，未扰动 q2 残差仍为 χ²=21.37569/2、p=2.2821×10⁻⁵；Jordan 为 χ²=5.87302/2、p=0.05305。源切向检验回答的是已明确写出的额外延伸假说，原 t=0 递推本身不蕴含这些导数方程。

## common-E 是具体候选组成，行列式尚不足以选出机制

新增对照源分别按 exp(λq)、exp(ηE) 定义，因此 q/E 两列没有额外的 N 因子；只有 cluster 密度列转换到共同 bulk s 时乘 N。三行读出固定为：根随动 rank-1 概率、根随动 W=𝒫₄[〈E〉]、原 U。记各源 X 的响应列为 (r_X,w_X,u_X)。

已计算的具名必要条件为

\[
\Delta_q=r_su_q-r_qu_s,\qquad
\Delta_E=r_su_E-r_Eu_s,\qquad
\Delta_{q,E}=\det\begin{pmatrix}
r_s&r_q&r_E\\w_s&w_q&w_E\\u_s&u_q&u_E
\end{pmatrix}.
\]

前两项对应共同单个 q 或 E 源加热时钟；第三项对应 s 在这组三行中可映射为 a_g+bK+cq+dE，其中 b、c、d 在两方向间共同、热微分时固定，但允许依 N 变化。六 N 的三阶行列式均 |z|<1.225；两个二阶对照最大 |z| 分别为 1.639、1.431。它们都未分辨。

读出列本身已提供方向：common-q 的 rank-1 列接近零，而 common-E 的同一列稳定在约 −0.234 至 −0.235；cluster 列约 −0.093 至 −0.098，与约 0.4 个 E 源单位处于相同量级。这个描述只涉及 rank-1 一行，没有自由拟合出一个完整机制。尤其 common-q 的近零列会使必要行列式缺乏辨别力；相容的 determinant 不等于单源或三态模型已经识别。

## 档案精度、协方差和解释边界

本次只重观察 N260、N340 各自已有的 counter 区间 [8200100000,8201000000)，各 900k；与原首 100k [8200000000,8200100000) 合并。每个端点将同 batch_id 的原 1000 与新增 9000 个不相交排列组成 100 个等权 10000 批，两方向共同删除；N65、85、130、170 保留各 100k、100×1000。四个 cyclic N 共 seed/counter 域而共同留一，两个端点 seed 不同，各自独立成组。K 前缀、各读出和源模型诊断都不是额外独立样本。

原普通 q/E 生产档案来自 `8b26a30a785bc142a9d17bfed99a8d0e98ddc4dc`。高精度 anchor 明确扣除了**全部当前源标记**：四个 cyclic N 使用 1,899,900,000 个未标记排列；端点使用 999,000,000 个。端点 complement 的原 batch0 已从 10M 扣到 9M，其他批仍为 10M；按真实批权重传播 anchor 协方差。没有沿用与新增 900k 重叠的旧两阶段 complement。源响应本身的精度仍是 cyclic 100k、端点 1M，不能写成 1.9B/1B 的源精度。

完整 new/old 联合向量、跨组协方差贡献与配对差均已保存。上文 z 是有限档案的一阶 delete-one 标准化读数；六 N 特别是四个 cyclic N 不能作为独立显著性相乘。新增行列式是聚合前固定的探索性比较，没有按 p 选源；其相容性不排除方向各自不同的源系数。静态全 K 的 q、E、S、qS、ES 也不包含 S(K₁)、S(K₂) 的联合标记，无法据此识别激活路径上的局部因果归属。这里的 E=q² 是拓扑量，连续极限能量场身份和原 norm-4 物理残差仍待识别。

资源回执见 [run.json](run.json)：两个 CPU 回放分别 74.58、97.80 秒，并行总墙钟 98.78 秒；聚合 1.44086 秒。Python 3.11.15 / NumPy 2.3.5 / SciPy 1.16.3，ARM64；无 GPU、无新随机 counter、无服务器操作、无测试套件重跑。回放及聚合代码、输入 CSV 和 SHA256 均由 JSON 直接索引；本报告未触发重新计算。

## 下一项实际机制读数

优先消费已经出现的 common-E 候选：用 rank-1 行确定一个有限尺寸 E-loading，再连同热根位移给出**具名的其他读出预测**；保持同一源单位、两方向共同系数，并传播 loading 与目标读出的同流协方差。现有 U 的这个预测残差只是已算 ΔE 的等价表达，不另算新证据。真正增加信息的目标是 rank-1 内部的 conditional primitive-line 读出：E 在固定 p 的该条件扇区内为常数，但 pooled 根随动仍会产生已知 thermal-transport 项，须从预测中保留。当前 q/E/cluster 表不含 line 标记，这是一项明确的后续采集与预测，而非已经完成的空间归因。

普通 q/E anchor 已非常精确，继续提高它的样本量不会解决当前高阶 source 噪声。下一步应集中在上述可被推翻的 common-E-plus-clock 预测与其物理条件读出，而非再次准备通用工具，或仅把未分辨行列式当成机制结论。

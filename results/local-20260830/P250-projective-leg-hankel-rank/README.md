# P250 model-free multivariate Hankel rank

Existing-data reanalysis of the fresh N505 80k/400-batch bivariate stream.  No
new simulation was run.

The two-charge plus and minus blocks each reject rank at most four but retain
rank at most five.  The four-channel shared block rejects rank at most five.
Thus a five-dimensional commuting state remains compatible within each hand,
while one raw state shared across both hands requires at least six dimensions.

`score.json` retains every Schur residual, full delete-one covariance, pivot,
correlation spectrum summary, asymptotic score, and finite-batch Hotelling
score.

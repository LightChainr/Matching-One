# P250 Z5 common-counter radius selector

`R2/`, `R3/` and `R4/` contain the new 4k streams and support-first scores.
The identical R1 stream remains in the inherited
`P250-z5-multiseparation-smoke/` package and is referenced rather than copied.

`selection.json` is the machine-readable frozen decision and `selection.md` is
its compact rendering.  The preregistration is
`analysis/p250_radius_selector_prereg.json`; the scientific interpretation is
`notes/p250-radius-selector-result.md`.

All four candidates use the same counter stream.  This package is a geometry
selector and does not authorize production.

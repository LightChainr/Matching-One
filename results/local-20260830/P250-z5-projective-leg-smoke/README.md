# P250 projective-leg operator smoke

This package contains the exact construction gate and the frozen 2,000-replica
propagation smoke for the root-marked projective-leg insertion.

- `exact_gate.json`: primitive line, black/white same-component propagation,
  period-basis and Z5 deck-character gates;
- `response_2k.*`: aligned raw sufficient statistics and full covariance;
- `score_2k.*`: pair propagation and cubic-interface decision without a phase
  score.

The preregistration is `analysis/p250_projective_leg_insertion_prereg.json` and
the interpretation is `notes/p250-projective-leg-insertion-result.md`.

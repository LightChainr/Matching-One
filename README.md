```text

q = r_black - 1 = 1 - r_white.

```text
q_n = -1 + 1{n>=K1} + 1{n>=K2},
M_N(p) = -1 + E[H_K1(p)] + E[H_K2(p)].

Under a natural product-local edge-subset contract, the four-terminal site junction is absent from ordinary Tutte/Krushkal-family states, so the matching defect is not a direct named edge-polynomial specialization. It is exactly a derivative of a typed-site rank-image/site-Krushkal quotient with one necessary and sufficient topology source. Main-integrated PR #329 supplies a stable RGS/group-orbit key for the terminal partition state, but no junction composition, gadget or radical result. This redirects exact work toward typed-port recurrence, coefficient algebra and the connectivity radical; it does not supply `p_c` or a general no-go for correlated gadgets.

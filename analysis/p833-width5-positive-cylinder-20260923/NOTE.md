## 1. 同一个物理模型、三个不同问题

固定宽度 w，NN square-site，行掩码 b 取 0,...,2^w-1。历史 H 是已占据行串。每增加 t 行后，临时把当前前缀闭合成环面，读取 ambient homology rank R_t in {0,1,2}；继续增长时不保留临时闭合边。B_t=1{R_t=1}。

t 是延拓行数，不是物理时间；R_t 可以下降，不是固定环面上的单调站点插入。当前 B_0 / R_0 包括在合同内。随机模型必须统一适用于全部历史准备和任意概率混合。

同一行的所有站点 iid Bernoulli(p_t)。不同列独立调参、实际行掩码的确定性逐行更新，是更强的合同；385 状态模型不对它们作承诺。其潜在初态可以是概率混合，不能当作 385 个按真实输入更新的历史标签。

写 398 状态 D5 商的转移为

    K(p) = sum_{k=0}^5 C_k p^k(1-p)^(5-k),
    C_k >= 0,        C_k 1 = binom(5,k) 1.

D_r 是完整秩输出的对角投影。后续全部计算使用整数 C_k。

## 3. S2：13 条常系数关系，以及真正的正压缩

### 3.1 观察核不只是某个 p 上的偶然关系

找到 13 个支撑两两不交的有符号行向量 v_l。逐 k 精确检查：

    v_l 1 = 0,
    v_l C_k = 0,              k=0,...,5,
    supp(v_l) 位于同一个 R 输出块。

其中四条为 (1,-2,1) 的中点关系，九条为 (1,-1,-1,1) 的平行四边形关系。系数和物理历史全部保存在 certificate.json / result.json。它们对全部 p、对全部逐行变化的 p_t 都成立，并且对完整的 0/1/2 秩输出也不可见。

最小例子是 rank 0 的三段历史

    A=[0,15], B=[0,7,13], C=[0,15,9],
    (e_A - 2e_B + e_C) C_k = 0  对每个 k.

这意味着准备 B 与准备 A/C 的等权混合有相同当前输出，经过任意一行均匀 Bernoulli 更新后有完全相同的 398 状态分布。它不意味着 A、B、C 三个纯历史可以合并。

一个四项例子为

    A=[7,0,15], B=[7,0,7,13], C=[7,0,14,11], D=[7,0,15,9],
    (e_A - e_B - e_C + e_D) C_k = 0.

这些最短表示长度不同，但可由上节共同长度七的代表替换；长度没有被用作隐形辅助坐标。

### 3.2 不是把负概率截成零

对中点关系，保留 A,C，令 B 编成两者的等权混合。

对四项关系，使用三个新的线性坐标行

    q1=e_D,
    q2=e_A-e_B+e_C,
    q3=e_A+e_B-e_C.

物理初态编码是非负的：

    A -> (q2+q3)/2, B -> (q1+q3)/2,
    C -> (q1+q2)/2, D -> q1.

q2/q3 的坐标写法有负数，**但它们不是宣称可直接当作原物理状态的概率混合**。需要另外检查它们产生的真实转移与输出概率非负。这一步本次确实做了。

将九组这样的坐标、四组中点和其余单独状态组合成 V (385x398) 与非负行随机初态编码 U (398x385)。程序逐整数系数验证

    VU=I_385,         V1=1,          U1=1,
    UVC_k=C_k,
    VC_k>=0,          k=0,...,5,
    D_r U=U Dtilde_r,  r=0,1,2.

定义

    Ctilde_k = V C_k U,
    Ktilde(p)=sum_k Ctilde_k p^k(1-p)^(5-k).

则 Ctilde_k>=0 且 Ctilde_k 1=binom(5,k)1，并有

    K(p)U=U Ktilde(p).

因而 (mu U, Ktilde(p_t), Dtilde_r) 是一个真正的 **385 状态、非负、归一化、确定秩发射**模型。对任何初态 mu、任意行参数序列 p_t、任意完整秩输出字串，概率与原模型完全相同。二进制 B 只是其粗化。

这些是系数恒等式，不是只在几个 p 点数值近似成立。全模型精确分母为 2；--model-out 可输出全部转移系数、U 与 V。V 只用于代数构造，实际生成模型只使用非负的 mu U、Ktilde 和输出投影。

### 3.3 为什么一般参数下最小值正好为 385

在 p=1/2，选出 385 个实际二进制输出字串，最长含当前输出共 19 位，及 385 个物理准备行。其整数概率分子子式在素数 1,000,003 下行列式为 821642，不为零。独立消元路径重新计算同一子式，得到相同值。

因此线性维数至少 385。13 个独立核方向或正 385 模型给出上界，故半点确切为 385。这个子式是一个非零参数多项式，在实区间内仅有有限个根，故除有限例外外线性维数为 385。

任何统一 k 状态概率实现的“准备 x 输出字串”矩阵都分解成准备编码乘以潜在字串概率，其秩至多 k。于是一般参数下

    最小线性维数 = 最小正状态数 = 385 < 强聚合类数 398.

这是 S2(a) 的构造性结局。强聚合只允许划分类，不是所有随机表示的最小正阶数。一般自动机等价与预测状态方法不主张新颖，本次是这个物理实例的精确压缩。

## 4. S1：p_b(5) 的 51 次多项式及其秩支撑

### 4.1 两个真实的生存核心

从全空历史 [0,0] 出发，所有尚未吸收的状态一直有 R=0；一旦出现水平 NN 绕行，进入一个永久 R=1 的吸收状态。宽五该核心有五个状态。

从全满历史 [31,31] 出发，只要原满首行仍连到当前行就保持 R=2；连接消失后也进入同一个 R=1 吸收状态。宽五该核心有七个状态。

程序按可达性构造两个子随机核心 Q0(p)、Q2(p)，逐支撑检查不可约性、同输出及唯一公共吸收态。对内部 p，它们具有严格正的左右 Perron 向量。定义赔率 x=p/(1-p)，A_j(x)=(1+x)^5 Q_j(p)。

两核特征多项式的 resultant 为

    resultant_z(det(zI-A0),det(zI-A2))
       = x^66 (x+1)^7 G51(x).

G51 的全部 52 个整数系数及其 p 变量变换均保存在 result.json。没有用小数根作 PSLQ 猜测。

有理不可约性用三个良好素数的分解次数交叉证明：

    mod 7:  2+3+4+8+12+22,
    mod 13: 15+18+18,
    mod 17: 1+7+21+22.

任何有理因子的次数必须同时是这三组次数的子集和；非平凡次数交集为空。因此 G51 在 Q[x] 不可约，Mobius 变换后的 p 多项式也给出次数 51 的极小多项式。

### 4.2 四个内部根，只有一个是共同 Perron 根

精确根隔离给出四个 p 根，数值仅供阅读：

    0.1861809889706..., 0.3562673812507...,
    0.5922358232050..., 0.8982639476335....

子结果式给出精确共同特征值有理函数。通过模 G51 的伴随矩阵行构造两个精确左特征向量，并核对全部多项式恒等式。在 x in (7/5,3/2) 的根处，用有理区间 Horner 证明五项/七项向量各项都为正；所以它是两核的共同 Perron 特征值，而不是只比较高精度 eigenvalues。

其余三个根的共同特征值低于 Q0 的最小行和，故按 Collatz 下界都不是 Perron 碰撞。最终

    p_b(5)=0.592235823205026677646851324052387293177746368612...
    rho=0.875062830394132537458173448805553416889796055627...

精确隔离区间随结果提供；计算内部使用更窄的有理区间来控制高次数特征向量的消去误差，未把浮点符号用作证书。

### 4.3 准平稳混合说明盲点究竟隐藏什么

令 alpha_0 Q0=rho alpha_0，alpha_2 Q2=rho alpha_2，且两者分别归一化为概率分布。它们都是可由真实历史准备的合法混合，一份完全在 R=0，一份完全在 R=2。

在二进制 B 观察中，两份准备都从 0 开始，以同一个几何等待律进入永久的 1：

    P(B_0=...=B_h=0)=rho^h,
    P(第一次 1 出现在 t)=(1-rho)rho^(t-1).

所以两份 **全部被动二进制轨迹** 同分布。这不是自然 Bernoulli 初态满足 P0=P2，也不是有限方形环面的根；它是两份准平稳准备有相同消亡率。完整 R_0 立即区分两份准备。

在 G51 的每个根，两个非零代数特征向量也能组成总和零的有符号二进制不可见向量。共同特征值非零，而前述 13 个方向都被 K 一步杀掉，因此这是第 14 个独立不可见方向。

另在 mod 1013、x=91（G51 的一个模根）使用实际字串子式得到二进制下界 384、完整秩下界 385。G51 不可约使这些非零子式适用于其全部特征零根：如果某子式被 G51 整除，良好约化后在模根也会为零，矛盾。

于是四个内部根的二进制线性维数精确为 384，完整秩为 385。只有共同 Perron 根给出上面的全正准平稳准备解释；其他根不伪装成正 Perron 碰撞。本轮不研究这些孤立点的最小正状态数。

## 5. 必须归属的先例：它已经是 Jacobsen 圆柱序列

Jacobsen 2015 arXiv:1507.03027v1 §4，特别是 (11)–(13)，把固定宽度、长度趋无穷的 2D/0D 平衡根写为开/闭扇区主特征值相等。§6.1 Table 2 已刊出本轮的宽四、宽五数字，约四十位完全对应。正文段落和表格在 arXiv HTML 一手读取；本轮未分析 PDF，也不声称读了该论文每一步证明。

本次不只核小数。独立写了一份**不使用 winding/gain、只记首行连通标记的边界划分**引擎，用来计算普通 NN 竖向生存，以及 matching 八邻接的竖向生存。把白占据概率设为 1-p 后，其精确矩阵与 native 核逐项换标相同：

|宽度|NN 生存：原始/强商|matching 生存：原始/强商|换标|
|---|---|---|---|
|4|19 / 5|19 / 2|两侧均恒等|
|5|51 / 7|51 / 5|NN 恒等；matching [0,2,1,3,4]|

这是每个多项式条目的等式，比只核相同特征多项式更强。它不声称重建了 Jacobsen 的所有 TL 状态或给出全宽度矩阵 intertwiner。

物理字典也可直接看出：有空黑首行时，不出现黑 NN 横向环，等价于白 matching 保留竖向连接；有满黑首行时，rank2 核就是黑 NN 竖向连接存活。两种核心分别给 rho_8(1-p)、rho_4(p)。

对固定 w，环面 rank2 事件的概率与 NN 竖向生存概率有相同的长度指数：上界是把切开的首行强制全满的生存事件；下界再要求首末两行全满，付出与长度无关的 p^(2w)，剩余竖向连接加上水平满行保证 rank2。对白 matching 作相同构造，并使用配置级有限 4/8 秩互补，得到

    lim_(m->infty) (1/m) log(P2(w,m;p)/P0(w,m;p))
      = log rho_4,w(p) - log rho_8,w(1-p).

固定个数的端行权重和概率正规化不改变两个长度指数相等的条件。因此本轮 Perron 盲点就是同一 cylinder balance 判据，不是从数值接近推断未知精确关系。有限 m 的振幅仍可不同，不能把该点当作每个 w x m 环面的精确平衡根。

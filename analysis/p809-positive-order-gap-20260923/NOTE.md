# #809 / #831：93 维线性预测仍需 94 个正随机状态

## 1. 结论与合同

**在 p_a 处，猜想成立，而且只记录二进制读出就已需要 94 个正状态。**

模型仍为宽度四、NN square-site 的逐行延拓。追加 t 行后临时闭合当前前缀，得到 ambient homology rank R_t；继续增长时不保留临时闭合边。记录 B_t=1{R_t=1}。t 是延拓行数，不是物理时间，不是固定环面的单调站点插入过程。

p_a=0.53604285634441581340... 是 #831 的 11 次参数点。令赔率 x=p/(1-p)，它的精确定义是

    f(x)=x^11+11x^10+57x^9+165x^8+264x^7+149x^6
         -193x^5-420x^4-331x^3-132x^2-26x-2=0

的唯一正根 x_a，再取 p_a=x_a/(1+x_a)。小数不是证明输入。

讨论的是一个共同的、时间齐次的有限隐状态概率模型：它须对原 94 个 D4 历史准备以及其任意概率混合，精确生成包含当前 B_0 在内的全部有限输出字串。允许任意非负的初态编码、任意非负边发射算子；潜在状态不要求是原状态的删减、合并或物理历史的凸组合。

**定理（该合同下）：**

    最小线性维数，包含常数 = 93；
    最小正的共同隐状态数 = 94。

同样的 94 下界适用于记录完整 R_t∈{0,1,2}：完整秩模型可以合并 0/2 输出得到二进制模型，而原 D4 机器提供 94 状态上界。这里并没有把普通秩、非负矩阵秩和可递归的正随机实现阶数混为一谈。

**不包括：**跳过 B_0 才开始记录、把 B_0 作为模型外的免费标签、仅固定一种自然初态、时间非齐次或时距特制模型、有限误差近似，以及 p_b 的正阶数。它们不是本定理的结论。

所有 94 种准备均可在相同历史长度五实现，因此没有暗用历史长度作为识别坐标。

## 3. 把“永不回落”变成正模型必须尊重的面

称一个二进制字串为坏字串，当且仅当包含相邻的 10。没有坏字串的轨迹属于 0*1*：一旦输出 1，之后永不回到 0。

以下八个物理准备保证所有坏字串概率为零：

| D4 编号 | 一段可实现的历史 | 当前 B |
|---:|---|---:|
| 0 | [0,0] | 0 |
| 6 | [0,7] | 0 |
| 5 | [15,15] | 0 |
| 28 | [15,1] | 0 |
| 29 | [15,3] | 0 |
| 30 | [15,5] | 0 |
| 31 | [15,7] | 0 |
| 7 | [0,15] | 1 |

令 G_0=(0,6,5,28,29,30,31)，G=G_0∪{7}。原转移图逐项确认 G 闭合，7 为恒 1 吸收状态。令 R=K[G_0,G_0]。

**坏字串概率空间恰为 85 维。** 本次选出 85 个实际坏字串，最长 11 个输出（最大延拓时距 10）。它们的 85 阶子式在模 1021、x=173 处的行列式是 352，非零；完整字串和行指标在 certificate.json。

上界也直接成立：八个 G 行恒为零，且 v 在补集上的非零限制还给一个独立线性关系，所以上界为 94-8-1=85。此处“坏字串”不是额外干预，而是同一被动二进制轨迹里的事件。

下面十个当前为 0 的状态组成第二个核心：

    J=(26,27,79,80,81,82,83,85,86,87)。

它们只转移到 J、7 或 84；7 和 84 的当前比特均为 1。令 Q=K[J,J]。不可见向量的全部支持正好包含在 G_0∪J 内，并在两边都不为零。

## 4. 两个很小的精确谱证书

不需要精确求出 R 和 Q 的全部特征根，只需以下分离：

    char_R(z) 在闭区间 [1/50,19/25] 没有实根；        (A)
    存在严格正行向量 ℓ，使 ℓQ < (19/25)ℓ；          (B)
    |λ| > 1/20。                                     (C)

(B) 使用整数向量

    ℓ=(344,427,689,526,555,102,369,506,270,100)。

脚本在 Q(x_a) 中逐项核对 (19/25)ℓ-ℓQ 的十个分量严格为正。

(A) 用 R 的 7 次特征多项式及其 Sturm 链完成。在 1/50 和 19/25 处的精确符号分别是

    +,+,-,+,+,-,-,-
    +,-,-,+,+,-,-,-。

两端变号数均为 3，且端点不是根，因此该区间没有实根。全部代数符号由 f 的有理隔离区间和有理区间 Horner 运算确认；不是浮点特征值或容差判断。

辅助直观：R 的正实特征根大约为 0.01298、0.78113、0.89485，而 Q 的 Perron 根大约为 0.75203。证明只消费有理切分 0.02 与 0.76，不消费这些近似小数。

## 5. 排除一般的 93 状态非负实现

这一节没有把潜在状态限制成物理状态的合并，也没有假定一个特定的非负分解形式。

### 5.1 最小维数让当前输出成为潜在状态的确定标签

反设存在一个 93 状态、时间齐次的非负边发射实现。设 P 为 94×93 初态编码矩阵，各行是概率分布；E_0,E_1≥0，T=E_0+E_1 行随机。

实际观察空间秩为 93，所以 P 的列秩为 93，潜在模型的字串概率列空间也为 93 维。因此：

    vP=0,              KP=PT。

第一式来自 v 消去全部字串；第二式来自把当前输出求和后的延拓概率相同，以及潜在字串列空间满维。两者都不是假设的物理强聚合。

每个物理准备的当前 B_0 是确定的。由于 P≥0、行和为 1，潜在状态若被某个当前为 b 的准备以正概率使用，它的当前发射 b 的概率就必须为 1。P 满列秩保证每个潜在状态都被使用。因此潜在状态各自有确定比特标签，并有

    E_b= D~_b T,       D_b P=P D~_b。

这一步只在“包含当前输出、统一适用于全部准备”的合同下成立，不能免费搬到延迟记录。

### 5.2 85 个坏方向与八个好准备把潜在面完全锁定

把从某潜在状态出发的全部坏字串概率都为零的状态称为好状态。由于概率非负，G 的八个物理准备只能编码到好状态。P 的唯一左关系是 v，而 v 在 G 外非零，因此 P[G,:] 的行秩为 8：至少需要八个好潜在状态。

另一方面，85 维的坏字串概率矩阵只能通过非好潜在状态贡献，故至少需要 85 个非好潜在状态。总数假定为 93，于是两者恰为

    8 个好状态 + 85 个非好状态。

好状态集在 T 下闭合，否则从一个好状态可以正概率到达一个会产生坏字串的状态，矛盾。八个好状态中，七个当前为 0，一个当前为 1；后者必为恒 1 吸收状态。

令 R~ 为七个好零状态上的转移子矩阵，P_0 为七个 G_0 准备到这些潜在状态的编码。P_0 是非负、行随机、可逆的 7×7 矩阵，且

    R P_0=P_0 R~。

因此 R~≥0 与 R 相似，具有同一谱。不需要假设 P_0 是置换。

### 5.3 非负编码与增长率产生矛盾

令 C=P[J,好零状态]，它是一个非负的 10×7 矩阵。J 的物理转移只落入 J 或两个当前为 1 的状态；后两者不能编码到好零状态。因此 KP=PT 给出

    QC >= C R~。                                          (1)

右边之外的项来自非好潜在状态转入好零状态，均非负。

设 h=ℓC≥0，由 (B) 和 (1)，

    h R~ <= (19/25) h。                                   (2)

另一方面，令

    w=v[G_0] P_0。

v[G_0] 非零且 P_0 可逆，故 w≠0。物理核心的特征关系给

    w R~=λw。

又由 vP=0 及 v 的支持只在 G_0∪J，

    w=-v[J] C。                                          (3)

因此 w 的支持包含在 h 的支持 I 内。ℓ 严格正，故 h_j=0 就意味着 C 的第 j 列为零。

(2) 与非负性说明 I 在 R~ 下闭合：若 j∉I，则 (h R~)_j=0，故从 I 不能转移到 I 外。并且 I 上严格正的 h_I 给出

    ρ(R~[I,I]) <= 19/25。

由于 I 闭合，这个非负矩阵的 Perron 根也是 R~、从而 R 的实特征值。由谱隙 (A)，它只能满足

    ρ(R~[I,I]) < 1/50。

但 w≠0 支持在 I，且 w R~=λw，所以 λ 也是 R~[I,I] 的特征值。这要求

    |λ| <= ρ(R~[I,I]) < 1/50，

与 (C) 的 |λ|>1/20 矛盾。

**故 93 状态的正随机实现不存在。** 少于 93 已由线性秩排除，原 94 状态模型给出上界，定理得证。

这是一条“零概率语言面 + 谱分离”的证明，不是用数值优化没有找到 93 状态来宣布不可能。

## 6. 这个结果说明什么，不说明什么

#831 中的混合不可辨识仍成立：确实少了一个线性方向。但线性商空间里仍需保持所有准备的非负编码和同一个非负更新；一个 93 维有符号表示不能承担这两个条件。

94 是这整个准备族的最小统一概率模型状态数，不是“真实物理自由度”数量，也不是某一个平稳准备或自然初态的状态下界。不由此认证某个有限概率矩阵的非负秩恰为 94；证明使用了共同的非负动力学。

p_a 下跳过当前 B_0 的合同仍未解决最小正阶数，其线性 93 与正阶数 93..94 的旧边界保留。p_b 的正阶数也未在本轮解决。原本在其他参数构造的 92/93 状态延迟模型不受本定理影响。

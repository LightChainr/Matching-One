# #837 补件：rank-only 比完整第一步边界又少一次传递机会

2026-09-24。本件在NOTE.md的四点接口证明之后继续推导，保留原文件和原检查结果。消费者：#833/#809。作者证明及精确有限检查，待独立复核。

**更强结论。** 在原三行准备族、独立新site概率位于[ε,1−ε]、只能通过临时闭合rank观察、不能重新制备的合同下，对只相差一个目标位的两份准备，任意长、可观察反馈或停止的rank轨迹都有

    TV(Law_0,Law_1) ≤ (1−ε)^5,
    等先验位错误 ≥ [1−(1−ε)^5]/2
                 = (5/2)ε−5ε²+5ε³−(5/2)ε⁴+(1/2)ε⁵.     (S)

因此 ε=.01 时错误至少 .02450497505，ε=.1 时至少 .204755。NOTE.md的(1−ε)^4是完整第一步充分边界通道的锐界，仍然正确；但它不能由rank-only轨迹达到。本件据此回答NOTE.md §8提出的该项疑问：rank读取还有严格的额外损失。是否能达到(S)的新下界，仍未证明。

## 证明

沿用NOTE.md §6的第一新行m。只有事件

    S={(m0,m1,m2,m3)=(0,1,0,1)}

会使两份第一步充分边界状态不同。在S之外，已经完全擦除。

在S之内，新站点m1的两个水平邻居m0、m2都为空。u=0时m1是孤立点；u=1时m1经旧局部分量接向m3，但它是这份差异的一条叶端。第一步的ambient rank在两侧都为0：旧首行排除竖向绕行；旧块对新行仅有m1,m3的出口，而m1的横向邻居为空，不能由此生成横向环。其余旧块也不能绕过目标块的断口形成一条横绕环。因此，第一步的rank观察未能读出这个区别。

令n为第二新行。若n1=0，第一行的m1就没有任何面向新前沿的出口。它在u=1中只是一条接到旧分量的内部叶枝，在u=0中是一个内部孤立点；删除这条无出口区别，不改变任何新前沿连接、整数路径gain或完成的ambient环空间。两份第二步充分边界状态于是完全相同，第二步rank也相同。之后的任何共同控制和新随机数都无法恢复区别。

所以，任何时刻的rank区别都要求S发生且n1=1。第一新行站点条件独立，Pr(S)≤(1−ε)^4。条件于任意已经发生的第一行与共同观察/控制随机化，第二新行站点1的占据概率≤1−ε。共享随机数耦合给

    Pr(可能出现rank区别) ≤ Pr(S,n1=1) ≤ (1−ε)^5.

S之外以及S内n1=0的分支全程同输出。耦合不要求控制器知道S；在S内它只观察到共同rank0。无限轨迹和停止规则同样由路径级耦合处理。由TV判别公式即得(S)。

这个证明没有宣布五个坏点是唯一失败机制，因此(S)只作下界，不声称最优rank错误。若允许免费观察完整第一步边界，则可在第二个端口擦除前读取，这不属于本合同。

使用check.py的独立整数开放圆柱充分状态遍历open_signature。宽5的一块准备、宽10的两块准备中，固定其余全部位，穷举每一个满足S的第一行，以及每一个n1=0的第二行：

|---|---:|---:|
|5|4|64|
|10|512|262144|

全部第一步状态确实不同且horizontal flag为0；全部第二步状态逐整数完全相同。实际运行约11.45秒，仅本容器遥测。没有Monte Carlo或宽10完整自动机；这里每一行的枚举范围明确，只是这一局部准备族。全宽度证明来自上述叶端消去，不靠表格外推。

这项补充检查不是默认check.py自动执行的一部分。下列标准库命令是本次实际执行的检查，可在研究目录或会话包根目录复现：

```sh
python - <<'PY'
from itertools import product
from check import prepare, open_signature
for w,t in [(5,1),(10,2)]:
    first=second=0
    for other in product((0,1), repeat=2*t-1):
        x=[0]+list(other)
        bits=list(zip(x[::2],x[1::2]))
        a=prepare(w,bits)
        bits[0]=(1,bits[0][1])
        b=prepare(w,bits)
        for m in range(1<<w):
            if m&15!=10: continue
            s0=open_signature(w,a+[m])
            s1=open_signature(w,b+[m])
            assert s0!=s1 and not s0[0] and not s1[0]
            first+=1
            for n in range(1<<w):
                if n&2: continue
                assert open_signature(w,a+[m,n])==open_signature(w,b+[m,n])
                second+=1
    print(w,first,second)
PY
```

NOTE.md的固定小ε、O(logw)充分构造不受影响；其允许误差远高于这个下界。下一问题应是rank-only的真正小噪声最优常数，或明示改变准备后如何增加信息出口，而不是假定长导线能恢复已经在前两行失去的区别。

## 0. 结果与边界

沿用 t=⌊w/5⌋ 个孤立分量的同长度三行准备。观察只有临时闭合后的同调秩 R₀,…,R_h（或 B_s=1{R_s=1}），输入是未来的独立站点概率，实验不能直接读取已经编码的旧比特。

**A. 两行查询的正确噪声阶数是 w^(-1/2)。** 对原单比特查询，将两行中各指定比特独立以 ε 翻转，最坏位错误率满足

    err₂(w,ε) ≤ min{1, 7ε + 3wε²}.                          (A1)

特别地，0<ε≤1/(400√w) 时 err₂<1%。先前 1/(200w) 是充分但非尖锐的 union bound，可被这次更强的界替代，旧结果仍然成立。

另一方面，对任何至多两行、任何各站点条件概率在 [ε,1−ε] 的策略，即使可根据先前秩输出自适应改变概率，要以固定错误率 η<1/2 区分相反比特的两份准备，必须有

    ε ≤ sqrt(1 − (1−2η)^(1/t)).                            (A2)

所以对固定小于1/2的误差目标，允许噪声的最大阶数是 Θ(w^(-1/2))；不主张最优常数，也不把 1/2 称为渗流临界指数。

**B. 固定噪声下，短查询其实易于近似。** 记

    β_h(w,ε) = (1−ε^h)^t,   0<ε≤1/2.

则对该准备族、所有上述 h 行策略，存在一个与准备无关的共同输出部分，其质量至少 1−β_h。它总是输出 R₀=⋯=R_h=0。于是

    sup_x TV(Law_x(R₀,…,R_h), δ_(0,…,0)) ≤ β_h,
    sup_(x,x') TV(Law_x, Law_x') ≤ β_h.                   (B1)

因此一个总输出0的单状态模型，对这整族准备和全部允许策略的 h 行轨迹都具有上述误差上界。固定 ε、h=o(log w) 时 β_h→0。原先的巨大精确秩不被撤回：精确区别可以位于极小的非零概率中。

若需要一次实验以错误率 η<1/2 读出未知比特，必要条件是

    h ≥ log[1−(1−2η)^(1/t)] / log ε
      = (log t − log[−log(1−2η)])/|log ε| + o(1).        (B2)

这是对数高度**下界**。本轮尚未证明固定 ε 的 O(log w) 完整查询构造，不能把必要条件称为充要条件。

## 1. 准备、允许策略与观察合同

第 g 个局部块占 a=5g、i=a+1、j=a+2、d=a+3 四列，a+4 为空分隔列。w−5t 的剩余列也为空。用

    H_x = [0,
           Σ_g (15 << 5g),
           Σ_g ((9+2u_g+4v_g) << 5g)]

制备 X=(u₀,v₀,…,u_(t−1),v_(t−1))。旧首行全空，且 t 个指定分隔列在三个旧行中全空。所有旧准备的 ambient rank 均0。

未来第 s 行第 j 个站点在给定过去后独立占据，概率 q_(j,s)∈[ε,1−ε]。q 可非均匀、随行变化，并依赖先前秩观测、查询下标及独立公共随机种子；不能依赖未知的 X 或免费保留的旧拓扑标签。实验总行数至多h；提前停止可用虚拟后续行补到h。

R_s 在前缀临时闭合后读取，继续生长时不保留临时闭合边。空的旧首行在所有这些临时环面上都存在，因此任何占据环均无竖向同调。若某一分隔列在全部新行仍空，它切断横向同调，故每个前缀 R_s 都是0。

讨论是最坏准备、受控查询；不是把这些特殊历史说成 iid 平衡态下的典型样本。

## 2. 共同擦除引理：允许自适应策略，不能用反馈躲开

在预先生成的相互独立 U_(j,s)∼Uniform[0,1] 上实现占据：站点占据当且仅当 U_(j,s)≤q_(j,s)。对每个指定分隔列 j，定义

    E_j = {U_(j,1)>1−ε,…,U_(j,h)>1−ε}.

因为 q_(j,s)≤1−ε，E_j 强制该列在所有h个新行为空，不受先前反馈影响。E_j 的概率恰为 ε^h，不同分隔列的事件独立。故

    P(E), E=∪_j E_j = 1−(1−ε^h)^t = 1−β_h.

事件 E 与 X、公共随机种子独立。在 E 上，每份准备的整条秩轨迹全0；如果控制依赖过去秩，控制本身也沿同一个全0反馈分支。因此在每个固定公共随机种子下，各准备的输出律含有同一部分 (1−β_h)δ₀。这证明(B1)。

更强地，该观察信道是如下信道的后处理：以概率1−β_h输出擦除符号，以概率β_h完整揭示X。形式上

    Q_x=(1−β_h)δ₀+β_h Qtilde_x.

这不是声称真实实验会揭示X；揭示信道只是一个更有信息的比较对象。对任意准备先验，数据处理给

    I(X; transcript | query, public seed)
       ≤ β_h H(X | query, public seed).                  (B3)

该证明仅用显式耦合；它与 Polyanskiy–Wu 的信息渗流／擦除比较相呼应，但不把他们的 XOR 图观测定理当作本同调模型的黑箱。

两份相反比特准备的等先验最优测试错误为 (1−TV)/2，所以要两侧最坏错误均≤η，须β_h≥1−2η。取对数即(B2)，h=2即(A2)。固定h时，β_h≤exp(−t ε^h)，所以固定噪声下的常高度查询逐渐没有可用信号。

### 重复不是免费补救

若每次都重新制备同一未知准备，使用独立新噪声，允许根据此前实验结果改变下一轮查询，n轮的 TV 仍至多

    1−(1−β_h)^n.

这是把每轮的共同擦除事件耦合起来；全擦除分支上的反馈一致。达到等先验错误η的必要轮数为

    n ≥ log(2η)/log(1−β_h).                              (B4)

它是必要下界，不是充分样本数。固定h、ε时，这个下界随宽度指数增加。

例：w=5000、t=1000、h=2、ε=0.1 时，β=0.99^1000≈0.0000431712474。一个总输出0的模型，对该族全部两行完整轨迹的TV误差不超过此数；区分任意两份准备的等先验错误不低于0.4999784。要把错误降到1%，(B4)至少要求90,615次重新制备。十进制只是公式的说明值，不是实测性能。

对于ε=0.1、目标错误1%，w=50/500/5000/50000时，(B2)分别要求h至少3/4/5/6。整数门槛用有理数幂直接验证；这不表示这些高度已足够。

## 3. 两行正向构造：单故障只在有限局部门槛上有害

只需证明读 u，读 v 是反射。把目标块循环平移到 a=0,i=1,j=2,d=3。两个目标新行分别为

    m: 除0、2外全占据;
    n: 除2外全占据.

每个新站点独立以ε翻转目标值。

### 3.1 真比特0：三个低概率站点是充分的隔离条件

如果 m₀、m₂、n₂ 均保持空，则噪声后的新图是理想查询图的子图。理想查询在u=0时rank0，删除高概率占据站点不能增加rank。因此

    P(false positive | u=0) ≤ 3ε.                       (C1)

此处不把固定环面中站点删除的单调性误用于一般逐行重新闭合过程；比较的两个图有相同最终w×5环面。

### 3.2 真比特1：七个高概率站点，加一个两行矩形穿越

考虑由列 3,4,…,w−1 组成的两行矩形，共L=w−3列。要求七个目标高概率站点占据：

    m₁,n₁,n₀,m₃,n₃,m_(w−1),n_(w−1).

四个矩形端点均在其中。若该矩形有黑NN左右穿越，便能把m₃接到n_(w−1)，再沿n₀,n₁,m₁回到目标旧分量。u=1时旧分量从i接到d，合起来给出绕横向一次的环。所有额外占据都不会破坏这一见证。

两行矩形有一个直接的4/8二择一：没有黑NN左右穿越，当且仅当存在一对不同新行上的白站点，列坐标相同或相邻。任何白matching上下路径都必须有一步跨越两行；反之该白对就是上下切断路径。候选对数为3L−2，矩形全部目标站点都是高概率站点，所以每一白对概率ε²。故

    P(false negative | u=1)
       ≤7ε+(3L−2)ε²
       ≤7ε+3wε².                                       (C2)

这是(A1)。它保留了真正有害的双故障，而不是把所有2w个站点的单故障都当作失败。

若0<ε≤1/(400√w)，w≥5≥4给

    7ε+3wε² ≤ 7/800+3/160000
             = 1403/160000 < 1/100.

全是严格可检查的常数界。结合(A2)，固定两行、固定误差目标下噪声的最优**阶数**就是w^(-1/2)。这不是最优常数，也不是普适临界缩放律。

### 3.3 先前记忆下界获得更大的有效噪声区间

输入翻转矩阵 W_ε=[[1−ε,ε],[ε,1−ε]] 在ε≠1/2可逆，所以对全部两行指令，tensor准备—响应秩仍是3^t。只要ε≤1/(400√w)，每个单比特查询错误≤1%，经典随机访问/Fano下界给

    log₂ M ≥ 2t[1−h₂(1/100)],
    M > (7/2)^t.

若预测模型还允许每个查询1%的TV误差，合并后的位错误≤2%，仍有M>(13/4)^t。这是原归一化**初始准备记忆**合同，不声称3^t维就是完整后续随机机器的阶数。信息论步骤归属已有RAC理论；本轮新增的是使其物理噪声范围由O(1/w)提高到O(1/√w)的几何估计。

## 4. 不应再把什么当成同一个问题

### 4.1 固定噪声下的精确大秩，与单状态近似可以同时成立

只要ε≠1/2，两行输入变换仍可逆，精确响应秩仍为3^t。但固定ε、h=2时，所有轨迹以概率至少1−β集中在0。因此在固定绝对误差下，巨大精确秩未必是计算或学习的障碍。高阶逆变换会放大极小的概率差，不能免费应用。

界(B1)控制的是无条件轨迹TV。对R_h≠0等稀有事件作后选择后，归一化可放大原来极小的差；不能从单状态无条件近似推出条件秩律也近似。后选择失败率属于实际实验成本。

### 4.2 最坏准备，与自然采样的平均误差不等价

若三个旧行也来自共同Bernoulli(p)，落在本张量准备族的总概率精确为

    p^(6t)(1−p)^(3w−8t).

当w=5t、p=1/2时为2^(-13t)；在所有p中最大值也只有[(6/13)^6(7/13)^7]^t。这不是说所有难准备都稀有，只说明**本构造**不能直接承担自然平均复杂度的下界。把一个模型仅在该族上的行为改坏，其自然平均TV损失至多该族的概率。若后续研究自然历史，必须另行规定准备分布和损失，而不是沿用均匀分布在4^t个人工准备上的RAC先验。

### 4.3 正实现、普通非负秩、学习成本分开

共同归一化潜在编码、算子闭合、普通矩阵非负分解、单个统计量的线性维数、有限误差学习成本不是一个对象。Littman–Sutton–Singh与Monràs–Winter给前两层的方法；Faenza等精确刻画的通信模型是“在期望意义计算矩阵”，不等于本题有统一归一化的二值随机访问；Hsu–Kakade–Zhang的可学习性还要求奇异值条件。见检索矩阵。

## 5. 检索后选择的下一步：固定噪声的对数高度查询，而非继续数状态

**C0目标。** 是否存在固定ε₀>0，以及不依赖宽度的常数C,c，使同一旧tensor准备在某个显式控制查询下满足

    max_(X,bit) P[query error] ≤ Cε₀ + Cw exp(−c h),

且h=O(log w)即可达到固定的小错误？这将与(B2)的必要阶数匹配。它是下一项真正可能改变结论的数学问题；本轮未把它写成已证。

### 为什么已有高密度穿越工具还不够

在一个全高密度W×h site矩形里，黑NN左右连接失败需要白8上下自避路径。简单路径计数在ε<1/7时就给一个保守界

    P[wire failure] ≤ 8W (7ε)^h/(1−7ε).

这只解决“远处导线是否断掉”。查询还要在比特0时阻止偶然旁路，在比特1时把微观旧端点接到导线。固定一列低密度沟槽不足：随着高度增加，错误占据可能跨过它；不能只证明高密度条带可靠就宣布整个查询可靠。

可试的明确几何是：从目标缺口向上逐渐加宽的低占据楔形隔离区，外侧为高占据通道，第一新行保留原局部查询接口。需要分别证明：

- 比特0时，锚定到旧白分隔的白matching隔离路径保持，且错误黑旁路的概率有宽度一致的小上界；
- 比特1时，两个旧黑端点以宽度一致的正概率接到外侧高密度通道，远处断线概率为O(w e^(−ch))；
- 隔离区未利用未查询的旧比特，也没有借用新的免费观测或改变噪声合同。

Damron–Lam Proposition2.5/Corollary2.7说明“纵向机会数×横向指数代价”如何决定细长条穿越，十分贴近这个尺度；但其对象是bond percolation/FPP，不能把结果和临界参数不加证明移到这里。Duminil-Copin–Tassion的site sharpness入口适合处理低密度路径尾部。先完成这个带旧端点的锚定连接/隔离引理，再谈大模拟或优化控制。

若这个锚定引理失败，有价值的交付是具体旁路/端点障碍及修正的高度代价，而不是硬套一个O(log w)猜想。

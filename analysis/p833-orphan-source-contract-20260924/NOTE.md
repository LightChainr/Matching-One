# #833 后续：13 条正压缩关系的局部来源、最大源合同及一个受控 110 维间隙

## 0. 本轮改变了什么，没有改变什么

本轮有三个层次，必须分别陈述。

1. 解释 #834 的 13 条关系：它们是 110 条带方向的**局部孤立前沿分量四项关系**在 D5 下的 13 个轨道。局部恒等式适用于满足条件的任意宽度，不依赖 Bernoulli 概率；宽五的完备性由有限证书给出，未推广到所有宽度。
2. 扩大已有 385 状态正模型的合同：从同一行独立同分布 Bernoulli，扩大到**任意 D5 不变的行分布**，包括行内相关、硬约束及随行改变的规律。这也是已有固定编码能够递归闭合的最大单行概率族。
3. 换成带已知方向的受控输入时，宽五的线性维数为 3328，最小正状态数为 3438。甚至只允许 32 种严格内部 Bernoulli 指令、每个位点以小概率 epsilon 违背指定掩码，在一个明确的开区间上仍有这个 110 维间隙。

第 3 条是**受控输入合同**，不是 #833 原问题中固定均匀 p 的自主近临界间隙。不能把它声称为证明了均匀方形 site 在 pc 附近有一般参数间隙。#834 的一般参数“正385=线性385”没有被撤回。

## 1. 物理对象与输入

固定宽度 w=5，square-site NN。已知历史 H 是若干实际行掩码；追加行后临时闭合当前前缀，读 ambient rank R_t in {0,1,2}，随后继续增长时不保留该次闭合边。B_t=1{R_t=1}。t 是延拓行数，不是物理时间，R_t 不保证单调。包括当前输出 t=0。

PR #834 的机器有 3438 个最小确定性未来类别，D5 商有 398 类。所有类别可以由同样长度七的历史准备。用 T_m 表示实际行掩码 m 的确定性转移矩阵（每行恰一个 1），D_r/D_b 表示完整/二进制当前输出投影。

所有“最小正状态数”都要求一个共同模型服务全部历史准备及其任意概率混合，初态编码不依赖尚未选择的未来实验。允许潜在初态是概率分布，允许一般非负边发射实现；不是只允许划分类，也不是一个指定初始分布的最小值。输出合同及输入族均是数学问题的一部分。

本轮先读取 #833 和 #834 最新评论；没有新的反对或替代输入。代码直接读取上一轮的完整宽五证书，复用并实际重跑原独立 boundary-star DFS/物理图检查，不把输入恢复称作独立新枚举。

## 2. 一条真正局部的转移恒等式

### 2.1 一般局部引理：孤立前沿分量

考虑一段不闭合成整圈的四站点行弧

    a -- i -- j -- d,          j=i+1 (mod w).

旧图中有一个分量 Q，不接触 pinned 首行，且它所有仍暴露的端点都在这四个位置。a,d 恒存在且属于 Q，i,j 是两个可选端点。Q 的路径增量与这段 NN 行弧一致；共同的既有水平周期子空间另外保存。除 i,j 是否作为当前端点存在之外，四个旧状态的消去骨架、其他分量和已完成周期均相同。

令 S_uv 表示 i,j 分别是否存在（u,v in {0,1}）。只对四个均为合法边界状态的情形作结论。则对每一个**确定的下一行掩码** m：

    delta_{T_m(S_11)} + delta_{T_m(S_00)}
      = delta_{T_m(S_10)} + delta_{T_m(S_01)}.           (1)

这里是整个下一边界状态的多重集合恒等式，不仅是相同的期望秩。

证明分两种情形。若新行的 i 或 j 未占据，相应旧端点根本不参与新旧连接，四状态沿该坐标成对相同，(1) 成立。若新行 i,j 都占据，它们已由新行 NN 边相连。若新行 a 或 d 占据，同一个新行分量已通过相邻边连接到旧 Q，可选边不会增添新的连接；增量一致排除了非零绕行的额外周期。若两外端点都未占据，Q 没有其他暴露端点或 pinned 连接，最多附着到一个新行分量，消去它不改变保留的连接/同调数据。四种更新此时全部相同。证明完毕。

强调两个限制：Q 不能另接远处端点或 pinned 首行，否则会有新的连接；路径增量必须一致，否则一条额外边可能制造真实绕行。当前闭合输出是否相同也是额外条件；只有同输出的四项关系才能直接用于含当前输出的完整轨迹商。

### 2.2 宽五的小例子

取四段历史，补空行后都可写成长度三：

    A=[0,0,15], B=[0,7,13], C=[0,14,11], D=[0,15,9].

它们当前秩均为0。在当前行的0,1,2,3弧上，0和3是恒定端点，1和2可选。四个方向明确的历史满足

    (e_A-e_B-e_C+e_D) T_m = 0,   m=0,...,31.          (2)

故两份混合 (A+D)/2 与 (B+C)/2 对所有确定后缀、所有未来随机输入规律、全部完整秩轨迹同分布，只要初始准备固定且未来控制是同一实验。四个纯历史本身并没有因此变为同一个历史。

### 2.3 110 条关系恰好解释了旧 13 条

在3438状态上逐输出块查找并精确核对，得到110条独立四项关系：85条支持在rank0，25条在rank1，rank2没有这种方向。每条都是(1,-1,-1,1)，都有上述局部孤立弧结构；共同骨架、端点、增量和输出条件逐条检查。

按 D5 的真实几何作用分组，得到

    110 = 4*5 + 9*10.

四个五元轨道投影到398类后，两个中间历史合并为同一二面体类，成为(1,-2,1)中点关系；九个十元轨道成为(1,-1,-1,1)平行四边形。这恰好逐条恢复 #834 的全部13条关系。

这也解释了探索中的否定结果：按相邻占据对数偏置行内分布，或区分相同占据数下的相邻/分散形状，都没有破坏13条关系。它们并不是不同占据数权重偶然相消。

## 3. 385 正模型适用于全部 D5 不变行规律

宽五的32个行掩码有8个D5轨道 O。可以用(占据数k，相邻占据对数a)区分：

    (0,0),(1,0),(2,0),(2,1),(3,1),(3,2),(4,3),(5,5),

轨道大小分别为1,5,5,5,5,5,5,1。

在398状态商上，让 C_O 统计在轨道 O 内各实际掩码的转移次数。复用 #834 的非负行随机编码 U 和代数重建 V，本轮对每个轨道分别核对

    VU=I, U1=V1=1,
    UVC_O=C_O,           VC_O>=0,
    D_r U=U Dtilde_r,
    Ctilde_O=VC_OU>=0,   C_O U=U Ctilde_O.              (3)

所以若 pi_t(O) 是下一行选择各轨道的概率，先选轨道，再在轨道中均匀选择一个掩码，则

    Ktilde_t = sum_O pi_t(O) Ctilde_O/|O|

是合法的385状态概率转移，精确保留全部秩轨迹。行内完全不需要独立。可以按行改变 pi_t，也可以按已观测输出和已公布的轨道历史选择下一轨道：对每个给定控制/输出序列的算子交织相同，反馈后的概率仍相同。

随机朝向条件须写清：条件于已声明的控制历史，轨道内部按均匀律选择。任意潜在历史依赖的朝向相关不是此马尔可夫交织声明自动覆盖的对象。

这是已有385模型的全族推广，不是对每个具体行律都声称最小值为385。统一服务该整个行律族的最小正/线性值都是385，因为该族包含均匀Bernoulli(1/2)，原385阶实际字串子式在本轮重新计算仍非零。

例如 q(m) proportional to exp(theta*k(m)+g*a(m))，任何theta,g及其逐行变化均在合同内。这个行内相关例子只是有限模型定义，不把它认作原Bernoulli渗流的同一物理模型。

### 3.1 已有编码的最大单行源族也恰好确定

令 F 是3438状态到385潜在状态的已有固定编码，即先取D5类，再用U。对未知行概率q(m)，若存在任何矩阵 Khat(q) 使

    T(q)F=F Khat(q),  T(q)=sum_m q(m)T_m,

那么同一D5类中的两行必须给出相同左侧。这给32个q(m)的齐次线性约束。本轮找到24条独立约束，并精确确认每个D5轨道的常数权向量都在其核里。因此整个核恰为8维的D5不变空间。配合(3)：

    这个固定编码能够随机递归闭合
       iff q(gm)=q(m) 对每个g in D5成立.               (4)

它是固定F的最大合同，不是声称任意非对称源下都不存在任何别的385状态编码。

一个物理反例足够显示边界：[1,1]与[2,2]被F编码为同一个潜在分布。下一行只把第0列概率设为1/2+delta，其他列仍1/2，完整下一秩律之差精确为

    (-delta, +delta, 0).

两者当前均rank1。均匀源的正模型不能原样拿来处理这个按列指定的源。

## 4. 带方向受控输入：线性3328，但正状态3438

本节改了输入合同：实验者可以逐行指定带列标签的行掩码m，或者下面的有噪声Bernoulli指令。包括当前B0，统一初态编码必须在未来指令确定之前准备。它不是固定均匀p的自主过程。

### 4.1 精确线性维数

110条独立关系在同一个完整rank输出块内，对每个T_m都被一步杀掉，因此对任意当前/未来输出投影和输入字串均不可见。线性上界为

    3438-110=3328.

下界由3328个实际二进制受控输出事件给出。递归构造概率列

    f_(b,m,w)=D_b T_m f_w,

从当前的两个输出指示开始，选出的事件最多需要5个未来行。它们都是0/1列，不是消元后的“虚构实验”。一个3328阶子式在GF(2)上行列式为1；按列、按行和相反主元顺序均核对。因此特征零维数至少3328，得到确切值。

这也证明110条局部关系穷尽了本合同的全部不可见线性方向，而不只是找到了一个小子空间。此完备性仅证于宽五。

### 4.2 任意正实现必须有3438个状态

二进制确定性细化是

    2 -> 808 -> 3318 -> 3438 -> 3438.

因此任何两种不同物理准备，都能由至多3行的确定后缀和一个二进制输出实验区分，概率一侧为1、另一侧为0。

假设有k状态正实现，alpha_s是物理准备s的潜在概率分布。对一对可被确定实验分开的准备，任何被两者共同赋正权重的潜在状态，都必须让同一个实验同时以概率1和0发生，这是不可能的。因此不同准备的潜在支持两两不交。3438个非空支持要求k>=3438。原确定性机器给出等号上界。

所以，即使只读一个比特，受控合同下也有

    最小正状态数3438 > 最小线性维数3328，间隙110.     (5)

一般0/1输出的极值性不是新理论；本次具体增量是该自然拓扑机器的110条完整局部关系及其精确线性维数。它与#833所说的被动支撑下界无力不冲突：这里显式改变了输入实验，拥有确定性区分实验。

### 4.3 不必真的使用0或1的站点概率

给32个掩码分别配一个指令。指令m执行时，站点独立：若该位为1，占据概率1-epsilon；若为0，占据概率epsilon。全部概率严格内部，未来输入字串是指令而不是实际噪声掩码。

相应转移为

    K_m(epsilon)=sum_b epsilon^d(m,b)(1-epsilon)^(5-d(m,b)) T_b.

32x32权重变换是二元翻转矩阵的五次张量积；epsilon!=1/2时可逆。因此两族算子的线性包相同，完整受控可观空间也相同，线性维数仍精确为3328。

正下界还可以在一个明确的开区间保持3438。每对准备的确定区分实验最多涉及15个未来站点；有噪声时，正确掩码串的失败概率至多15 epsilon。因此对应输出律TV至少1-30 epsilon，正模型初态分布的重叠

    overlap(alpha_i,alpha_j)=sum_l min(alpha_il,alpha_jl)

至多30 epsilon（任何实验都是潜在初态后的随机信道，TV不会增加）。

对n份概率分布放在k个潜在点上，总两两重叠至少n-k：逐潜在点，最大项与其余项配对已贡献“总和减最大项”；跨点相加，并用每点最大项<=1，即得n-k。

于是

    k >= n - binom(n,2)*30 epsilon
      = n - 15 n(n-1) epsilon.

取n=3438，得到

    0 < epsilon < 1/177246090
       => 最小正状态数=3438，最小线性维数=3328.        (6)

例如epsilon=10^-9，总重叠预算为0.17724609<1，整数状态数不能少一个。这是32个严格内部物理Bernoulli源上的开区间结论，不是仅在无噪声端点成立。没有声称该保守区间最优。

再次强调：这些源在各列接近指定0/1掩码，不是“共同均匀p接近方形pc”。不能把(6)写成#833原自主近临界合同已解决。

## 5. 精确维数也有近似可测性的边界

epsilon=1/2时所有指令退化为同一个均匀行源，原385模型精确。epsilon!=1/2时受控线性维数跳回3328，但当epsilon很接近1/2，这不表示必须实际使用几千状态。

把每个指令下的站点与Bernoulli(1/2)使用同一Uniform变量耦合。每个站点不一致概率为delta=|epsilon-1/2|。前h行至多5h个站点，因而忽略指令、使用均匀385模型预测整个输出轨迹时，对任意历史准备都有

    TV(true controlled path, uniform-385 prediction)
        <= min(1, 5h |epsilon-1/2|).                  (7)

这是一条耦合上界，不是实测误差；确定初始R0也由同输出编码精确保留。共同的基于已观察过去的控制策略，可在首次配置不一致之前耦合为同一策略，结论不变。

例如h=20、|epsilon-1/2|<=10^-4时，(7)给1%的全轨迹TV上界。中等噪声下的确切最小正状态数本轮未求；(6)的下界和(7)的近似上界处理的是不同区域。

## 7. 剩下的一条结构猜想

C0：在更宽的同类行机器上，是否所有同输出、对每个实际行掩码被一步杀掉的线性方向，都由局部孤立前沿分量的这类四项关系及其嵌入组合生成？

本轮证明局部恒等式本身在所声明条件下不依赖宽度，且在宽五全部不可见方向恰由它们生成；不把后者外推成全宽度完备性，也不预设对应正坐标总能保持非负。一个具有不同几何支撑的最小核向量就是有用反例。未自动启动宽六队列。

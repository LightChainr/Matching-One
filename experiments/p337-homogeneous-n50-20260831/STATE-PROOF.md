# NN frontier 的全局 rank 商空间压缩：独立审查

**结论：对指定的 `(count,sumS,K)` 及终点 `q=r−1,E=q²`，该压缩精确，条件是 r=1 时的规范方向 h 本身必须保留在状态 key，且 frontier 的遗忘时序覆盖周期闭缝边。** 不需要保存完整整数 winding subgroup、每个组件的 winding rank 或更高绕行倍数。本审查只给证明，不做枚举或修改主工作树。

## 1. 精确不变量

令已经加入图中的全部 cycle 的 lifted physical displacement 张成全局实子空间 `H⊂R²`。保留 `r=dim H`。每个活跃组件内选择一棵生成树，以一个规范活跃点为基点，保存其他活跃点沿树的相对位移在 `R²/H` 中的像。

不同生成树给同一端点的路径之差是已知图中的 cycle，其位移属于 H；因此这个商空间位移与树的选择无关。每个组件的基点可不同，不需要保存跨未连接组件的绝对位置偏移。实际 NN 边位移必须使用覆盖空间中的真实步长，包含周期边的方向；不能用商顶点坐标差替代它。

三个存储阶段恰好实现此不变量：

- r=0：H=0，保留二维整数位移；
- r=1：令 h 为全局 H 的规范 primitive 整数方向，保存 `det(h,d)`。其核在 R² 中恰为 H；
- r=2：商空间为零，只保留 connectivity 即可。

h 按 physical vector 的整数 gcd 和固定正负号规则规范化即可；这里仅需方向，不要求 h 是周期格中的某个指定 generator。所有 determinant 与位移应作精确整数计算。

## 2. 三种边操作都由压缩态决定

对边 `u→v` 的真实位移 e，若 u、v 已在同一组件，cycle 残差为 `d_u+e−d_v`。

1. **连接不同组件。** 新边是 bridge，不增加 beta，也不增加全局 H；合并组件的 gauge，使这条边在当前商空间中的位移约束成立即可。两组件原有的所有 winding 已经包含在全局 H 中，不能在此再次计一次 rank。
2. **r=0 的冗余边。** 残差为零则 rank 不变；非零则令 H 为该方向，rank 增1。此时必须把**全部组件**的已存二维位移同时投影，不仅是出现该 cycle 的组件。
3. **r=1 的冗余边。** projected 残差为零，当且仅当其真实 cycle 已在 H 中；非零则增至 rank2。整数绕行倍数或过去组件的 winding 生成元数量不会改变这一判定。r=2 后任何未来边都不再增加全局 rank。

每条冗余边无论残差是否为零，普通图 beta 都增加1。特别是 r=1 下平行于 h 的非零绕行被投影成0，**它仍然是一个新普通图 cycle，S 仍要加2**。不能把“商空间残差为0”误写成“整条边无贡献”。r=2 丢掉位移后也同样保留这一计数。

这给出对所有未来边序列的归纳证明：连接关系、beta 的增量和全局 rank 的增量，与未压缩 gain-aware union-find 完全相同。

## 3. 遗忘组件与周期边

仅当一个顶点的所有 incident edges 都已处理，才可把它从 frontier 删除。这包括穿过周期接缝、连接首尾扫描行的边。若某组件还有其他活跃点，保留它们的连通等价关系与商位移；可重选规范活跃基点并减去其位移，不能因旧基点被忘记而丢失组件内路径。

当最后一个活跃点消失时，该组件不可能再接入未来图，所以其内部连通/位移数据可以全部删除；但全局 H/r 必须继续保留，因为其已发现的 winding 仍属于最终图。已累计的 beta/S 也不回退。该计数方式不需要在封闭组件时再额外加入一次 cluster 奖励。

若实际 sweep 过早忘记周期边端点，整个方案会失败；这是 frontier 调度条件，不是商空间压缩本身的损失。

## 4. S 与统计合并

初值 `S=2N+1` 正确。加入一个占据顶点使 `K+=1`，其即时贡献为 −3；加入 bridge 的贡献为0；加入冗余边的贡献为 `2−Delta r`。逐步总和恒等于

```text
S = 2*beta−r−3K+2N+1.
```

即题设源恒等式。某个组件第一次形成 winding，不一定使全局 r 增加：若其方向已经在其他组件提供的 H 内，则此边只加2，不能再减1。

设一个压缩状态的值为 `(n,s)=(count,sumS)`。未来一条分支的增量 delta 由压缩状态和新增顶点/边唯一决定，则

```text
n' = n,
s' = s+delta*n.
```

若多个历史到达同一规范状态，直接分别相加 n、s。其未来可行分支、终点 r 和每步 delta 相同，所以任意后缀的源总和均正确。过去 beta/S 可以不同，不妨碍这一线性统计合并。K 必须继续作为状态量或等价的按 K 索引多项式保留，不能把不同 K 的计数无标记混合。

终点 r 固定后，所需 `sum(qS)=q*sumS`、`sum(ES)=E*sumS` 都可直接得到。count 和 sumS 足够保留源的一阶矩；它们不支持在完成后恢复整个 S 分布、S² 或任意有限 t 的 `exp(tS)`。若另一个算法从起点就逐转移累积 `exp(t*delta)`，相同状态压缩仍可使用，但那不是仅凭本次两列统计事后重建。

## 5. 不能省略的 h 与整数信息边界

**r=1 的 h 必须属于合并 key。** 只保留 `r=1` 和 projected scalars 而丢 h 不精确：一个只有单活跃基点、所有相对位移为0的状态，可能已有水平 H，也可能已有竖直 H。未来加入一条水平 winding cycle，前者不增 rank，后者增至2，S 相差1。两者不能合并；未来边的 `det(h,e)` 本身也需要知道 h。

反之，一旦规范 h 已保留，隐藏的整数倍数没有再进入目标的通道：q/E 只用全局实 rank；S 的其余拓扑量 beta 是普通图 cycle 个数，已由每条冗余边计入。不同绕行倍数、不同生成元的整数 index、或某个旧组件单独承载了哪个同向 cycle，都不影响未来 q/S。

本结论不覆盖其他输出，例如每组件 winding、完整整数子群、有限模数 twist 相容性或指定 primitive winding sector。若以后需要那些量，必须重新论证状态充分性。对当前纯 NN、目标只含 q/E/S 的 frontier，按上述条件实现即可精确。

## 6. 按 K 的多项式合并与整数容量

完成小图核验后，实现再将 K 从 hash key 移到值中的动态连续系数区间。
一次占据分支把指数 K 整体加1，空置分支不移动；同边界态按相同 K
加和 count 与 sumS。源增量只由边界态及该分支决定，故每个系数仍按
`(n,s) -> (n,s+delta*n)` 变换。区间中可能的零系数保留为0，不合并不同 K
或近似其分布。此改变只压缩重复的边界 key，不改变任何物理输入。

对固定 N<=50，任意 partial graph 有 beta<=E<=2N、0<=K<=N、0<=r<=2，
故 `|S_partial|<=6N+1` 是一个保守界。每个层/系数的路径数至多2^N，
因此 count 及 `|sumS|<=(6N+1)2^N<=301*2^50<2^63` 均可用 signed64。
实际加法与乘法先在 signed128 中计算、检查范围后再存回。gain仍有独立
int32运算/int16存储范围检查。新程序显式拒绝 N>50，不能把本容量论证
自动推广到更大几何。

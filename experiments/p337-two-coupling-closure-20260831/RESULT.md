# 一孔缺陷需要超出共同温度与同一源耦合的响应方向

**已排除一个完整的有限模型类。** 对固定N50 `(5,5)/(1,7)` 几何对，一孔缺陷造成的四个原q/E响应不能同时由温度和闭合源`S=C+F4+Bvac`的共同重参数化产生。并未增加描述符、重新枚举构型或启动云机器。

## 判决

同一个端点profile族若能够一阶描述内部变化，链式法则要求

```text
H = b*T + c*C,
T=∂p(q₁,E₁,q₂,E₂), C=Cov((q₁,E₁,q₂,E₂),S),
H=25*(1-p)*(f_one_hole-f_intact).
```

b/c可以任意平滑依赖p/t，但必须在四行中共同使用。我们在已固定共同根处计算全部四个3×3 minor，未选择有利行：

```text
D3 = sum_I det([T,C,H]_I)^2
   = 0.000439154238009660181272355003750509…
D3 > 1/10000 > 0  （精确有理下界）
```

全部有理包络宽度为`4.196e-37`；这些是计算包络，非统计置信区间。辅助检验确认`rank[T,C]=2`，加上H后rank=3。完整矩阵、四个minor、源中心化、根异号与斜率检查见[机器结果](results/latest.json)和[评分报告](results/REPORT.md)。D3数值依赖单位，零与非零判决不依赖可逆坐标选择。

这四个读数直接决定两几何的rank边缘分布：`P0=(E-q)/2,P1=1-E,P2=(E+q)/2`。因此结论针对原观测层的共同闭合，未引入新的局部响应坐标。消去共同root运动只作列加法，D3保持原样。

既有一孔结果已否定源无关整体增益，给出`U U_st-U_s U_t=27.76656…`；但即使完全留在同一源族中，`U(epsilon,t)=u((1+lambda*epsilon)*t)`也能使相应混合行列式非零。旧结果不能排除有效源耦合变化。本次进一步排除了两几何q/E profile的共同热/源坐标闭合；它不排除偶然只匹配标量U的模型。

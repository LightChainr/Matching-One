## 计算定义与核验

用完整生成元解 `F₀π′=−F′π₀, sum(π′)=0`。在原正交 character-i 基 Q 中，定义 `H=−Q*F₀ᵀQ`、`B=Q*diag(π₀)Q`，其导数同理。相关矩阵约定与上一批完全一致：`C(t)=conj[Z* B exp(−Ht) Z]`。

时间域采用矩阵指数 Fréchet 导数；归一化响应为 `U′=C₀^{-1}(C′−C₀′U)`。零频用

```
R  = C₀⁻¹ conj[Z* B H⁻¹ Z]
R′ = C₀⁻¹ {conj[Z*(B′H⁻¹ − B H⁻¹H′H⁻¹)Z] − C₀′R}.
```

`B′` 项与 `−C₀′R` 一起构成平稳重加权贡献；`H′` 项为物理生成元贡献。两部分的分拆保持固定的旧源定义。还输出了 `∫tU′(t)dt`，没有据此新增筛选目标。

- 本次重建的 H、B、Z 与已归档零扰动文件逐元素一致。
- Poisson 导数方程最大残差 `1.03×10⁻¹⁵`；`sum π′=−1.11×10⁻¹⁶`。
- Kreweras 对称性预言同 ray 一阶响应为零；实测最大残差 `5.05×10⁻¹⁶`。
- 全 186 模态展开与 Fréchet 时间响应差 `3.14×10⁻¹⁵`；与 resolvent 积分差 `1.77×10⁻¹⁵`。

## 适用范围

这是有限 width=8 Markov 过程的确定性导数计算，以 float64 求解解析方程，未作有理数证书。14/16 维模型**输入完整模型的 π 和 π′**，所以这里验证的是给定平稳度量及其导数后的动力学压缩，尚不能宣称它们独立预测静态混合。模态截断是两条 propagator leg 的有符号响应预算，可能有零时截断残差；它不是概率权重，也不是独立的 η 依赖 Markov 模型。本文据此讨论响应机制和固定模型的压缩效果，不推出连续极限算符或 square-site 字典。

# Design and timing

This is a retrospective mechanism analysis selected after the shared-label first derivative and complete birth curves were known. On2026-08-31 the parent and two other research teams confirmed that the finite q_t task was not already executing. Before reading new outputs, the parent chose only t=-1,+1 for each pre-existing g_plus/g_minus policy, both original sizes, the fixed p_ref and exact p integral. No width, size, parameter fit or new tail population was added.

The first new operation was the full joint-safe degree/loop census on old prefixes. It is then used for exact finite normalization and for the analytic score H=pi_a(g-mean_a g). The saved uniform-label/tail archive estimates finite response by an all-pair half-difference. The even/odd finite combinations and remainder diagnostics are dependent descriptions of this same experiment. Full source, code, runtime and outputs are in this directory.

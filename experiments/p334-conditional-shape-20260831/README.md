## 对纯平移解释的约束

若每个完整 prefix Z 内仅发生 `X_t=X+t a(Z)`、`Y_t=Y+t b(Z)`，不论两个位移是否相同，所有条件方差和协方差导数都必须为零。`minus → D` 的中心方差响应在两 N 同向分辨，直接约束这一整类解释。

该响应在合并72组的全部20次删批估计中保持负号：N325 范围 `[−2.58667e−8, −2.17043e−8]`，N425 范围 `[−1.43980e−8, −1.14235e−8]`。新64组单独的结果为 `−2.51351e−8 ± 5.59101e−9`、`−1.34706e−8 ± 3.03356e−9`，也在全部删批中保持负号。这里的单独计算只隔开条件随机流，仍共享原前缀，不能视为独立总体复现。

旧8组同一 cell00 目标为 `−1.91313e−8 ± 1.72681e−8`、`−8.48194e−9 ± 1.48955e−8`，原先精度不足。新64与旧8的配对差在两N均不到0.35个配对标准误；合并后的标准误分别缩小约3.24、4.51倍。进展来自既有追加尾部的条件精度，没有把估计器之间的差异当成新物理效应。

出生间隔方差在 N425 的 plus→S 和 minus→D 下有响应，N325 相应读数较弱。因而本次对“每个 prefix 内的确定性平移”约束明确；对于允许位移依赖 label 或 suffix、但要求逐路径 W 不变的更宽共同平移机制，尚未获得同等清晰的两N一致判断。

## 无偏性、来源与复现

沿用 [03603388 的恒等式](https://github.com/LightChainr/Matching-One/blob/03603388e6c0bee5889a64229a124d3f5e89790b/notes/p334-nested-covariance-response.md)：每 quartet 取 `b_f=(f_U+f_V)/2`、`h_f=(s_U−s_V)(f_U−f_V)/2`，其中 `f_U` 是同一 label 两条 suffix 的均值。令 `P_Q` 为互异 quartet 的乘积均值，则

```
H Cov(f,g|Z) = mean(h_fg) − P_Q(b_f,h_g) − P_Q(b_g,h_f).
```

形状平方的多项式展开使用互异 quartet 的二、三、四阶 U 乘积，不平方有噪声的条件导数。代码通过集合分拆公式以 O(Q) 计算这些乘积。固定数组的全排列核验无差异；有限二点分布的16个四-quartet结果有理数穷举给出真能量与估计平均都为 `41/2`，并保留负估计反例 `−30`。

数值实现将 C 减去 prefix 固定的 `k0/(N+1)`，以减轻抵消；条件协方差及其导数不变。旧score逐元素重建差为零，旧矩转换误差及共同factor核验见 [QA.json](QA.json)。全部原始读数在 [results/latest.json](results/latest.json)，每prefix结果在 `results/prefix_shape_N325.npz`、`results/prefix_shape_N425.npz`；远端直接生成的完整表在 [results/REPORT.md](results/REPORT.md)。

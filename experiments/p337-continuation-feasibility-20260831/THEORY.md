# 0/1 孔信息不能独自控制齐次 U：同 root、同正斜率的精确反例

**结论：仅保留已有 0/1 孔系数、`q∈{-1,0,1}`、`E=q²` 和孔数概率，不能在 `epsilon=1` 给原 U 确定符号。** 两套满足这些条件的整数 Bernstein 补全，保留每个几何完全相同的 q 曲线、共同 root 和严格正斜率，却分别给出 `U≈+10.1035767865` 与 `U≈−10.0743244096`。任何仅依赖这些条件、对所有补全都正确的 U 区间，宽度至少为 `20.1779011961`。

这比“多孔概率接近 1”更强：即使额外提供这两套补全的完整 q 曲线、root 和斜率，E 的导数仍不可识别。这里证明的是**摘要约束的信息不足**。补全不是原格点真实多孔连通律，也不是两个新物理候选；原图的连通规则可能排除它们，但那正是孔尾概率与所列摘要之外必须加入的信息。

固定 `S*=C+F4+Bvac` 和 `pA=1−epsilon*(1−p), pB=p`，不换 source 或 chart。反例发生在 `t=0`，此时固定源倾斜权重等于 1。它已足以否定“仅凭这些信息能对包含 t=0 的原 U 家族作受控延续”的保证；没有为未知孔层另定义 S，也没有声称补全满足配置级源/拓扑恒等式。

## 1. 使用比一阶 Taylor 截断更完整的已有信息

父 N50 的 A/B 子格各有 `M=25` 个位置，几何顺序固定为 `(5,5)`、`(1,7)`。用 `f_g,0(p)`、`f_g,1(p)` 表示现有完整与一孔 Bernstein 表给出的原 q/E 条件均值。输入来自 `f5c4a74a20bad8589c39e1034cfb209462110dbe`，与相邻 `p337-two-coupling-closure-20260831/SOURCES.json` 的四表哈希逐一核对。

在齐次点 epsilon=1，A 孔数 `H~Bin(M,1−p)`。记

```text
w0=p^M,
w1=M(1−p)p^(M−1),
tau=1−w0−w1,
K_g,f=w0*f_g,0+w1*f_g,1.
```

于是 `f_g=K_g,f+R_g,f`，其中 `R=E[f*1{H≥2}]`。使用精确的 w0/w1 而非把它们 Taylor 展到 epsilon 的一次项，对端点资料最有利；下述失败不来自低阶 Taylor 本身的截断误差。所有补全在 epsilon=0 有相同的完整 0/1 孔信息和同一个一孔导数。

## 2. 一个保持完整 q 曲线不变的补全对

只在未知的 `H≥2` 层考虑三个独立 B 占用位 `X1,X2,X3∈{0,1}`。定义两条确定读出规则：

```text
A: qA=2*X1*X2−1,             EA=qA²=1;
B: qB=X1*X2+X1*X3−1,        EB=qB².
```

两条 q 都对 B 占用单调，均只取 −1、0、1。对每一个 p，

```text
E[qA]=E[qB]=2p²−1,
E[EA]=1,
E[EB]=1−2p²+2p³.
```

相同 q 不仅是某个 p 处相同：在每个 `K_B=k` 行，配置总数和整数和为

```text
count = C(25,k),
sum_qA = sum_qB = 2*C(23,k−2)−C(25,k),
sum_EA = C(25,k),
sum_EB = C(25,k)−2*C(23,k−2)+2*C(22,k−3).
```

越界二项系数记为 0。它们满足 `0≤sum_E≤count`、`|sum_q|≤sum_E`，且 `(sum_E±sum_q)/2` 为非负整数。因此这是实际可实现的条件 q 分布，不是互不相容地挑选 q 和 E 均值。读出规则给出这些公式，不需枚举任何新孔构型。

补全 `+` 在几何 1 用 A、几何 2 用 B；补全 `−` 交换两规则。两套都完整保留真实 0/1 孔表。记 `L=K_1,E−K_2,E`、`G=2p²(1−p)`，则两套的**每个几何** q 曲线完全相同：

```text
q_g^+=q_g^−=K_g,q+tau*(2p²−1),
Q=mean_g(q_g),
(E1−E2)^±=L±tau*G.
```

所以它们有同一 Q、同一共同 root，以及同一分母 `D=Q'`。但

```text
(E1'−E2')^±=L'±(tau*G)',
U^± = [50^(13/8)/2] * [L'±(tau*G)'] / (DeltaCos4*D),
DeltaCos4 = −1−527/625 = −1152/625.
```

此处直接使用原 U，不添加 descriptor、source 或归一化选项。

## 3. 精确共同 root、斜率和 U 包围

```text
Q' ≥ 4*p_lo*(1−kappa(p_hi))
     − kappa'(p_hi)*(1+max|2p²−1|)
     − 2M*kappa(p_hi) > 0.
```

在该区间，kappa、kappa' 均递增，所以右侧是有效下界。二分随后用精确分数细化同一个 root；导数与原 U 通过精确 Taylor 余项包围计算，面积因子用整数八次根包围。没有概率置信区间或 Monte Carlo 误差。

## 4. 热导数预算：遗漏概率不等于遗漏导数

在 epsilon=1、t=0，令 `K_B~Bin(M,p)`，总占用 `J=M−H+K_B`。沿固定齐次 p 坐标，乘积测度的 score 为

```text
ell_p=(J−2Mp)/(p(1−p)).
```

于是对 p 本身不变的静态读出，严格有

```text
R_f' = E[1{H≥2} * f * ell_p],
Bplus  = E[1{H≥2} * max(ell_p,0)],
Bminus = E[1{H≥2} * max(−ell_p,0)],
B1 = Bplus+Bminus.
```

由支持条件直接得到

```text
|R_q|≤tau,              0≤R_E≤tau,
|R_q'|≤B1,              −Bminus≤R_E'≤Bplus,
|R_1,E'−R_2,E'|≤B1,    |mean_g R_g,q'|≤B1.
```

这些 score 界是给定逐构型范围时的最坏情况界；E 在 score 正/负处选择 1/0 即可达到端点。把两个几何的 E 差当成范围 `[−1,1]`，可避免误报额外因子 2。一般的 Cauchy 上界为 `B1≤sqrt(tau*2M/[p(1−p)])`，但脚本直接作有限二项计数求和，得到更尖锐的精确值。此概率求和没有计算任何多孔拓扑读出。

在固定有理参考点 `p=1/2`：

```text
tau = 16777203/16777216 ≈ 0.99999922514,
B1 = 1580127547307075/140737488355328 ≈ 11.22748150313,
known mean(q)' ≈ 0.00002033098845,
possible D budget ≈ [−11.22746117215, +11.22750183412],
|P4(R_E')| ≤ B1/|DeltaCos4| ≈ 6.09129855856.
```

该参考点只用于检验误差界，未声称是原齐次 root。即使先把 root 固定，支持/尾概率预算也无法保证斜率分母的正下界；若加入原图 rank 单调性，可把负斜率排除，但单调性本身仍不给可用的正下界。第 2–3 节进一步表明：即便绕过这一分母困难，把 root 和正斜率完整交给推断者，分子的取向导数仍存在严格符号歧义。

## 5. 真正需要补足的误差项

令 `Q=Qtilde+R_Q`、`A=P4(E_p)=Atilde+R_A`，近似根为 `ptilde`。在同一个覆盖根的区间 I 上，若能证明

```text
|R_Q|≤rho0,       |R_Q'|≤rhoD,
|R_A|≤rhoA,       inf_I Qtilde' = s > rhoD,
|Atilde'|≤LA,     |Qtilde''|≤LD,
```

并有两端异号保证根留在 I，则设 `d*=s−rhoD`，有

```text
|p*−ptilde| ≤ delta = rho0/d*,
|U−Utilde| ≤ a*(rhoA+LA*delta)/d*
             + |Utilde|*(rhoD+LD*delta)/d*,
a=N^(13/8)/2.
```

这同时包含热导数误差、共同根移动、分母误差和面积/角度放大。0/1 孔加范围界只能提供 `rho0≤sup tau`、`rhoD≤sup B1`、`rhoA≤sup B1/|DeltaCos4|`，在目标区域通常已使 `s>rhoD` 失败；即使单独补上分母正界，也不消除第 2 节的分子歧义。

因此缺失条件可以具体表达为：**在同一根区间，对未知多孔层的取向差热 score 矩给出严格消去/符号/幅度界，并同时控制 pooled q 的根与斜率。** 只增加孔尾概率精度、沿端点导数线性外推，或只证明 root 可跟踪，都不能替代这一项。这里不提出自动枚举二/三孔或新 MC；若没有这种连通结构约束，现有端点材料对“已解释齐次 U 异常”的延续主张应停在信息不足。

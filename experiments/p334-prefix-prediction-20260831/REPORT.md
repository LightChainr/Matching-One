# 源Gram在同cell00内带来明确的组外预测增益

精确的前缀源Gram矩阵G能够预测一部分此前由rank-cell标签无法解释的局部响应变化。预先固定的`J(Z)=B G(Z)`模型，在留出的原批次上，比同cell00常数矩阵模型降低了约38%–39%的A响应风险、54%–59%的出生中心响应风险。两个模型每个输出均为4个参数，没有通过更多参数或事后特征筛选取得优势。

| 输出 | N325：常数风险−BG风险，原20批SE | N425：常数风险−BG风险，原20批SE |
|---|---:|---:|
| A(p_ref) | `8.10738e-8 ± 1.09580e-8` | `6.39379e-8 ± 1.77188e-8` |
| 占常数风险比例 | `38.17% ± 9.33百分点` | `39.37% ± 10.59百分点` |
| 出生中心C/(N+1) | `9.46838e-10 ± 1.25164e-10` | `7.39776e-10 ± 1.55294e-10` |
| 占常数风险比例 | `54.42% ± 15.47百分点` | `58.65% ± 15.71百分点` |

A的常数风险为`2.12382e-7/1.62419e-7`，BG风险为`1.31308e-7/9.84814e-8`。出生中心的常数风险为`1.73977e-9/1.26139e-9`，BG风险为`7.92933e-10/5.21609e-10`。比例的分母在点估计和所有leave-one-batch中均为正；完整风险、Monte Carlo噪声诊断和共同协方差见`results/score.json`。

这支持一个具体的有限几何机制近似：保持即时联合rank/Euler分布的源变化机会及其两源耦合，可以通过同N内共享的B，预测部分未来局部响应。G不是任意拟合出的潜变量；它来自完整标签census的精确`E[HHᵀ|Z]`。预测改善并不证明`J=BG`是完整机制或唯一因果解释，剩余风险未强制为零；两个N分别训练，尚未检验跨N零重拟合迁移。

## 估计与防止泄漏

研究总体只包含原cell00的1502/1551个前缀，不追加任何prefix、label或suffix。每前缀使用原8+新64组quartet的既有J均值和跨不同quartet的无偏energy。出生中心响应由`integral A=1-2C/(N+1)`精确转换，没有重做birth层级分解。

G为`sum_a pi_a³ Cov(L|a)`，与旧masked `pi_a²` Gram不同。模型只比较常数K与BG，没有加截距、ridge、特征扫描或第三个模型。训练只解2×2方程，全部完整/删一拟合的最大条件数为1.139/1.118。

5折固定为`batch mod5`，同一前缀的所有quartet始终属于同一角色。风险采用`U_energy-2<P,Jbar>+||P||²`；在训练和测试批次分离的条件下，它估计真实局部J的平方预测误差，避免把Monte Carlo尾部噪声直接计入预测误差。比较两个模型时共同U_energy精确抵消。主汇总为cell00内前缀等权均值，另保留除以原20000的总体贡献，未将不同大小批次均值等权平均。

每次删除一个原批次都重新训练全部5折、重新预测并汇总风险，之后计算20批joint jackknife factor。不能把重叠训练fold当成独立重复；本分析没有这样处理。四个读数共享原样本与模型，不作为独立票数，也未将风险差转成名义高斯p值。

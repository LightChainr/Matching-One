# 预定分析：源机会矩阵能否预测同cell内的局部响应？

此方案在本轮拟合/预测结果出现前固定。只使用既有精确census和原8+新64组quartet，不追加prefix、label或suffix；不重做局部det及birth层级分解。

研究总体限定为原cell00：N325的1502个、N425的1551个固定前缀。按N分别训练。两个预先指定的输出是两几何的A(p_ref)局部响应，以及出生中心`C/(N+1)`的局部响应；后者由`integral A=1-2C/(N+1)`精确转换。输入源次序始终为(L_first,L_second)，观测行次序为(first,second)。

只比较两个同为4参数的矩阵模型，不扫选特征：

1. cell00常数响应：`P(Z)=K`；K由训练前缀的局部响应矩阵估计值取平均。
2. 具名机制模型：`P(Z)=B G(Z)`，其中`G(Z)=E[H Hᵀ|Z]`为精确census源Gram，`H_s=pi_a(L_s-mean_a L_s)`；B是训练前缀共享的2×2矩阵。

G描述保持即时联合rank/Euler分布的源变化机会及两源耦合。`J=BG`假定从这种源机会到未来观测量的局部线性转移B在同N/cell中共用。G由前缀确定，不使用尾部结果作为特征。该G含`pi_a³ Cov(L|a)`，不混用旧masked `pi_a²` Gram。

采用5折原批次分组交叉拟合，固定`fold=batch mod5`，每折测试4个原批次，训练其余16批。所有属于同一前缀的72组quartet始终处于同一个训练/测试角色。B以训练集的`sum ||Jbar-BG||_F²`最小化：`B=(sum Jbar Gᵀ)(sum GGᵀ)^(-1)`；只解2×2方程，不用伪逆、ridge或事后调参。记录训练矩阵特征值、条件数及各折系数。

每前缀已有72组quartet的`Jbar`与跨不同quartet的无偏energy：

```
U_energy = sum_{q!=r}<X_q,X_r> / (72*71)
E[U_energy|Z] = ||J(Z)||_F²
R_U(P) = U_energy - 2<P,Jbar> + ||P||_F²
```

P只由其他批次训练，所以该测试风险对真实局部J的平方误差无偏。直接比较的主读数是`R_constant-R_BG`；共同U_energy严格抵消，保留预测与目标的配对。负的无偏risk/energy不截零。`||Jbar-P||²`只作含Monte Carlo噪声的诊断，不作为主风险。

主汇总为cell00条件均值，分母是该N保留的cell00前缀数；另存除以原20000的总体贡献。各原批次的cell00数不相同，使用前缀等权，而非批次均值再等权。每删去一个原批次，都重新进行全部5折训练、预测和风险汇总，再计算20批delete-one joint factor。不能把固定一次预测后的批次SE当作含训练不确定性的最终SE。

报告每N/输出的零预测energy、常数风险、BG风险、配对风险改善、相对于常数的改善比例（仅分母在点估计及所有LOO中均为正时）；保留所有fold参数、LOO以及共同factor。结果解释为有限几何中的组外预测证据：改善支持G中的前缀信息具有预测价值，不证明机制闭合或唯一因果解释；没有改善只限制这一共享B模型，不否定源Gram的物理定义。

实际执行前将核对旧8、新64、合并72的均值/energy组合身份，以及新包输入SHA256。正式分析由root分配计算环境后运行；本阶段不开机、不重置key。
